# network-watch 예제

- `arm.fbx`: Live Link 요청으로 여는 3D 모델입니다 (팔의 본과 메시. FBX 7.4 ASCII, 약 8 KB). `crates/yolu-model/tests/common/fbx_ascii.rs`의
  `arm_scene().to_ascii()`로 작성했으며 실제 모델은 사용하지 않았습니다. `tools/network-watch.py`가 작업 폴더로 복사해 사용합니다.
