# 화면 색상 가져오기

Windows의 편집 메뉴와 스포이트 옵션 모음에서 사용할 수 있습니다. 아래는 기본 단축키이며, 설정의 “단축키”에서 변경할 수 있습니다.

- 화면 색상 가져오기: `Ctrl+Alt+I`
- 창을 숨기고 화면 색상 가져오기: `Ctrl+Alt+Shift+I`
- 왼쪽 클릭으로 확정하고, Esc·오른쪽 클릭·포커스 상실 시 취소합니다.

모든 모니터를 한 번만 캡처하고 정지 이미지를 오버레이 창에 표시합니다. 확대경 중앙의 픽셀 색상을 가져옵니다. 캡처 이미지는 메모리에만 보관하며 종료 시 폐기합니다. 파일을 저장하거나 통신하지 않습니다. 창을 숨긴 경우 확정·취소·캡처 실패 중 어느 경우에도 다시 표시합니다. 그리는 동안에는 시작할 수 없습니다.

고 DPI에서는 캡처 중인 스레드를 Per-Monitor V2로 전환해 캡처·표시·커서 위치를 물리 픽셀 기준으로 일치시킵니다. 원래 DPI 상태는 종료 시 복원합니다. 왼쪽·위쪽 모니터의 음수 좌표를 포함한 가상 데스크톱을 처리하며, 확대경은 커서가 있는 모니터의 경계 안에 배치합니다. 모니터 구성이 변경되면 취소합니다.

GDI의 8 bit 출력을 sRGB로 간주해 페인트 색상에 넣습니다. HDR 부동소수점 값이나 모니터별 ICC 프로파일을 보존하는 색 측정 기능은 아닙니다. HDR 데스크톱에서는 OS가 SDR로 변환한 결과를 사용하므로 화면에 보이는 색과의 일치를 보장하지 않습니다. 보호된 영상 등 GDI에서 읽을 수 없는 화면도 지원하지 않습니다.

스칼라 채널과 마스크에서는 가져온 sRGB 값을 `0.2126 R + 0.7152 G + 0.0722 B`의 회색으로 변환합니다. 문서·Undo·저장 형식은 변경하지 않습니다. 캡처 이미지는 최대 128 MiB이며 캡처용 DIB를 합쳐 최대 256 MiB로 제한합니다. 이를 초과하는 구성은 이유를 표시하고 거부합니다.

Linux의 X11·Wayland에서는 이 기능의 진입점을 표시하지 않습니다.
