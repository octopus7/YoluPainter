# 색상 세트

색상 세트, 사용한 색상 기록(최대 64색), 네 모서리에서 만드는 중간색은 개인 설정입니다. 문서 저장과 Undo에는 포함되지 않습니다. 기본 16색은 자체적으로 선정한 색상입니다.

저장 위치는 앱 설정 폴더의 `colorsets/`입니다. 각 세트는 내부 ID(16자리 소문자 16진수)를 이름으로 하는 `.ycolors` 파일입니다. 이름을 파일 경로로 사용하지 않습니다. 변경 사항은 임시 파일에 기록하고 동기화한 뒤 파일을 교체하여 확정합니다. 기록에 실패하면 세트 편집도 확정하지 않습니다. 삭제 시 선택한 세트의 파일만 삭제하며 마지막 세트는 남겨 둡니다.

내부 형식은 빅 엔디언입니다.

| 항목 | 내용 |
| --- | --- |
| 식별자 | 4바이트 `YCS\0` |
| 버전 | u16, 현재 1 |
| 세트 이름 | u16 바이트 길이와 UTF-8 |
| 색상 수 | u16 |
| 각 색상 | 이름(같은 길이 접두사가 붙은 UTF-8), RGBA 각각 f32 |

RGBA는 straight, RGB는 sRGB 인코딩 값이며 각 성분은 유한한 0~1입니다. 투명 픽셀의 RGB와 f32 값을 그대로 저장합니다. 색상 이름과 세트 이름은 최대 256바이트이며 제어 문자는 허용하지 않습니다. 파일은 최대 2 MiB, 세트당 4096색, 128세트입니다. 폴더 탐색은 최대 256항목입니다. 탐색 한도에 도달하거나 탐색에 실패하면 기록을 중단하여 기존 파일을 보호합니다.

`state.conf`도 같은 바이너리 형식을 사용합니다. 세트 이름 필드에는 선택한 ID의 10진수 표기를 저장하며, 처음 4색은 왼쪽 위·오른쪽 위·왼쪽 아래·오른쪽 아래, 그 뒤는 최근 사용 순서의 기록입니다. 기록과 네 모서리는 변경 시 저장합니다. 저장에 실패하면 알리고 다음 변경 시 다시 시도합니다. 손상된 state.conf는 자동으로 덮어쓰지 않습니다. 읽을 수 없는 세트는 이유를 알리고 그대로 두며, 읽을 수 있는 세트만 사용합니다.

중간색은 7×7입니다. 각 성분을 sRGB 인코딩 값 그대로 쌍선형 보간합니다. 알파도 독립적으로 선형 보간하며, 프리멀티플라이 또는 선형광 변환은 하지 않습니다.

GPL은 [GIMP 공개 사양](https://developer.gimp.org/core/standards/gpl/)의 구형 형식과 이름이 있는 형식을 읽고 RGB 8비트로 내보냅니다. 저장된 부동소수점 값은 가장 가까운 8비트 값으로 반올림합니다. GPL에는 투명도가 없으므로 투명색이 포함된 내보내기는 이유를 표시하고 거부합니다. 열 수는 검증하지만 표시할 때는 현재 영역 너비에 맞춰 다시 배치합니다.

ACO는 [Adobe 공개 사양](https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/#ColorSwatches)에 따라 v1, v2, v1 뒤에 이어지는 v2를 읽습니다. RGB·HSB·회색조를 지원합니다. CMYK·Lab·별색은 색상 관리 없는 변환을 피하기 위해 색 공간 번호를 표시하고 거부합니다. 목록이 2개 있으면 색상이 일치하는지 확인하고 v2의 UTF-16 이름을 사용합니다. 잘림, 범위 초과, 문자 인코딩 오류, 잉여 데이터, 한도 초과는 세트 전체를 거부하며 일부만 가져오지 않습니다.

`.ylp`·브러시·Unity 문서 형식은 바뀌지 않습니다. 이전 버전은 이 설정 폴더를 사용하지 않습니다.
