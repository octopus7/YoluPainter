# 아이콘 제3자 고지

흰색 48 px PNG입니다. 0.4.x까지의 Unity 브리지에서 복사한 것과 같은 방법으로 SVG를 흰색으로 바꿔 렌더링한 것을 포함합니다.
Fluent는 [Microsoft Fluent UI System Icons](https://github.com/microsoft/fluentui-system-icons),
Phosphor는 [Phosphor Icons](https://github.com/phosphor-icons/core)의 MIT 라이선스입니다. 원문은 뒷부분에 보존합니다.
원본 SVG를 가져온 커밋은 기록되어 있지 않으므로 버전을 추정하지 않습니다. 검토한 PNG의 SHA-256은 `tools/licenses-reviewed.json`에 고정합니다.

`tools/`의 일반 아이콘은 regular, `_selected`는 Fluent의 filled·Phosphor의 fill입니다 (사각형과 타원 선택은 bold, 다각형은 일반 아이콘과 같은 regular).
나머지는 regular입니다 (`lock_filled`만 filled). `arrow_maximize`·`arrow_minimize`·`copy_add`는 독립 실행형 앱에서 추가했습니다. `snap_ruler`·`snap_special`은 regular 아이콘에 bold 자석을 겹친 것입니다.
다각형 선택의 일반·선택 상태 이미지 2장은 0.4.x까지의 Unity 브리지에 있는 `uv_wireframe.png` (Phosphor polygon regular)와 바이트가 일치합니다.

`tools/liquify`와 `tools/liquify_selected`는 기존 Fluent UI `ink_stroke` PNG를 변경 없이 재사용합니다.

선택 도구에 추가한 아이콘 (같은 처리 방식이며 별도 표기가 없으면 Fluent regular): `shape_union` (shape_union), `shape_subtract`
(shape_subtract), `shape_intersect` (shape_intersect), `edit` (edit), `quick_mask` (shape_organic), 선택 영역 펜 도구 아이콘
`tools/select-pen` (Phosphor highlighter regular) 및 `tools/select-pen_selected` (Phosphor highlighter fill). 사각형 선택 도구 아이콘
`tools/select-rectangle`과 `tools/select-rectangle_selected`는 Phosphor selection의 regular 및 bold입니다.

`uv_wireframe`은 Unity 패키지에서 변경 없이 복사했습니다: Phosphor `polygon` (MIT).

`local_fire_department`는 Unity 패키지에서 변경 없이 복사했습니다: Fluent UI `fire` regular (MIT). 메시 맵 베이크 버튼에 사용합니다.

`window_minimize`·`window_maximize`·`window_restore`는 Windows에서 독립 실행형 앱의 창 버튼에 사용합니다 (Fluent regular, 닫기 버튼은 기존 `close`). 다른 아이콘과 같은 절차로 흰색 48 px로 렌더링했습니다.

`error_circle` (로그 패널의 오류 표시 및 오류만 표시 전환)과 `document_copy` (모두 복사 버튼)는 Fluent regular이며, 다른 아이콘과 같은 절차로 흰색 48 px로 렌더링했습니다.

`record`·`stop`·`play` (액션 패널의 기록 시작·중지, 액션 재생)는 Fluent regular이며, 다른 아이콘과 같은 절차로 흰색 48 px로 렌더링했습니다.

`more_horizontal` (선택 도구의 도구 속성에 있는 모든 모드 버튼)은 Fluent regular이며, 다른 아이콘과 같은 절차로 흰색 48 px로 렌더링했습니다.
