# 그라데이션 맵과 그라데이션 세트

보정 레이어·필터의 “그라데이션 맵”은 원래 색의 밝기 (휘도)를 그라데이션 (램프)의 위치에 대응시켜 색을 바꿉니다. 채우기 레이어의 그라데이션
(그라데이션 데칼 등)도 같은 램프 입력란을 사용합니다.

<a id="ランプの欄"></a>

## 램프 입력란

위에서부터 다음 순서로 배치됩니다. 좁은 패널에서는 버튼과 미리보기가 다음 줄로 넘어갑니다.

| 항목 | 내용 |
|---|---|
| 방향 반전 | 어두운 곳과 밝은 곳의 색을 맞바꿉니다 (그라데이션 맵 전용). |
| 색상 혼합 모드·휘도 보정 | 인접한 색상 분기점 사이의 혼합 방식입니다 (그라데이션 맵 전용. 아래 “색상 혼합” 참고). |
| 그라데이션 세트 | 그룹 버튼, 미리보기 목록, 추가·이름 바꾸기·삭제 버튼입니다. 미리보기를 누르면 해당 그라데이션을 적용합니다. |
| 분기점 편집 | 위쪽 행은 불투명도 분기점, 아래쪽 행은 색상 분기점, 작은 마름모는 중간점입니다. 빈 곳을 누르면 추가하고, 드래그해 이동하며, 오른쪽 클릭하거나 행 밖으로 끌어 놓으면 삭제합니다 (2개는 유지). Esc로 드래그를 취소합니다. |
| 선택한 분기점 | 이전·다음 분기점으로 이동하는 버튼과 삭제 버튼, 위치 (0〜100%)입니다. |
| 색상 (색상 분기점) | 주 색상·보조 색상·지정, 색상 미리보기, 스포이트입니다. |
| 불투명도 (불투명도 분기점) | 불투명도입니다 (0%면 원래 색 유지). |
| 중간점·혼합률 곡선 | 해당 분기점에서 다음 분기점까지 구간의 혼합 방식입니다. |
| 값 곡선 | 램프 전체의 입력을 변형하는 방식입니다 (채우기 그라데이션 전용). |

<a id="色の選び方"></a>

### 색상 선택

- 색상 분기점을 **더블 클릭**하거나 색상 미리보기를 누르면 색상 창 (색조 원과 내부 사각형·16진수 입력란·페인트 색상 적용 버튼·현재 색상 세트의 색)이 열립니다.
  다른 색상 입력란 (채우기 레이어의 값·lilToon 색상 등)과 같은 창이며, 창은 1개입니다. 드래그·입력은 즉시 색상에 반영됩니다. 원·사각형 드래그는 놓을 때까지,
  16진수·버튼·색상 세트 선택은 조작 1회마다 실행 취소 1회가 됩니다. 페인트 색상은 바뀌지 않습니다.
  제목 표시줄을 드래그해 이동할 수 있으며, 다음에 열 때도 같은 위치에 나타납니다. 창 밖을 눌러도 닫히지 않습니다. 다른 분기점을 선택하면 창을 유지한 채 해당 분기점의 색을 조절합니다.
  Esc를 누르면 창을 열었을 때 (분기점을 바꿨을 때)의 색으로 되돌리고 닫습니다 (되돌린 변경도 실행 취소로 추적할 수 있음). 닫기 버튼은 현재 색을 유지한 채 닫습니다.
  불투명도 분기점을 선택하거나 분기점을 삭제하거나 다른 레이어를 선택하면 닫힙니다.
- **주 색상**·**보조 색상**을 선택하면 분기점의 색을 주 색상·보조 색상 (페인트 색상)으로 설정하며, 페인트 색상을 바꾸면 따라갑니다. 연동 표시는 화면 상태이며 문서에는 포함되지 않습니다.
  분기점마다 1개씩 설정할 수 있고, 여러 분기점이 동시에 연동될 수 있습니다 (0은 주 색상, 마지막은 보조 색상 등). 어느 분기점을 선택했는지와 관계없이 따라갑니다.
  색상 선택이나 스포이트로 해당 분기점의 색을 정하면 그 분기점만 연동을 중지합니다 (**지정**을 눌러도 동일). 그라데이션 세트를 적용하거나 다른 작업 (실행 취소 등)으로 문서의
  분기점 배열이 바뀌면 모두 중지합니다. 분기점 추가·삭제 시 남은 분기점의 표시는 유지됩니다 (삭제한 분기점의 표시만 없어짐).
- **스포이트** (Windows 전용)는 화면 색상을 가져와 선택한 색상 분기점에 넣습니다. 페인트 색상은 바뀌지 않습니다.
- 색상 분기점은 RGB만 보유합니다. 투명도는 불투명도 분기점에서 결정합니다.
- 값 채널 (Roughness 등)에 적용하는 채우기 그라데이션은 색상 대신 값 (0〜1) 입력란을 표시합니다.

<a id="混色"></a>

## 색상 혼합

인접한 색상 분기점 사이의 색을 혼합하는 방식이며 그라데이션 맵의 램프에 있습니다. 입력란 이름은 “색상 혼합 모드”, “휘도 보정”이며,
**수식은 이 앱 자체의 방식**입니다 (다른 앱에서 이름이 같은 모드와 픽셀까지 일치한다고 보장하지 않습니다).

| 색상 혼합 모드 | 수식 |
|---|---|
| 일반 | sRGB 값 (0〜255)을 그대로 선형 보간합니다. 기존 혼합 방식이며 PSD 그라데이션과 같습니다. |
| 선형 | sRGB를 선형 광량으로 되돌려 보간한 다음 sRGB로 변환합니다. 어두운 색끼리 섞어도 지나치게 어두워지지 않습니다. |
| 지각적 | 선형 광량에서 Oklab (Björn Ottosson)으로 변환해 L·a·b를 보간한 뒤 되돌립니다. 색이 탁해지는 것을 줄이고 선명하게 혼합합니다. sRGB 범위를 벗어난 색은 각 채널을 0〜1로 제한합니다. |

혼합 가중치는 구간의 중간점 (또는 혼합률 곡선)으로 결정됩니다. 분기점 위 (가중치 0과 1)의 색은 어떤 색상 혼합 모드에서도 해당 분기점의 색 자체입니다.

<a id="輝度の補正"></a>

### 휘도 보정

지각적 모드에서만 사용할 수 있는 5단계 (없음·낮음·중간·높음·최고)이며, 강할수록 혼합한 색이 밝아집니다. 양 끝 채도를 혼합한 값에 비해 혼합 결과의 채도가 감소한 양
(ΔC = (1−t)·C0 + t·C1 − C. C는 Oklab a·b의 길이, t는 가중치)에 비례해 Oklab 밝기 L을 높입니다.

`L' = min(1, L + k・ΔC)`, `k`는 단계별로 0·0.25·0.5·0.75·1입니다.

보색 사이의 중앙처럼 채도가 떨어지는 곳일수록 밝아지며, 분기점 위나 채도가 감소하지 않는 혼합 (같은 색조끼리)에서는 바뀌지 않습니다. 기본값은 “높음”입니다.

<a id="混合率曲線"></a>

## 혼합률 곡선

색상 분기점에서 다음 분기점까지 각 구간의 혼합 방식을 곡선으로 정할 수 있습니다 (해당 분기점의 “혼합률 곡선” 확인란). 가로는 2개 분기점 사이의 위치, 세로는 왼쪽 분기점의 색 (아래)에서
오른쪽 분기점의 색 (위)으로 섞이는 정도입니다.

- 곡선을 처음 사용할 때는 현재 중간점과 같은 방향의 곡선으로 시작합니다 ((0,0)·(중간점,0.5)·(1,1)을 통과). 곡선을 사용하는 구간에서는 중간점을 사용하지 않습니다 (해제하면 중간점이 돌아오며 중간점 값은 삭제되지 않음).
- 점은 최대 16개입니다. 빈 곳을 누르면 추가하고, 드래그해 이동하며, 오른쪽 클릭하거나 테두리 밖으로 끌어 놓으면 삭제합니다 (양 끝점은 가로로 움직일 수 없음).
- 곡선 양 끝의 높이가 0과 1이 아니면 분기점 위에서 색이 급격히 바뀝니다.
- 분기점을 추가하면 곡선이 있는 구간이 해당 분기점에서 좌우로 나뉩니다 (샘플링해 재구성하므로 외관은 거의 유지됨). 분기점을 삭제하면 양옆 구간이 1개로 합쳐지고 곡선이 없는 상태로 돌아갑니다.
  위치·색상을 바꿔도 곡선은 유지됩니다.

“값 곡선” (채우기 그라데이션에 있으며 입력을 램프 위치로 변형하는 방식)과는 별개로, 혼합률 곡선은 구간 내부의 혼합 방식만 정합니다. 평가 순서는
입력 → 값 곡선 → 구간 결정 → 구간 가중치 (혼합률 곡선이 있으면 사용하고, 없으면 중간점) → 색상 혼합 모드입니다.

<a id="グラデーションセット"></a>

## 그라데이션 세트

램프 미리보기 목록이며 그룹별로 배치됩니다. 기본 제공 그룹은 기본·음영·색감·하늘과 빛·특수이며, 마지막 “사용자”는 자신의 그라데이션 그룹입니다.

- 미리보기를 누르면 해당 그라데이션을 적용합니다. 세트가 보유하는 것은 분기점 배열·혼합률 곡선·값 곡선이며, **색상 혼합 모드와 휘도 보정은 현재 값을 유지합니다**. 색상 혼합을 보유할 수 없는 채우기 그라데이션에 적용할 때는
  혼합률 곡선을 제거합니다. 값 곡선 입력란이 없는 그라데이션 맵에 적용할 때는 값 곡선을 직선으로 만듭니다 (보이지도 수정할 수도 없는 곡선이 들어가지 않도록 함). 채우기 그라데이션에는 값 곡선도 적용합니다.
- “기본”의 “주 색상→보조 색상”, “주 색상→투명”, “흰색→검은색”은 당시의 페인트 색상으로 만듭니다.
- 추가 버튼은 현재 램프를 “사용자” 그룹에 추가합니다 (이름은 “그라데이션 N”). 이름 바꾸기·삭제 버튼은 “사용자” 그룹에서 선택한 미리보기에만 적용됩니다. 기본 제공 항목은 변경할 수 없습니다.
- 사용자 그라데이션은 최대 128개입니다.

<a id="保存"></a>

### 저장

설정 폴더의 `gradients/user.ylgrad`에 저장합니다 (보조 도구의 `.ylsubtool`과 같은 방식). 1번째 줄은 `yolupainter-gradients 1`이고 이후에는 `key=value` 행이 이어집니다
(UTF-8, 최대 8 MiB, 빈 행은 건너뜀).

```text
yolupainter-gradients 1
ramp.1.name=夕空
ramp.1.colors=0:1a2040:0.5;0.5:cc5060:0.3;1:ffd080:0.5
ramp.1.opacities=0:1:0.5;1:1:0.5
ramp.1.curve=0:0;0.5:0.6;1:1
ramp.1.segment.0=0:0;0.3:0.8;1:1
```

- `colors`는 `位置:RRGGBB:中点`을 `;`로 연결합니다. `opacities`는 `位置:不透明度:中点`입니다. `curve` (값 곡선. 없으면 직선)와 `segment.<区間>` (해당 구간의 혼합률 곡선. 없으면 중간점)은 `x:y`의 배열입니다.
- 번호는 1부터 시작하며 세트는 번호순입니다. 알 수 없는 항목·중복 항목·범위를 벗어난 값·이름이나 색상이 없는 항목·너무 많은 항목이 있는 파일은 파일 전체를 불러오지 않고 이유를 알립니다
  (해당 파일에 저장하지 않습니다. 더 새로운 버전의 파일도 변경하지 않습니다).
- 기록할 때는 임시 파일에 작성하고 다시 읽어 확인한 뒤 마지막 1회의 교체로 확정합니다 (도중에 충돌해도 이전 버전이 남음). 저장할 수 없다면 추가·이름 바꾸기·삭제를 수행하지 않고 이유를 알립니다. 시작 시 읽지 못한 파일이 남아 있는 동안에도 같습니다
  (덮어쓰지 않으므로 목록에만 남았다가 재시작하면 사라지는 상태를 만들지 않습니다). 해당 파일을 수정하거나 옮기고 앱을 다시 열면 다시 추가할 수 있습니다.

<a id="保存と-psd"></a>

## 저장과 PSD

- `.ylp`에서는 색상 혼합 (일반 이외의 혼합 모드·혼합률 곡선)을 사용하는 그라데이션 맵이 있는 문서만 정본 버전 25가 됩니다. 사용하지 않는 문서는 기존 버전을 유지합니다.
  0.4.x까지의 Unity 브리지는 버전 22 이상 문서를 열 수 없습니다. 형식의 세부 사항은 [YLP_FORMAT.md](YLP_FORMAT.md)의 “색상 보정 필드”에 있습니다.
- 채우기 그라데이션의 램프는 0.4.x까지의 Unity 브리지도 읽을 수 있는 배열 (정본 버전 21)로 저장하므로 색상 혼합·혼합률 곡선을 보유할 수 없습니다 (입력란에도 표시하지 않음).
- PSD 보정 레이어의 그라데이션은 sRGB 값의 선형 보간 (중간점 포함)만 보유합니다. 색상 혼합이나 혼합률 곡선이 있는 그라데이션 맵은 그대로 기록할 수 없습니다.
  “베이크하여 저장”에서는 휘도의 256개 지점에서 원래 색을 확인해 정지점 배열 (색상·불투명도 각각 최대 32개, 위치는 1/4096)로 펼칩니다. 근사치이므로 펼친 정지점 수와
  내보낸 합성 결과의 최대 차이를 저장 전 “PSD 내보내기 확인” 창에 레이어 이름과 함께 표시합니다. 펼친 이유는 실제 사용한 기능만 표시합니다 (값 곡선만이면 “곡선”, 혼합만이면 “색상 혼합”, 둘 다면 “곡선·색상 혼합”). PSD를 다시 열어도 색상 혼합 모드는 복원되지 않습니다.
