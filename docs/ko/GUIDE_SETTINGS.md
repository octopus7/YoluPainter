# 설정


“편집 → 설정…”(`Ctrl+,`) 화면의 항목을 구분별로 설명합니다. 왼쪽에 구분이 나열되며 누르면 오른쪽에 해당 구분의 항목이 표시됩니다. 구분은 “일반”·“펜”·“단축키”·“표시”·“메모리”·“처리”·“3D 뷰”·“파일”·“Live Link와 외부 조작”·“업데이트”입니다(“업데이트”는 업데이트 확인 기능이 있는 버전에만 표시). 이전에 연 구분을 기억하여 다음에도 같은 구분부터 시작합니다. 오른쪽 영역은 구분별로 스크롤됩니다. 제목을 드래그하여 창을 움직일 수 있습니다.

위의 “설정 찾기” 필드에 문자를 입력하면 항목 이름(화면 언어의 문자)에 맞는 항목만 모든 구분에서 찾아 구분별로 묶어 오른쪽에 나열합니다. 왼쪽에서는 일치하는 항목이 있는 구분이 강조됩니다. 구분 이름이 일치하면 해당 구분의 모든 항목이 나열됩니다. 구분을 누르면 검색 필드가 비워지고 해당 구분이 열립니다. `Esc`는 검색 필드에 문자가 있으면 비우고 없으면 창을 닫습니다. 팝업·포트 번호나 표의 검색 필드 같은 입력 필드·키 할당 대기·색 창이 사용하는 `Esc`는 설정 창을 닫지 않습니다. 닫으면 검색 필드가 비워지며 다음에 열면 이전 구분부터 시작합니다. 왼쪽 구분이 열 안에 들어가지 않는 낮은 화면에서는 열을 스크롤합니다.

값은 설정 폴더의 `YoluPainter/settings.conf`에 기본값이 아닌 것만 기록됩니다(Windows는 `%APPDATA%`, Linux는 `~/.config`). 잘못된 값은 해당 항목만 기본값으로 되돌리고 이유를 알립니다.

### 언어

설정에 아직 언어가 없으면(최초 실행 등) OS 언어로 시작합니다. 한국어이면 한국어, 일본어이면 일본어, 그 외에는 영어입니다. OS 언어는 Windows에서는 표시 언어, Linux에서는 `LC_ALL`·`LC_MESSAGES`·`LANG`으로 확인합니다. 환경 변수 `YOLUPAINTER_LANG`(`ja`·`en`·`ko`)이 있으면 그것이 우선합니다. 언어를 선택하여 설정이 저장된 뒤에는 항상 저장한 언어로 시작합니다.

## 펜

| 항목 | 내용 |
|---|---|
| 태블릿 필압(시험 기능)(Mac) | Wacom·XP-Pen 등의 드라이버가 macOS 표준 이벤트로 보내는 필압·기울기·지우개 끝·사이드 버튼을 읽습니다. 기본값은 켜짐입니다. 끄면 펜이 마우스처럼 그립니다. 전환은 즉시 적용됩니다 |
| 펜 입력(Windows) | 펜의 필압·기울기·회전·지우개 끝·사이드 버튼을 읽는 방식입니다. “Windows Ink”(기본값) 또는 “WinTab”(Wacom 등 태블릿 드라이버가 제공하는 입력)입니다. 전환은 즉시 적용되며 별도 창에도 같은 선택이 적용됩니다. 접촉 중이던 펜은 전환 시 놓은 것으로 처리됩니다 |
| 필압 조정 | 펜 필압을 브러시에 전달하기 전에 보정합니다. 곡선·하한·상한·그리기 영역과 “자동 조정”·“지우기”·“되돌리기”·“기본값” 버튼이 나열됩니다 |

WinTab을 선택해도 WinTab 드라이버(`Wintab32.dll`)가 없거나 드라이버가 응답하지 않거나 태블릿이 연결되지 않았거나 WinTab을 열 수 없으면 Windows Ink로 읽고 이유를 한 번만 알립니다. 선택은 WinTab을 유지하며 창을 앞으로 가져올 때 다시 시도합니다. 드라이버 마우스 모드 등으로 WinTab 위치가 커서와 맞지 않으면 점 위치를 커서 위치로 합니다(필압 등은 WinTab에서 읽음).

<a id="筆圧の調整"></a>

### 필압 조정

펜 필압이 너무 강하거나 약할 때 펜 필압(곡선의 왼쪽에서 오른쪽)이 브러시에 전달할 필압(아래에서 위)으로 바뀌는 관계를 정합니다. 마우스 필압은 1을 유지하며 조정을 거치지 않습니다.

- 곡선: 빈 곳을 누르면 점을 추가하고 드래그로 움직이며 오른쪽 클릭으로 지웁니다. `Esc`로 드래그를 취소합니다. 옅은 막대는 그린 선의 필압 분포입니다.
- “하한”·“상한”: 하한 이하 필압을 0으로, 상한 이상 필압을 1로 만듭니다.
- 그리기 영역: 평소 강도로 선을 몇 개 그립니다. 그린 선은 영역 안에만 유지하며 문서에 들어가지 않습니다. “펜” 구분을 떠나거나 설정 창을 닫으면 버립니다.
- “자동 조정”: 그린 선의 필압 분포에서 하한·상한·곡선을 결정합니다. 선이 부족하거나 필압이 거의 일정하면 결정하지 않고 짧은 이유를 표시합니다. “지우기”는 그린 선을 지웁니다. “되돌리기”는 “펜” 구분을 열었을 때의 조정으로, “기본값”은 하한 0%·상한 100%·직선으로 돌아갑니다.

결정한 조정은 설정 파일에 들어가며(문서나 브러시에는 들어가지 않음) 2D 캔버스와 3D 뷰 모두에 적용됩니다. 손가락이나 펜이 터치로 압력을 보내는 경우에도 같은 조정을 거칩니다([GUIDE_PAINT.md](GUIDE_PAINT.md)).

## 단축키

키와 마우스 조합·파이 메뉴를 확인하고 바꿉니다. 왼쪽에서 “단축키”를 누르면 그 아래에 구분(어디서나·시점/페인트/편집/포즈/숨기기/진행 중 조작/파이 메뉴)이 나열되고 오른쪽에 표(작업 이름·키·마우스)가 표시됩니다. 표 위에는 이름 검색 필드와 “키로 찾기”(두 기능은 표 안만 필터링), 아래에는 “기본값으로 되돌리기”·“내보내기…”·“불러오기…”가 있습니다. 사용법은 [GUIDE_KEYS.md](GUIDE_KEYS.md)의 “단축키 바꾸기”에 있습니다.

## 표시

| 항목 | 내용 |
|---|---|
| 표시 합성 | 2D 캔버스에 표시할 레이어 합성을 수행할 위치. “자동”·“GPU”·“CPU” |
| 수직 동기화 | 화면 갱신이 모니터 수직 동기화까지 기다릴지 정합니다. 기본값은 꺼짐(기다리지 않음)입니다. 켜면 화면 위아래 어긋남(테어링)이 생기지 않는 대신 펜으로 그린 선이 화면에 나올 때까지의 지연이 늘어납니다. 다음 실행부터 적용되며 바꾼 뒤에는 “재시작 시 반영”이 표시됩니다 |
| GPU 메모리 | 3D 뷰·캔버스 GPU 합성·에셋 썸네일에 사용할 수 있는 GPU 메모리 양. “자동”·“낮음”·“표준”·“높음” |
| 베이크에서 RT 코어 사용 | 메시 맵 베이크에 GPU RT 코어(하드웨어 레이 트레이싱)를 사용할지 정합니다. 기본값은 켜짐입니다. 지원하지 않는 GPU 또는 같은 광선을 RT 코어를 사용하지 않는 경로로 계산한 결과와 맞지 않으면 설정과 관계없이 RT 코어 없이 베이크합니다. 드라이버가 멈추는 PC에서는 꺼 주세요. 끄면 항상 RT 코어를 사용하지 않는 경로로 베이크합니다. 화면 렌더링 방식은 바뀌지 않습니다 |

**표시 합성**은 화면에 표시하는 합성만 대상으로 합니다. 저장·내보내기·3D 뷰 값의 합성은 무엇을 선택해도 CPU입니다(GPU 픽셀은 여러 단계 문서에서도 CPU 결과와 2 이내의 차이가 날 수 있음. 표시만의 차이). 자동은 사용 가능한 GPU가 있으면 GPU, 소프트웨어 GPU에서는 CPU로 합성합니다. 조정 레이어·독립 그룹·노멀 채널·효과가 있는 문서도 GPU로 합성합니다(효과 계산은 CPU에서 수행하고 완성한 픽셀을 GPU에 업로드). 그린 타일이 “GPU 메모리”에서 배분한 캔버스 예산(표준 512 MiB)을 넘는 문서, GPU 텍스처 상한을 넘는 크기, 그룹 중첩이 너무 깊은 문서는 CPU로 전환합니다. 환경 변수 `YOLUPAINTER_CANVAS`(`auto`·`gpu`·`cpu`)로 고정할 수도 있습니다.

**수직 동기화**가 꺼져 있는 동안(기본값)은 화면 표시 호출이 수직 동기화를 기다리지 않습니다. 펜 입력부터 선이 화면에 나올 때까지의 지연이 줄어드는 대신 화면 위아래 어긋남(테어링)이 생길 수 있습니다. 사용하는 그래픽 환경에 기다리지 않는 표시 방식이 없으면 기다리는 방식으로 동작합니다. 다시 그리기 요청이 계속되어도 CPU와 GPU를 모두 소모하지 않도록 앱이 다시 그리기 간격에 하한을 둡니다(입력이 있으면 1/240초보다 짧은 간격으로 다시 그리지 않음. 다시 그리기 요청만 있으면 창이 있는 모니터의 새로 고침 한 주기보다 짧은 간격으로 다시 그리지 않음. 새로 고침 빈도는 Windows에서만 읽고 60~240 Hz로 제한하며 읽지 못하면 120 Hz). 켜져 있는 동안에는 수직 동기화가 간격을 결정하므로 하한을 두지 않습니다. 창을 만들 때 결정되므로 전환은 다음 실행부터 적용됩니다.

**베이크에서 RT 코어 사용**은 환경 변수 `YOLUPAINTER_BAKE_RAY_QUERY=0`(`false`·`off`·`no`도 같음)으로도 끌 수 있습니다(환경 변수가 꺼짐이면 설정이 켜져 있어도 꺼진 상태를 유지하며 이 행은 누를 수 없음). 바꾸면 다음 확인·베이크 때 GPU 디바이스를 다시 만듭니다.

**GPU 메모리**가 부족하면 3D 뷰가 다른 텍스처 세트 이미지를 줄이고 현재 세트 이미지를 작게 표시합니다(텍스처와 내보내기는 바뀌지 않음). “자동”은 GPU 메모리 양을 알 수 있을 때만 그에 맞춥니다(적으면 낮음, 많으면 표준 양을 늘림). 알 수 없으면 표준입니다. 행 오른쪽의 “자세히”를 열면 “합계” 슬라이더가 나타나며 3D 이미지(3D 뷰의 선택 영역 가장자리·오버레이 포함)·캔버스 합성·에셋 썸네일에 4 : 4 : 1로 배분합니다. 움직이면 단계 선택 대신 양을 직접 지정하는 방식이 됩니다.

## 메모리

| 항목 | 내용 |
|---|---|
| 실행 취소 기록 | 실행 취소 기록에 사용하는 모든 텍스처 세트의 메모리 합계. 초과한 오래된 단계부터 버립니다 |
| 레이어 메모리 | 모든 텍스처 세트의 모든 레이어가 픽셀에 사용하는 메모리 합계 상한. 초과하는 작업은 아무것도 바꾸지 않고 거부합니다 |
| 한 번의 작업 | 스트로크나 채우기 한 번이 되돌리기용으로 보유할 수 있는 메모리. 내보내기 작업에도 사용합니다. 초과하는 작업은 아무것도 바꾸지 않고 중단합니다 |
| 최소 실행 취소 단계 수 | 실행 취소 예산을 넘어도 유지할 최근 단계 수(0~100). 0은 예산을 엄격히 적용합니다 |
| 디스크 캐시 | 아래 “디스크 캐시” 참조 |

3가지 메모리는 “자동” 또는 MiB로 선택합니다. 자동은 물리 메모리에서 결정합니다(레이어 메모리는 절반, 실행 취소 기록은 1/8, 한 번의 작업은 1/16. 각각 하한과 상한 있음). 모두 사용할 수 있는 양의 상한이며 미리 할당하지 않습니다. 실행 취소 기록과 레이어 메모리는 프로젝트 전체 합계입니다. 한 번의 작업과 최소 실행 취소 단계 수는 텍스처 세트별입니다. `.ylp`를 열 때 픽셀은 레이어 메모리 설정(256 MiB 미만으로 내려가지 않음)까지 읽습니다.

<a id="ディスクキャッシュ"></a>

### 디스크 캐시

“디스크 캐시”는 메모리 상한(레이어 메모리와 실행 취소 기록 예산의 합)을 넘은 타일을 사용하지 않는 것부터 디스크로 옮겨 큰 문서에서도 계속 그릴 수 있게 합니다. 기본값은 켜짐입니다. 끄면 예산을 넘는 작업은 거부합니다. 디스크에서 다시 읽을 수 없는 타일이 생기면 해당 텍스처 세트를 읽기 전용으로 바꾸고 알립니다. 자세한 내용은 [GUIDE_FILES.md](GUIDE_FILES.md)에 있습니다.

행 오른쪽의 “자세히”를 열면 다음 2가지가 표시됩니다.

- “캐시 상한”: 사용할 디스크 양. 자동은 64 GiB와 저장 위치 여유 공간 절반 중 작은 값입니다. 가득 차면 초과 작업을 거부합니다.
- “캐시 위치”: 캐시 파일을 둘 폴더를 “선택…”으로 고릅니다(빠른 드라이브일수록 옮긴 타일을 복원하는 속도가 빠름). “기본값으로 되돌리기”는 OS 임시 폴더로 돌아갑니다.

| 회전 중심 | 3D 뷰를 회전할 때의 중심. “화면 중심”·“표면 위치(자동 깊이)”·“모델 중심”·“텍스처 세트 중심” |

| 축 방향에서 정투영 | 축 시점을 선택하거나 스냅 회전으로 축 시점으로 전환하면 정투영으로 하고, 회전하여 축에서 벗어나면 원근으로 돌아갑니다. 기본값은 켜짐입니다([GUIDE_3D.md](GUIDE_3D.md)의 “축 시점과 정투영”) |
| UV 와이어프레임 | 색 견본 2개. UV 와이어프레임 색과 “겹친 UV” 색입니다. 누르면 색 창이 열리며 색과 불투명도를 정합니다 |

회전과 줌 중심은 3D 뷰 표시 설정의 “시점”과 같은 값입니다. 어느 쪽에서 바꿔도 같은 설정이 변경됩니다([GUIDE_3D.md](GUIDE_3D.md)).

<a id="外からの操作mcp"></a>

### 외부 조작(MCP)

“외부 조작 수신”을 켠 동안만 AI 어시스턴트(MCP)나 명령줄의 조작을 `http://127.0.0.1:<番号>/mcp`에서 기다립니다. 기본값은 꺼짐입니다. 켜면 “포트 번호” 행이 표시됩니다(기본 17347, 1024~65535). 바꾸면 연결하는 쪽의 번호도 맞춰야 합니다. 상태 바 오른쪽 끝에 작은 원이 표시되어 대기 중·연결됨·수신 불가 상태를 색으로 구분할 수 있습니다(도구 설명에 URL이나 이유 표시).

- 이 PC 내부에서만 통신합니다. 비밀번호가 없으므로 켜 둔 동안에는 이 PC의 다른 계정 프로그램도 연결할 수 있습니다.
- 명령 하나가 화면의 실행 취소 한 단계가 됩니다. 그리는 도중, 저장 도중, 읽기 전용 텍스처 세트의 편집은 이유와 함께 거부합니다. 문서를 바꾸어 여는 명령은 받지 않습니다.
- 끄면 수신 대기를 중단하고 연결도 닫습니다.

연결 방법은 [MCP.md](MCP.md), 명령줄은 [CLI.md](CLI.md)에 있습니다.

## 설정 화면 밖에 있는 설정

- **복구**: “파일 → 복구…” 창에서 기록 간격·유지할 세대 수·사용할 디스크 양을 정합니다([RECOVERY.md](RECOVERY.md)).
- **선택 영역 버튼 바**: “선택 영역” 메뉴의 “선택 영역 버튼 바 표시”([GUIDE_SELECT.md](GUIDE_SELECT.md)).
- **패널 배치**: 설정 폴더의 `YoluPainter/layout.json`에 저장합니다([GUIDE_START.md](GUIDE_START.md)).
- **키·마우스 할당과 파이 메뉴**: “단축키” 구분에서 바꾸며 설정 폴더의 `YoluPainter/keymap.json`에 기본값과 달라진 부분만 저장합니다. 도구 키 동작 방식은 `tool_keys`에 도구 선택 작업 ID와 동작 방식(`hold`는 누르는 동안만, `tap_or_hold`는 짧게 누르면 전환·길게 누르면 누르는 동안만)으로 기록합니다(예: `"tool_keys": { "tool.eraser": "hold" }`. 기본값인 누르면 전환은 기록하지 않음)([GUIDE_KEYS.md](GUIDE_KEYS.md)).
