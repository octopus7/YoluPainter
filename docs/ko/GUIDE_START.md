# 시작하기

이 페이지에서는 화면 구성, 문서(프로젝트) 만들기와 열기, 첫 스트로크, 2D 화면 이동, 패널 배치를 설명합니다. 앱을 시작하면 2048 × 2048 캔버스와 테스트용 큐브가 열립니다. 초기 레이어는 맨 아래에 흰색 단색 채우기 레이어(「채우기 1」), 그 위에 빈 「레이어 1」이 있으며 빈 레이어가 선택된 상태로 시작합니다.

<a id="画面の見方"></a>

## 화면 구성

| 위치 | 내용 |
|---|---|
| 메뉴 모음(맨 위) | 파일·편집·레이어·선택 영역·필터·보기·창·도움말이 있습니다. 오른쪽 끝에는 프로젝트 이름(저장하지 않은 변경 사항이 있으면 「•」 표시)과 Live Link 진입점인 Unity 아이콘이 나란히 있습니다 |
| 옵션 모음(그 아래) | 맨 왼쪽에 모드(페인트·편집·포즈·숨김)가 있습니다. 오른쪽에는 선택한 도구에서 자주 사용하는 설정 2~3개가 표시됩니다. 도구 속성과 같은 값입니다 |
| 도구 모음(맨 왼쪽) | 도구 버튼이 있습니다(편집·포즈 모드에서는 선택·이동·회전·크기 조절 4개, 숨김 모드에서는 면 선택·숨기기 버튼). 맨 아래에는 기본색과 보조색이 있습니다 |
| 왼쪽 도킹 영역 | 위에서부터 「보조 도구」(영어 표시는 Tools)·「도구 속성」·「브러시 크기」가 세로로 놓이며 맨 아래에는 「색상」·「색상 세트」가 있습니다 |
| 중앙 | 왼쪽 「3D 뷰」, 오른쪽 「캔버스」(2D)가 나란히 있습니다. 둘 다 탭이므로 겹쳐 놓고 전환할 수도 있습니다 |
| 오른쪽 도킹 영역 | 위에서부터 「텍스처 세트」·「채널」·「에셋」, 「레이어」·「로그」, 「속성」·「머티리얼」·「작업 기록」이 있습니다. 「내비게이터」는 닫혀 있으며 「창」 메뉴에서 열면 「텍스처 세트」 그룹에 들어갑니다(열려 있는 동안 체크가 표시되고 다시 누르면 닫힘. 「액션」도 같음) |
| 상태 표시줄(맨 아래) | 오른쪽 끝에 버전과 빌드(예: `0.7.0 · a1b2c3d`), 메모리 사용량이 표시됩니다. 왼쪽에는 직전 작업 결과가 한 줄 알림으로 나타납니다(아래의 「알림과 로그」) |

「보조 도구」「도구 속성」「브러시 크기」 패널의 내용은 선택한 도구에 따라 바뀝니다. 브러시 선택과 설정은 [GUIDE_PAINT.md](GUIDE_PAINT.md)에 있습니다. 「속성」에는 선택한 레이어의 내용이 표시됩니다([GUIDE_LAYERS.md](GUIDE_LAYERS.md)). 「머티리얼」에는 현재 텍스처 세트의 외관 설정이 표시됩니다([GUIDE_3D.md](GUIDE_3D.md)). 포즈 패널은 본이 있는 모델을 불러오면 나타납니다([GUIDE_3D.md](GUIDE_3D.md)).

## 모드

그리기는 「페인트」 모드에서 합니다. 「편집」「포즈」「숨김」 모드에서는 그리지 않습니다. 2D 캔버스는 보기 전용이 되며(화면 이동·회전·확대와 오른쪽 버튼 스포이트는 사용 가능), 3D 뷰에도 그리지 않습니다. 브러시와 색상 패널은 어두워지고 누를 수 없습니다. 포즈 모드는 본이 있는 모델을 불러왔을 때만 선택할 수 있습니다([GUIDE_3D.md](GUIDE_3D.md)). 편집 모드에서는 3D 뷰의 표시로 채우기 투영·그라데이션 데칼·필터 모양·점·3D 경로·3D 자를 선택하고 `G`·`R`·`S`로 조작합니다. 포즈 모드에서는 같은 키로 선택한 본을 조작합니다([GUIDE_3D.md](GUIDE_3D.md)의 「오브젝트 선택과 이동」). 숨김 모드에서는 3D 뷰별로 UV 아일랜드와 본을 기준으로 면을 숨깁니다([GUIDE_3D.md](GUIDE_3D.md)의 「면 숨기기(숨김 모드)」).

모드는 다음 방법으로 전환합니다. 그리는 중에는 전환할 수 없습니다.

- 옵션 모음 맨 왼쪽의 드롭다운.
- `Ctrl+Tab` 파이 메뉴(포인터 위치에 열림. 키를 누른 채 항목 방향으로 움직였다가 놓거나, 바로 놓고 항목을 클릭. 사용 방법은 [GUIDE_KEYS.md](GUIDE_KEYS.md)).
- 「보기 → 모드」.
- 그리기 도구를 선택하면(「편집」 메뉴의 도구 등) 페인트 모드로, 포즈 패널의 「본」 트리에서 본을 선택하면 포즈 모드로 전환합니다.

## 문서 만들기·열기·저장

<a id="新しいプロジェクトを作る"></a>

### 새 프로젝트 만들기

「파일 → 새 프로젝트…」(`Ctrl+N`)에서 다음 항목을 정하고 「만들기」를 누릅니다.

- 「템플릿」: 「PBR(모든 채널)」·「lilToon(색상·노멀·발광)」·「색상만」. 초기 레이어에서 사용할 채널이 달라집니다. 모든 텍스처 세트는 맨 아래에 흰색 단색(「채우기 1」, Color 채널만), 그 위에 빈 「레이어 1」이 선택된 상태로 시작합니다(Color를 사용하지 않는 템플릿은 흰색 없이 빈 레이어만 둠).
- 「메시」: 「모델 선택…」에서 FBX를 선택하면 모델의 머티리얼마다 텍스처 세트를 만들 수 있습니다. 선택하지 않으면 2D로 그리는 문서가 되며 모델은 나중에 선택할 수 있습니다.
- 「텍스처 세트」: 만들 텍스처 세트의 행입니다. 모델을 선택하면 머티리얼마다 한 행씩 나열됩니다. 행마다 이름·크기(512·1024·2048·4096·8192)·머티리얼을 정합니다. 머티리얼 필드에서 여러 머티리얼을 선택할 수 있으며 다른 행의 머티리얼을 선택하면 그 행에서 이동해 옵니다. 머티리얼이 없어진 행은 생성하지 않습니다.
- 「노멀 맵 형식」과 「생성 후 메시 맵 베이크」.

생성 후 변경은 「파일 → 프로젝트 구성…」에서 합니다. 새 프로젝트와 같은 행으로 텍스처 세트 추가와 삭제, 이름, 할당할 머티리얼(복수 선택 가능), 크기, 모델 교체와 다시 불러오기, 노멀 맵 형식을 수정할 수 있습니다.

<a id="テクスチャセット"></a>

### 텍스처 세트

텍스처 세트는 모델의 머티리얼에 입힐 텍스처입니다. 하나의 텍스처 세트를 여러 머티리얼에 할당하면 해당 머티리얼의 면이 같은 텍스처를 사용합니다. 프로젝트 하나당 최대 64개까지 만들 수 있습니다. 레이어·실행 취소 기록·선택 영역은 텍스처 세트별로 나뉩니다. 「텍스처 세트」 패널에서 세트 전환, 이름 변경(더블 클릭), 세트 추가(현재 세트와 같은 크기와 채널, 흰색 단색과 빈 레이어로 시작), 현재 세트 삭제, 3D 뷰와 Unity에 표시할지 전환(눈 아이콘)할 수 있습니다. 여러 머티리얼을 할당한 세트의 행에는 머티리얼 이름이 나열됩니다. 하나의 텍스처 세트 안에는 레이어 묶음(레이어 세트)을 여러 개 둘 수 있습니다([GUIDE_LAYERS.md](GUIDE_LAYERS.md)의 「레이어 세트」).

### 열기·저장

「파일 → 열기…」(`Ctrl+O`)로 `.ylp`를 엽니다. `.ylp` 파일을 창으로 드래그 앤 드롭해도 열 수 있습니다. 저장하지 않은 변경 사항이 있으면 「저장하지 않은 변경 사항이 있습니다.」라고 묻습니다. 「변경 사항 검토」(기본 선택, `Enter`)는 파일을 열지 않고 앱으로 돌아가며, 「변경 사항 버리기」는 변경 사항을 버리고 파일을 열고, 「취소」(`Esc`)는 중단합니다. 「파일 → 최근 프로젝트 열기」에는 열거나 저장한 `.ylp`가 최근 순서로 최대 10개 나열됩니다(포인터를 올리면 전체 경로 표시, 「목록 지우기」로 삭제 가능, 찾을 수 없는 파일은 열지 않고 목록에서 제외). FBX 파일을 드롭하면 3D 뷰로 불러오며 PSD와 이미지(PNG·JPEG·TGA)는 「파일 가져오기」 창에서 대상을 선택하여 가져옵니다([GUIDE_FILES.md](GUIDE_FILES.md)).

저장은 「저장」(`Ctrl+S`)과 「다른 이름으로 저장…」(`Ctrl+Shift+S`)을 사용합니다. 내보내기·PSD·배포용 저장·복구는 [GUIDE_FILES.md](GUIDE_FILES.md)에 정리되어 있습니다. 0.4.x까지의 Unity 브리지와 `.ylp`를 주고받는 방법은 [UNITY.md](UNITY.md)를 참고하세요.

## 첫 스트로크

1. 색상을 정합니다. 도구 모음 아래쪽의 기본색이나 「색상」 패널에서 선택합니다.
2. 「보조 도구」 패널에서 브러시를 선택합니다(키는 `B`).
3. 「레이어」 패널에서 그릴 레이어를 선택합니다. 새로 만들려면 `Ctrl+Shift+N`을 누릅니다.
4. 「캔버스」 또는 「3D 뷰」에서 왼쪽 버튼으로 드래그합니다.
5. 잘못 그렸다면 `Ctrl+Z`로 실행 취소하고 `Ctrl+Shift+Z`(또는 `Ctrl+Y`)로 다시 실행합니다. 「작업 기록」 패널에서 행을 누르면 그 단계까지 한 번에 되돌아갑니다.
6. `Ctrl+S`로 저장합니다.

## 2D 화면 이동

표시만 이동합니다. 저장되는 이미지는 회전하거나 뒤집히지 않습니다.

| 작업 | 입력 |
|---|---|
| 확대·축소 | 휠 또는 `Ctrl+Space`를 누른 채 왼쪽 버튼 드래그(좌우로 이동하며 누른 점이 중심) |
| 이동 | 가운데 버튼 드래그 또는 `Space`를 누른 채 왼쪽 버튼 드래그 |
| 회전 | `Alt`를 누른 채 왼쪽 버튼 드래그(15° 간격, `Shift`도 누르면 자유 회전). `Shift+R`로 되돌림 |
| 좌우 뒤집기 | `H` |
| 화면에 맞추기 | `Ctrl+0` |

「보기」 메뉴에는 위에서부터 UV 와이어프레임과 겹치는 UV 켜기/끄기([GUIDE_3D.md](GUIDE_3D.md)), 확대, 축소, 화면에 맞추기, (구분선) 화면 왼쪽 회전, 화면 오른쪽 회전, 회전 초기화, 화면 좌우 뒤집기, (구분선) 자에 스냅·특수 자에 스냅·스냅할 특수 자 전환([GUIDE_PAINT.md](GUIDE_PAINT.md)), (구분선) 모드, 3D 뷰에 모델 전체 맞추기가 있습니다. 「내비게이터」 패널에서는 캔버스 전체 축소 이미지를 누르거나 드래그하여 볼 위치를 옮길 수 있습니다(현재 표시 범위가 테두리로 나타남). 「확대율」과 「회전」 슬라이더, 좌우 뒤집기·전체 보기·100%·회전 초기화 버튼도 있습니다. 3D 뷰 조작 방법은 [GUIDE_3D.md](GUIDE_3D.md)에 있습니다.

캔버스 오른쪽 위에는 버튼 두 개가 겹쳐 표시됩니다. 왼쪽 「눈·UV·▽」에서 눈과 UV 글자를 누르면 UV 와이어프레임 표시를 켜거나 끄고, ▽에서 선 색상과 불투명도를 바꿉니다. 오른쪽은 칠할 채널 버튼이며 누르면 「텍스처 세트」「레이어 세트」「칠할 채널」의 3열 목록이 열립니다. 행을 누르면 해당 텍스처 세트·레이어 세트·채널로 전환합니다(채널은 그릴 대상이며, 오른쪽 눈 아이콘은 2D 캔버스에 표시할 채널). 열 제목의 「＋」로 텍스처 세트와 레이어 세트를 추가합니다. 그리는 동안에는 누를 수 없습니다.

## 패널 배치 변경

탭을 드래그하여 다른 탭 그룹에 넣거나 가장자리에 놓아 나란히 배치할 수 있습니다. 캔버스와 3D 뷰를 나란히 두면 둘 다 보면서 그릴 수 있습니다. 배치(탭 그룹·분할·크기·앞에 있는 탭)와 창 크기·위치·최대화 상태는 설정 폴더의 `YoluPainter/layout.json`에 저장하고 다음 실행 시 복원합니다. 구분선이나 탭을 움직이지 않은 동안에는 창 너비를 바꾸면 오른쪽 열 너비도 따라 바뀝니다(전체 너비의 약 19%, 하한 있음). 한 번 움직인 뒤에는 바뀌지 않습니다. 읽을 수 없거나 알 수 없는 탭이 있거나 탭이 빠지거나 중복되는 배치는 기본 배치로 시작합니다. 단, 이전 버전이 저장한 배치에 없는 「도구 속성」「브러시 크기」「머티리얼」은 기존 배치를 버리지 않고 읽을 때 추가합니다(도구 속성과 브러시 크기는 「보조 도구」 그룹 아래에 세로로, 머티리얼은 「속성」 바로 뒤에 배치). 다른 탭의 배치는 바꾸지 않습니다(이전 버전 배치에서는 「에셋」「채널」「내비게이터」도 기존 그룹에 남고 캔버스와 3D 뷰도 이전처럼 하나의 그룹). 0.5.x는 이 3개 탭이 있는 파일을 읽으면 알 수 없는 탭 때문에 기본 배치로 시작합니다. 저장된 위치가 현재 연결된 화면 어디에서도 보이지 않으면 위치는 복원하지 않고 크기만 복원합니다. 화면보다 큰 창은 시작 후 한 번만 화면 안에 맞춥니다. 0.4.x는 별도 창이 있는 이 파일을 읽으면 기본 배치로 시작합니다.

「창」 메뉴에는 패널 목록이 나옵니다. 열린 패널에는 표시가 붙으며 누르면 앞으로 가져옵니다. 닫힌 패널은 엽니다. 「패널 배치 초기화」로 기본 배치로 돌아가며 별도 창은 닫힙니다.

<a id="ui-を隠す"></a>

### UI 숨기기

`Tab`을 누르면 메뉴 모음과 뷰(캔버스와 3D 뷰)만 남기고 도구 모음·옵션 모음·뷰가 아닌 패널·뷰 탭 제목·뷰 내부 버튼을 숨깁니다. 다시 `Tab`을 누르면 복원합니다(키는 「단축키」의 「UI 숨기기/표시」에서 변경 가능). 숨기는 동안에도 상태 표시줄은 보이며 오른쪽에 「UI가 숨겨져 있습니다. Tab 키로 다시 표시합니다.」가 나옵니다. 배치를 바꾸지 않으므로 복원하면 원래 배치와 크기로 돌아갑니다. 별도 창으로 꺼낸 패널은 숨기지 않습니다. 그리는 중에는 전환할 수 없습니다.

<a id="別ウィンドウに出す"></a>

### 별도 창으로 꺼내기

도킹된 탭을 오른쪽 클릭하여 「별도 창에서 열기」를 선택하거나 탭을 메인 창 밖으로 드래그하여 놓으면 해당 패널이 OS의 별도 창이 됩니다. 다른 모니터에도 둘 수 있습니다. 캔버스와 3D 뷰도 별도 창에서 그릴 수 있습니다. 키·펜 필압·파일 드롭은 포커스가 있는 창에서 동일하게 작동합니다.

- 별도 창끼리는 탭을 드래그하여 그룹으로 묶을 수 있습니다.
- 도킹 영역으로 되돌리려면 탭을 메인 창의 도킹 영역 위에 놓거나 오른쪽 클릭의 「도킹 영역으로 돌아가기」를 선택하거나 창을 닫습니다. 닫으면 분리 전의 그룹으로 돌아갑니다.
- 위치·크기·내부 탭은 다음 실행 시 복원됩니다. 분리한 모니터에 있던 창은 메인 창 위에 열립니다(Windows, Linux는 저장된 위치에 그대로 열림).
- Windows의 별도 창은 작업 표시줄에 나타나지 않고 메인 창 앞에 유지되며 메인 창을 최소화하면 함께 숨겨집니다. OS 제목 표시줄은 없고 탭 행의 빈 곳을 드래그하면 이동합니다. 더블 클릭하면 최대화와 복원을 전환하고 오른쪽 끝 닫기로 도킹 영역에 돌아가며 가장자리를 드래그하면 크기가 바뀝니다.
- 「에셋」 항목을 별도 창의 패널로 드래그 앤 드롭할 수는 없습니다(같은 창 안에서만 가능). 별도 창의 패널에서는 펜 측면 버튼이 오른쪽 클릭으로 동작하지 않습니다. 캔버스와 3D 뷰의 측면 버튼 조작은 작동합니다.

<a id="windows-の上の帯"></a>

### Windows 상단 표시줄

Windows에서는 OS 제목 표시줄 대신 메뉴 모음 오른쪽 끝에 최소화·최대화(최대화 중에는 복원)·닫기를 둡니다. 표시줄의 빈 곳을 드래그하면 창이 움직이고 더블 클릭하면 최대화와 복원을 전환하며 가장자리를 드래그하면 크기가 바뀝니다. Mac과 Linux는 OS 창 테두리를 그대로 사용합니다.

<a id="一覧のスクロール"></a>

### 목록 스크롤

목록과 영역의 스크롤 방식은 어디서나 같습니다. 휠로 이동할 수 있으며 오른쪽 가장자리의 스크롤 손잡이를 잡아 움직일 수 있습니다. 트랙을 누르면 손잡이가 누른 위치로 이동하고 그대로 드래그할 수 있습니다. 펜으로 누른 채 움직여도 마우스처럼 손잡이를 조작할 수 있습니다. 목록(레이어·브러시·에셋·속성·채널 등) 위에서 오른쪽 버튼을 누른 채 움직이면 목록이 포인터를 따라 스크롤됩니다(누르기 시작한 목록은 포인터가 패널 밖으로 나가도 계속 스크롤). 왼쪽 도구 모음 위에서 오른쪽 버튼을 누른 채 움직이면 포인터가 지나간 도구를 선택합니다. 움직이지 않고 놓으면 기존처럼 오른쪽 클릭 메뉴가 열립니다. 손잡이는 평소에는 가늘고 포인터를 가까이 대거나 잡으면 굵어집니다.

<a id="知らせとログ"></a>

## 알림과 로그

작업 결과나 수행할 수 없었던 이유는 상태 표시줄 왼쪽에 한 줄 알림으로 나타났다가 사라집니다. 오른쪽 표시 영역에 닿을 만큼 긴 문장은 「…」로 줄이며 포인터를 올리면 전체 문장을 보여 줍니다.

- 완료 알림은 4초, 거부·주의·실패는 12초 후 사라집니다. 누르면 즉시 사라집니다. 포인터를 올린 동안에는 사라지지 않습니다(계속 올려 두어도 처음 나타난 뒤 3배인 12초·36초가 지나면 사라짐).
- 거부와 실패는 「무엇을 할 수 없는지(이유)」 형식의 한 문장입니다.
- 「로그」 패널에는 실행 이후의 주의와 오류가 시각·종류·출처·메시지로 나열됩니다(최대 1,000행, 같은 알림이 이어지면 한 행으로 묶고 「×3」처럼 횟수를 표시). 위쪽 버튼으로 오류만 필터링, 선택한 행 복사, 전체 복사, 로그 지우기를 할 수 있습니다. 행을 눌러 선택하고 `Ctrl`로 추가·해제하며 `Shift`로 범위를 선택합니다. 완료 알림과 거부는 로그에 들어가지 않습니다. 「도움말 → 로그 폴더 열기」에서 진단 기록 파일이 있는 폴더를 열 수 있습니다.
- 아직 읽지 않은 충돌 기록이 있으면 메뉴 모음에 「!」가 표시됩니다. 누르면 「충돌 보고서」가 열리며 내용 복사, 폴더 열기, GitHub 신고 페이지 열기를 할 수 있습니다. 자동으로 전송하지 않습니다.

상태 표시줄 오른쪽 메모리 표시에 포인터를 올리면 세부 내역(앱 전체·레이어 메모리·실행 취소 기록·GPU)이 나옵니다. GPU 사용량은 가져올 수 있을 때만 표시됩니다. 외부 명령을 수신 중이면 왼쪽에 작은 원이 나타납니다([GUIDE_SETTINGS.md](GUIDE_SETTINGS.md)).
