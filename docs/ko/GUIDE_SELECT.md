# 선택과 변형


선택 영역 만들기와 사용법, 저장하는 방법, 레이어 이동·변형, 복사와 붙여넣기를 설명합니다. 선택 영역은 2D 캔버스와 3D 뷰 모두에서 만들 수 있습니다. 현재 선택 영역은 텍스처 세트별로 `.ylp`에 저장됩니다.

<a id="選択範囲を作る"></a>

## 선택 영역 만들기

| 도구 | 키 | 사용법 |
|---|---|---|
| 사각형 선택·타원 선택 | `M` / `Shift+M` | 드래그합니다. 사각형은 “모서리 둥글기”를 지정할 수 있습니다 |
| 올가미 | `L` | 둘러싸듯 드래그합니다 |
| 다각형 선택 | `Shift+L` | 클릭하여 점을 놓습니다. `Enter` (시작점 클릭이나 두 번 클릭도 가능)로 닫고 `Backspace`로 마지막 점을 지웁니다 |
| 자동 선택 | `W` | 누른 픽셀과 비슷한 색상을 선택합니다. “허용 오차”·“인접 영역만”·“모든 레이어 대상”을 지정할 수 있습니다. 2D 캔버스에서 대칭자가 적용되고 “대칭자에 스냅” (기본 켜짐)이 켜져 있으면 누른 점의 모든 대칭 복사 위치에서 각각 선택하고, 그 합집합을 현재 생성 방식으로 한 번의 선택 영역에 적용합니다 (실행 취소 1회. 캔버스 밖 복사본은 사용하지 않고 같은 픽셀에 겹치는 복사본은 1회만 처리). 캔버스 밖을 누르면 가장자리 픽셀을 누른 것으로 간주하여 대칭 위치를 선택합니다. 3D 뷰에서는 대칭 복사하지 않습니다 (2D 캔버스가 표시되지 않는 동안에는 이 옵션을 전환할 수 없음) |
| 선택 펜·선택 지우개 | `S` | 브러시처럼 칠하여 선택량을 추가하거나 지웁니다. 지름·경도·불투명도는 브러시와 공유합니다 |
| ID 색상으로 선택 | `Shift+W` | 베이크한 ID 맵의 색상으로 선택합니다 |

3D 뷰에서는 사각형 선택·타원 선택·올가미·다각형 선택·자동 선택·ID 색상으로 선택을 사용할 수 있습니다. 3D 뷰 화면에 모양을 그려 보이는 면의 텍스처 픽셀에 투영하고 2D 캔버스와 같은 선택 영역을 만듭니다 ([GUIDE_3D.md](GUIDE_3D.md)의 “화면에 그려 선택하기”). 선택 펜·선택 지우개도 3D 뷰에서 사용할 수 있으며 누른 면의 텍스처 픽셀에 칠해 선택 영역을 추가·삭제합니다 (빠른 마스크를 사용하는 동안은 브러시와 지우개도 같은 역할). 선택 영역의 가장자리는 2D 캔버스와 3D 뷰의 보이는 면 위에 모두 표시됩니다.

“보조 도구” 패널 목록에는 이 선택 도구들이 나열되며 행을 누르면 도구가 바뀝니다. 생성 방식은 옵션 막대의 “새로 만들기”·“추가”·“빼기”·“교차”에서 선택합니다. “도구 속성” 맨 위에도 같은 막대가 있으며 처음에는 “새로 만들기”·“추가”·“빼기”와 “⋯” (모든 생성 방식)만 표시합니다. “⋯”를 누르면 “교차”도 나타납니다 (교차를 선택한 동안에는 접기 설정에서도 4개가 표시됨). 선택 펜의 막대에는 “선택 펜”과 “선택 지우개” 2개가 있습니다. `Shift`를 누르면 추가, `Ctrl`은 빼기, `Shift+Ctrl`은 교차입니다. 선택 펜에서는 `Shift`가 선택 펜, `Ctrl`이 선택 지우개입니다. 사각형과 타원은 누르기 시작한 뒤 `Shift`를 누르는 동안 종횡비를 고정하고 `Alt`를 누르는 동안 누른 점을 중심으로 합니다. “종횡비 고정”·“중심에서”를 미리 켤 수도 있습니다. “안티앨리어싱”으로 가장자리의 부드러움을 정합니다.

전체 작업은 “선택 영역” 메뉴에도 있습니다.

| 작업 | 키 |
|---|---|
| 모두 선택 / 선택 해제 / 선택 영역 반전 | `Ctrl+A` / `Ctrl+D` / `Ctrl+Shift+I` |
| 빠른 마스크 | `Shift+Q` |

`Esc`는 작업 중이면 취소하고, 진행 중인 작업이 없으면 선택 영역을 해제합니다.

<a id="id-の色で選ぶ"></a>

### ID 색상으로 선택하기

베이크한 ID 맵에서 누른 픽셀 (3D 뷰에서는 누른 면의 UV 위치)과 비슷한 색상 영역을 선택합니다 (“허용 오차”로 범위 지정). 메시 파트별 색상을 직접 지정할 수도 있으며 수동 ID 색상은 `.ylp`에 저장되어 다시 열면 복원됩니다. 색상을 지정한 모델과 다른 모델을 열면 다른 모델의 색상으로 유지되며 편집과 ID 맵 베이크를 거부합니다. ID 맵 베이크는 [GUIDE_3D.md](GUIDE_3D.md)에 설명되어 있습니다.

## 선택 영역 다듬기·사용하기

- **다듬기**: “선택 영역” 메뉴의 “확장”·“축소”·“테두리”·“가장자리 흐리게”·“가장자리 선명하게”로 모양을 바꿉니다. `…`가 붙은 항목은 “반경”과 “가장자리 고정”을 지정하는 창을 엽니다. “가장자리 고정”을 켜면 선택 영역이 캔버스 밖으로 이어지는 것으로 처리하여 축소·테두리·흐림이 캔버스 가장자리에서 떨어지지 않습니다.
- **빠른 마스크**: 선택 영역을 빨간 오버레이로 표시하며 브러시와 지우개로 수정할 수 있습니다. 3D 뷰의 브러시와 지우개로도 누른 면의 텍스처 픽셀을 수정할 수 있고 빨간 오버레이는 3D 뷰 면 위에도 표시됩니다 ([GUIDE_3D.md](GUIDE_3D.md)).
- **선택 영역 안에만 그리기**: 브러시와 지우개는 선택 영역 안에만 적용됩니다. 페인트통과 도형의 “칠하기”도 같습니다.
- **버튼 막대**: 선택 영역을 만들면 그 아래에 나타납니다. 해제·반전·확장·축소·가장자리 흐리게·페인트 색상으로 채우기·선택 영역 지우기 (`Delete`)·복사하여 새 레이어 만들기 (`Ctrl+J`)·선택 영역을 레이어 마스크로 만들기·선택 영역 저장이 나열됩니다. 왼쪽 끝 손잡이로 옮길 수 있습니다. “선택 영역” 메뉴의 “선택 영역 버튼 막대 표시”로 숨길 수도 있습니다. 선택 영역이 없을 때 `Ctrl+J`는 레이어 복제입니다.

## 선택 영역 저장하기

“선택 영역” 메뉴의 “저장된 선택 영역…” 또는 막대의 “선택 영역 저장…”을 누르면 “저장된 선택 영역” 창이 열립니다. 이름을 지정하고 “저장”을 누르면 현재 선택 영역을 보관할 수 있습니다 (텍스처 세트 1개당 최대 32개). 저장한 항목은 “새로 만들기”·“추가”·“빼기”·“교차” 중 하나로 불러올 수 있으며 이름 변경과 삭제도 가능합니다. 모두 실행 취소 1회로 되돌릴 수 있습니다. 텍스처 세트 크기를 바꾸면 저장한 선택 영역도 현재 선택 영역처럼 다시 만들며 축소로 아무것도 남지 않는 항목은 제거하고 알립니다.

저장된 선택 영역을 사용하는 `.ylp`는 이전 형식 앱 (0.3.x 독립 실행형과 Unity 브리지)에서 이유를 표시하며 열 수 없습니다 ([UNITY.md](UNITY.md)).

## 이동·변형하기

이동·변형 (`V`)은 선택한 레이어를 움직입니다. 그룹이면 내용 전체, 여러 레이어를 선택했으면 모두, 선택 영역이 있으면 그 안의 픽셀과 선택 영역을 이동합니다.

- 드래그하는 동안은 변형 후 바깥 테두리만 표시합니다. 놓으면 확정되며 도중에 `Enter`를 눌러도 확정합니다. `Esc`·창 포커스 상실·도구 전환 시에는 아무것도 바꾸지 않고 취소합니다. 모두 실행 취소 1회로 되돌릴 수 있습니다.
- 바깥 테두리 핸들로 이동·확대/축소 (`Shift`로 종횡비 유지)·회전 (`Shift`로 15° 단위)을 합니다. 화살표 키로 1픽셀, `Shift`와 함께 누르면 10픽셀 이동합니다.
- “좌우 반전”·“상하 반전”·“시계 방향으로 90° 회전”·“시계 반대 방향으로 90° 회전”은 “편집” 메뉴와 옵션 막대에 있습니다.
- “도구 속성” 패널의 “수치 입력”에서 위치 (X·Y)·배율 (너비·높이)·각도를 숫자로 지정하여 “적용”할 수 있습니다 (“초기화”로 처음 값 복원). “보간”은 “이중 선형” (부드럽게) 또는 “최근접 이웃” (픽셀의 선명함 유지)이며 옵션 막대에도 있습니다.

변형 종류는 보조 도구에서 선택합니다. “일반”은 위의 변형, “자유”와 “원근”은 모서리를 움직여 모양을 바꾸며 “메시”는 격자점 (열과 행은 1〜32)을 움직입니다. `Ctrl`을 누른 채 이동을 시작하면 자유 변형이 됩니다. 원근은 모서리를 움직이면 같은 변의 다른 모서리가 좌우 반대 방향으로 움직입니다.

“왜곡”은 도구 모음 버튼으로 선택합니다 (단축키 없음). 픽셀을 브러시처럼 움직입니다. 보조 도구에서 “밀기”·“오른쪽으로 소용돌이”·“왼쪽으로 소용돌이”·“오므리기”·“부풀리기”·“복원”을 선택하고 “지름”과 “강도”를 지정합니다. “복원”은 이번 왜곡을 시작할 때의 픽셀로 되돌립니다.

텍스트 레이어를 움직이면 텍스트 위치·회전·크기가 바뀝니다. 반전·종횡비를 바꾸는 확대·기울이기·선택 영역 내부만의 변형은 할 수 없습니다 ([GUIDE_PAINT.md](GUIDE_PAINT.md)).

## 복사·잘라내기·붙여넣기

“편집” 메뉴에도 있습니다.

| 작업 | 키 |
|---|---|
| 복사 | `Ctrl+C` |
| 잘라내기 | `Ctrl+X` |
| 병합하여 복사 | `Ctrl+Shift+C` |
| 붙여넣기 | `Ctrl+V` |

복사와 잘라내기는 선택 영역 (없으면 레이어 전체)의 픽셀을 페인트 채널 (마스크에 그리고 있으면 마스크)에서 복사합니다. “병합하여 복사”는 보이는 합성을 복사합니다. 같은 픽셀을 OS 클립보드에도 이미지로 넣으므로 다른 앱에 붙여넣을 수 있습니다. 붙여넣기는 새 레이어가 되며 (실행 취소 1회), 다른 앱에서 복사한 이미지도 붙여넣을 수 있습니다. 텍스처 세트보다 큰 이미지는 붙여넣을 수 없습니다.
