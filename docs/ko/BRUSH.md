# 브러시

브러시 설정 중 사양을 문서로 남길 가치가 있는 항목을 설명합니다. 브러시 상세 설정 창의 항목은 화면에서 확인할 수 있으므로 여기서는 공식과 형식, 다른 도구와의 차이만 다룹니다.

<a id="色の混ぜ厚塗り"></a>

## 색상 혼합(두껍게 칠하기)

기존 브러시는 그리기 색상을 그대로 놓습니다. **색상 혼합**을 사용하는 브러시는 찍힘(dab)마다 아래 색상을 읽고 그리기 색상과 섞어서 놓습니다. CLIP STUDIO의 밑바탕 혼색(색상 혼합·색상 겹치기·번짐, 물감 양·물감 농도·색 늘이기, 혼색 모드, 휘도 보정)에 해당하는 확장이며 공식은 YoluPainter 자체 규칙입니다(CLIP STUDIO 결과와의 일치를 보장하지 않음. 가져온 브러시의 값 환산은 [BRUSH_IMPORT.md](BRUSH_IMPORT.md#下地混色の換算)). 혼합 방식이 「없음」인 브러시는 픽셀과 파일 모두 혼합 기능 추가 전과 같습니다.

<a id="設定"></a>

### 설정

브러시 상세 설정 창의 「잉크」에서 바꿉니다(혼합 방식·물감 양·물감 농도·색 늘이기·모든 레이어에서). 혼합 방식을 선택하면 혼색 모드·휘도 보정·번짐 강도·번짐 강도 연동·초기 물감 양 행도 표시됩니다.

| 항목 | 범위 | 기본값 | 의미 |
| --- | --- | --- | --- |
| 혼합 방식 | 없음/혼합/겹치기/늘이기 | 없음 | 아래 3가지(CLIP STUDIO의 색상 혼합·색상 겹치기·번짐에 해당) |
| 물감 양 | 0~100% | 50% | 혼합색에서 그리기 색상(브러시에 실린 물감)의 비율. 100%이면 아래 색상을 가져오지 않고 0%이면 아래 색상만 사용 |
| 물감 농도 | 0~100% | 100% | 놓는 양. 스트로크 불투명도 상한에 곱할 배율 |
| 색 늘이기 | 0~100% | 50% | 이전 dab에서 가져온 색상을 다음 dab으로 끌고 가는 비율. 늘이기에서는 읽는 위치의 지연 거리에도 적용 |
| 모든 레이어에서 | 켜기/끄기 | 끄기 | 끄기: 그리는 레이어만 밑바탕으로 사용. 켜기: 보이는 레이어의 합성 결과를 밑바탕으로 사용 |
| 혼색 모드 | 표준/지각적 | 표준 | 혼합색을 만드는 공간. 표준은 sRGB 값 보간(기존의 모든 동작), 지각적은 물감처럼 혼합([지각적 혼합](#知覚的な混ぜ)) |
| 휘도 보정 | 0~4(없음~최고) | 0 | 지각적 모드에서만 작동. 클수록 혼합으로 어두워지는 양이 감소 |
| 번짐 강도 | 크기에 연동/크기에 연동(넓게)/고정값 0~8픽셀 | 크기에 연동 | 늘이기에만 적용. 화면의 「번짐 강도 연동」을 끄면 고정값(슬라이더 값), 켜면 크기에 연동(넓게). 아래 색상을 평균할 상자의 반경(연동은 dab 반경의 10%, 넓은 연동은 dab 반경에 비례하며 그보다 넓고 둘 다 1~8픽셀, 고정값 0은 1픽셀). 3D 표면에서 대칭을 함께 쓰지 않을 때는 상자 평균을 사용하지 않으므로(아래 「적용 범위」) 효과 없음 |
| 초기 물감 양 | 0~100% | 100% | 첫 dab에 실린 물감 중 그리기 색상 비율(나머지는 첫 dab 아래 색상). 100%는 그리기 색상만 사용. 작으면 시작 부분이 옅고 진행하면서 그리기 색상이 물감에 추가되어 진해짐 |
| 영향 요인(양·농도) | 입력별 켜기/끄기, 최솟값, 곡선 | 끄기 | 필압·기울기·속도·무작위로 양·농도를 변경. 반응은 [필압 반응](#筆圧の応え)과 같음(최솟값과 곡선) |

혼합 방식:

- **혼합**: dab 아래 같은 픽셀의 색상(스트로크 시작 전 이미지)과 브러시에 실린 물감을 섞어서 놓습니다. 같은 스트로크가 여러 번 겹쳐도 픽셀에 남는 색상은 마지막으로 덮은 dab의 혼합색이며 겹칠 때마다 그리기 색상에 가까워지지 않습니다.
- **겹치기**: 현재 표면(같은 스트로크가 앞서 놓은 내용 포함)의 같은 픽셀을 읽어 물감과 섞어서 놓습니다. 혼합과 달리 놓은 색상 위에 다음 dab이 겹칩니다(겹친 픽셀은 앞선 dab이 놓은 색상을 읽어 다시 혼합). 이동 방향과 상자 평균은 사용하지 않습니다.
- **늘이기**: 이전 dab에서 현재 dab까지의 이동만큼 뒤쪽 밑바탕 색상(현재 표면, 같은 스트로크가 앞서 놓은 내용 포함)을 작은 상자(번짐 강도, 기본값 dab 반경의 10%, 1~8픽셀)로 평균하여 읽고 물감과 섞어 놓습니다. 흐림과 문지르기의 중간처럼 색상이 선을 따라 늘어납니다. 뒤쪽을 읽는 거리는 이동량의 `1 + 2 × 色延び`배이며 dab 크기를 넘지 않습니다.

<a id="式"></a>

### 공식

색상은 straight RGBA(0~255), α는 0~1로 처리합니다. 정밀도는 공식마다 다릅니다. 물감 `C`·`L`의 계산(1.과 4.)은 배정밀도이며(4.의 밑바탕 합계는 픽셀별 곱셈이 단정밀도, 덧셈이 배정밀도), 픽셀 혼합색 `M`(2.)과 합성(3.)은 단정밀도(f32)입니다.

1. **브러시에 실린 물감 `C`**: 첫 dab은 그리기 색상입니다([초기 물감 양](#設定)이 1보다 작으면 그리기 색상과 첫 dab 아래 색상을 해당 비율로 혼합). 다음 dab부터는 `C = L × 色延び + 描く色 × (1 − 色延び)`입니다. `L`은 이전 dab 후 남은 물감입니다. 색 늘이기 0이면 매번 그리기 색상부터 시작하고 1이면 물감을 그대로 끌고 갑니다.
2. **픽셀 혼합색 `M`**: 아래 색상 `U`와 물감 `C`를 물감 양 `A`에 따라 α 가중치로 섞습니다.
   `wu = U.α × (1 − A)`, `wc = C.α × A`, `M.rgb = (U.rgb × wu + C.rgb × wc) / (wu + wc)`, `M.α = C.α`.
   효과 브러시(흐림·문지르기)와 같은 가중치이며 **투명한 밑바탕 색상은 섞이지 않습니다**(투명 레이어에 그려도 그리기 색상이 옅어지지 않음). `wu + wc`가 0인 픽셀은 칠하지 않습니다.
3. **놓기**: 기존 브러시와 같은 경로입니다. 스트로크 커버리지(불투명도 × 필압 × 흔들림 × 종이 질감 × **물감 농도**를 상한으로 흐름에 따라 접근)로 픽셀별 색상 `M`에 접근시키고 스트로크 시작 전 픽셀 위에 일반 합성(`blend`)으로 겹칩니다.
4. **물감 갱신**: dab이 끝난 뒤 `L = 荷と、打点の下の色の平均（被覆 × α で重みを付けた平均）を量 A で混ぜた色`로 갱신합니다. 물감 중 양 A만큼만 다음으로 남고 나머지는 아래 색상으로 교체됩니다(양이 많을수록 더 오래 끌고 감). 밑바탕이 모두 투명하여 가져올 것이 없으면 `L = C`입니다(물감 유지). 끌고 가는 길이는 dab당 교체 비율이므로 dab 간격이 좁을수록 더 짧은 거리에서 교체됩니다.

공식의 「혼합」(2.·4.·1.에서 `L`과 그리기 색상 혼합)은 혼색 모드가 표준이면 위의 가중 보간, 지각적이면 [지각적 혼합](#知覚的な混ぜ)입니다(가중치는 같으며 휘도 보정은 2.에만 적용하고 물감 혼합·채취에는 적용하지 않음). 표준 모드이고 초기 물감 양이 1(기본값)인 브러시는 기존과 같은 픽셀을 만듭니다.

필압으로 양·농도를 바꿀 때는 `A × 応え(筆圧)`, `濃さ × 応え(筆圧)`를 사용합니다(기본 반응은 필압 자체). 가볍게 닿으면 양을 줄여 아래 색상을 늘이고 세게 누르면 그리기 색상을 놓는 방식으로 사용할 수 있습니다.

<a id="知覚的な混ぜ"></a>

### 지각적 혼합

표준 혼합은 sRGB 값을 가중 보간하므로 파랑과 노랑은 회색에 가까워지고 흰색에 노랑을 조금 섞으면 옅은 노랑이 됩니다. 지각적 혼합은 물감에 가까워 파랑과 노랑은 어두운 초록, 흰색과 소량의 노랑은 강한 노랑이 됩니다. 공식은 YoluPainter 자체 방식이며 원추세포 반응(LMS) 공간에서 흡수 곱에 가까운 혼합을 합니다(`t`는 뒤쪽 색상의 가중치 = 물감 비율).

1. 선형광에서 원추세포 반응 `x = M·lin + 0.005`를 구합니다. `M`은 Hunt-Pointer-Estevez 원추세포 기본 함수(D65로 정규화, [LMS color space](https://en.wikipedia.org/wiki/LMS_color_space))에 sRGB(D65) 원색을 결합한 3×3입니다. 0.005는 반응이 0인 색상이 곱을 0으로 무너뜨리지 않게 하는 하한입니다.
2. 8제곱근의 거듭제곱 평균 `P = (1 − t)·a^(1/8) + t·b^(1/8)`를 구합니다(`a`·`b`는 두 색상의 `x`). 지수 1/8은 기하평균(흡수의 곱)에 가까우며 제곱근 3회로 구할 수 있습니다.
3. 혼합 반응은 `P^8`입니다. 휘도 보정은 혼합으로 어두워지는 양의 지수를 5단계로 바꿉니다. 휘도 보정 `k`(0~4)에 따라 `P^(16 − 2k)` 쪽으로 `P^8`에서 `s·g`만큼 접근시킵니다(`s = min(1, min(t, 1 − t) / 0.05)`, `g = min(1, Δ / 0.16)`, Δ는 두 색상 `x`의 8제곱근 차이의 최댓값). 최고(4)는 접근시키지 않으며(지수 1), 없음(0)은 지수 2입니다. 양 끝(`t` = 0·1)과 같은 색끼리는 바뀌지 않습니다.
4. 반응에서 0.005를 빼고 `M`의 역행렬로 선형광, 이어 sRGB로 되돌립니다.

공식은 + − × ÷, 제곱근, 테이블 조회만으로 작성했으며 OS 수학 함수를 사용하지 않습니다. 공식상 스칼라·SSE4.1·AVX2·NEON 경로, 스레드 수, OS와 무관하게 같은 바이트가 되도록 구성했습니다. 픽셀마다 원추세포 반응 변환과 제곱근·sRGB 변환을 거치므로 표준 혼합보다 대략 한 자릿수 배 무겁고 워커로 그릴 크기 추정도 이에 맞췄습니다.

<a id="下地の読み方"></a>

### 밑바탕 읽기

- dab을 찍기 전에 읽을 범위의 픽셀을 프레임으로 고정하며, 어떤 픽셀도 쓰기 전에 이를 끝냅니다. 쓰는 중에는 표면을 다시 읽지 않으므로 워커로 그리든 순서대로 그리든 같은 픽셀을 만듭니다.
- **혼합**은 스트로크 시작 전 이미지를 읽습니다(현재 레이어만 읽을 때 이미 수정한 타일은 되돌리기 복사본에서 읽음). 같은 스트로크가 앞서 놓은 픽셀은 읽지 않으므로 브러시 간격이나 같은 위치를 지나는 횟수에 따라 혼합 방식이 바뀌지 않습니다. 물감의 끌림만 스트로크 내부에서 색상을 옮깁니다.
- **겹치기**와 **늘이기**는 현재 표면을 읽습니다(이 스트로크가 앞서 놓은 픽셀 포함, 문지르기와 동일). 앞서 끌거나 놓은 색상을 뒤의 dab이 옮깁니다. 겹치기는 같은 픽셀을, 늘이기는 이동 뒤쪽을 상자 평균으로 읽습니다.
- **모든 레이어에서**(보이는 레이어의 합성을 밑바탕으로 사용)는 현재 평가 경로(혼합 모드·불투명도·효과·마스크 포함)로 첫 dab 전에 합성하여 고정합니다. 혼합에서는 현재 레이어만 읽을 때와 비교해 아래 레이어 등이 포함되는 점만 다릅니다. 겹치기·늘이기에서는 고정된 이미지를 읽으므로 앞서 끌거나 놓은 색상을 옮기지 않고 원본 이미지 색상을 읽습니다. 고정한 합성 이미지는 복제의 「모든 레이어에서」처럼 스트로크 한도에 포함하며 초과하면 스트로크 전체를 취소합니다.
- 읽기 프레임도 스트로크 한도에 포함합니다. 늘이기는 상자 평균용 적분 이미지도 포함합니다. 초과하면 스트로크 전체를 취소하여 픽셀·기록을 원래대로 유지합니다.

<a id="効く範囲"></a>

### 적용 범위

- 색상 채널을 색상으로 칠하는 브러시에만 적용합니다. Roughness 같은 데이터 채널, 노멀, 레이어 마스크에서는 혼합하지 않습니다(값이 손상되기 때문). 여러 채널을 스트로크 한 번으로 칠할 때(머티리얼)는 색상 채널만 혼합하고 데이터 채널에는 같은 dab을 혼합 없이 칠합니다.
- 지우개, 흐림·문지르기·복제 효과 브러시에서는 혼합하지 않습니다(설정은 남지만 적용되지 않음).
- 선택 영역과 투명 픽셀 잠금은 일반 브러시와 같이 작동합니다. 선택 밖의 픽셀과 잠긴 투명 픽셀은 칠하지 않고, 절반 선택된 픽셀은 원래 픽셀에서 혼합색으로 절반만 접근하며 투명 픽셀 잠금은 투명 픽셀의 RGB와 알파를 보호합니다. 칠하지 않는 픽셀의 밑바탕 색상은 물감에도 들어가지 않으므로(혼합) 선택 밖의 색상을 가져와 선택 안으로 옮기지 않습니다. 늘이기는 이동 뒤쪽 색상을 읽으므로 흐림·문지르기와 같이 선택 밖의 색상도 읽습니다.
- 3D 표면에 그릴 때도 적용합니다. 혼합·겹치기는 dab 픽셀을 묶어 전달하고 쓰기 전에 밑바탕 색상을 고정합니다(흐림과 같은 경로, 겹치기는 현재 표면을 읽음). 늘이기는 문지르기처럼 펼침 맵으로 UV 이음새를 넘어 직전 dab 쪽의 밑바탕 색상을 읽습니다(상자 평균 없음). 대칭(2D·3D 대칭자)과 함께 사용할 때는 복사본마다 이동 방향이 다르므로 이동 방향을 쓰지 않고 같은 픽셀 주변의 상자 평균만 사용합니다(이때 상자는 번짐 강도의 고정값도 적용, 혼합·겹치기는 대칭에서도 같은 공식이어서 좌우가 거울상이 됨).
- 3D 표면과 대칭 dab은 픽셀이 있는 타일의 연결된 덩어리마다 밑바탕을 고정하여 칠합니다. dab 하나가 UV의 떨어진 아일랜드나 대칭의 떨어진 복사본에 걸쳐도 읽기 프레임은 덩어리별 작은 범위이며 외접 상자(캔버스 대부분)를 읽어 한도를 소모하지 않습니다(하나로 연결된 dab은 기존처럼 프레임 하나, 고정한 프레임 바이트는 덩어리별로 스트로크 한도에 포함).
- 혼합 브러시는 픽셀별 페인팅 진입점(`apply_pixel`)에서 사용할 수 없습니다.
- 혼합은 CPU에서만 수행합니다. GPU 브러시 미리보기(`yolu-gpu`의 `brush_dabs`)는 원형 브러시 끝의 커버리지와 색상만 계산하는 별도 경로이며, 아래 픽셀 읽기와 dab별 물감 갱신에 의존하는 혼합은 지원하지 않습니다. 저장과 Undo의 기준은 항상 core 스트로크입니다.

### 저장

사용자 브러시(`.ylbrush`, 설정 폴더의 `brushes/`)는 혼합 방식이 「없음」이 아니면 첫 줄을 `yolupainter-brush 3`으로 쓰고 혼합 항목을 기록합니다. 사용하지 않는 브러시는 기존과 같은 버전·바이트입니다(필압 반응만 쓰는 브러시는 버전 2).
시작·끝 보정과 손떨림 보정이 있는 브러시(CLIP STUDIO에서 가져온 브러시의 설정, [BRUSH_IMPORT.md](BRUSH_IMPORT.md))만 첫 줄을 `yolupainter-brush 4`로 쓰고 `assist.stabilizer`·`assist.taper_in`·`assist.taper_out`(픽셀, 0~10000)을 기록합니다.
(버전 2·3 항목도 사용한다면 같은 파일에 기록합니다.) 시작·끝 보정과 손떨림 보정은 그리는 사람의 설정이어서 브러시에 포함되지 않으므로 가져온 브러시만 가지며, 그 브러시를 선택한 동안에만 현재 설정에 겹쳐 적용됩니다.
[최소 1픽셀](#最低-1-ピクセル)을 켠 브러시만 첫 줄을 `yolupainter-brush 6`으로 쓰고 `controls.min_one_pixel=1`을 기록합니다(다른 버전 항목도 같은 파일에 기록. 꺼진 브러시는 기존과 같은 버전·바이트이며 버전 5까지의 파일은 꺼짐으로 읽음).
버전 6까지의 항목으로 기록할 수 없는 [영향 요인](#筆圧の応え)(무작위, 기울기·속도의 최솟값 또는 곡선, 원형도·질감 농도의 영향 요인, 경도·물감 양과 농도에 대한 기울기·속도·무작위)을 사용하는 브러시만 첫 줄을 `yolupainter-brush 7`로 쓰고 영향 요인을 `influence.<項目>.<入力>.on`·`.min`·`.curve`로만 기록합니다(항목은 `size`·`opacity`·`flow`·`hardness`·`roundness`·`texture_density`·`mix_paint`·`mix_density`, 입력은 `pressure`·`tilt`·`speed`·`random`. 버전 2·3 필압 항목과 `pressure_size` 등의 전환값·`controls.tilt_size` 등은 기록하지 않음). 기존 형식으로 표현할 수 있는 브러시는 같은 버전·바이트를 유지합니다.
버전 7까지의 항목으로 기록할 수 없는 기능을 쓰는 브러시만 첫 줄을 `yolupainter-brush 8`로 씁니다(버전 7과 같은 영향 요인 키에 추가로 기록). 현재 다음 8가지이며 아무것도 사용하지 않는 브러시는 기존과 같은 버전·바이트입니다. 버전 7까지의 파일에 이 키가 있으면 알 수 없는 항목으로 거부합니다.

- 시작·끝 보정 대상이 기본값(크기만·최솟값 0)이 아닌 브러시: `assist.taper.<項目>`(항목은 영향 요인과 같은 8개, 적용하지 않으면 `off`, 적용하면 최솟값 0~1)를 8행 모두 기록합니다.
- 브러시 끝 반복 방식 `pingpong`·`hold`·`once`·`shuffle`, 끝 뒤집기 `random`·`fold`, 브러시 끝끼리 어둡게 비교, 질감 회전을 쓰는 브러시: `tip.selection`의 새 값·`tip.flip_x_rule`·`tip.flip_y_rule`·`tip.darken=1`·`texture.angle`(도)을 기록합니다.
- [색상 변화](#色の変化)를 쓰는 브러시: 끝 변화는 `color.tip.hue`(도)·`color.tip.saturation`·`color.tip.value`(3개 모두 기록), 보조색 혼합률은 `color.sub_mix`(0은 생략), 스트로크별 변화는 `color.stroke.hue`(도)·`color.stroke.saturation`·`color.stroke.value`·`color.stroke.sub_mix`(4개 모두 기록), 변화 대상은 `color.target`(`main_and_sub`·`sub`, 기본색은 생략)입니다. 영향 요인은 `influence.color_hue.<入力>.…`·`influence.color_saturation.<入力>.…`·`influence.color_value.<入力>.…`·`influence.color_sub_mix.<入力>.…` 형태이며 다른 항목과 같은 `.on`·`.min`·`.curve`를 사용합니다.
- [산포 효과](#散布効果)를 쓰는 브러시: `spray.size`(입자 크기)·`spray.density`(입자 밀도)는 항상 기록하며 `spray.link_size=1`(브러시 크기 연동)·`spray.bias`(산포 편향)·`spray.angle`(입자 방향, 도)·`spray.direction`(`line`·`whole`·`center`)·`spray.random_angle`(무작위 강도)은 기본값(끄기·0·없음)이 아닐 때만 기록합니다. 영향 요인은 `influence.spray_size.<入力>.…`·`influence.spray_density.<入力>.…` 형태이며 다른 항목과 같은 `.on`·`.min`·`.curve`를 사용합니다(영향 요인만 쓰는 브러시도 버전 8).
- 색상 혼합의 버전 8 항목을 쓰는 브러시(혼합 방식이 「없음」이 아닌 경우만): 겹치기 방식(`mix.mode=layer`), 지각적 혼색 모드(`mix.space=perceptual`), 0이 아닌 휘도 보정(`mix.correction`, 0~4), 고정 번짐 강도(`mix.blur`, 픽셀, 0~8) 또는 크기 연동(넓게)(`mix.blur=linked`), 100%가 아닌 초기 물감 양(`mix.load`, 0~1)입니다. 모두 기본값이면 기록하지 않으며 이 기능을 쓰지 않는 혼합·늘이기 브러시는 기존과 같은 버전·바이트입니다. 버전 7까지의 파일에 이 키가 있으면 알 수 없는 항목으로 거부하고 `mix.mode=layer`는 읽을 수 없는 값으로 거부합니다.
- [듀얼 브러시](#デュアルブラシ)의 추가 항목을 쓰는 브러시: 추가 혼합 모드는 `dual.mode`의 새 값(`normal`·`add`·`lighten`·`screen`·`linear-height`)이며 `dual.link_size=1`(주 브러시 크기 연동)·`dual.flow`(농도)·`dual.anti_alias`(보조 안티앨리어싱, `none`·`weak`·`medium`·`strong`)·`dual.angle_tilt=1`·`dual.angle_rotation=1`·`dual.angle_line=1`(방향에 더할 요소)·`dual.angle_random`(방향 무작위 강도)은 기본값(끄기·1·주 브러시와 같음·0)이 아닐 때만 기록합니다. 영향 요인은 `influence.dual_size.<入力>.…`·`influence.dual_flow.<入力>.…`·`influence.dual_spacing.<入力>.…`·`influence.dual_thickness.<入力>.…` 형태로 다른 항목과 같은 `.on`·`.min`·`.curve`를 사용합니다(영향 요인만 쓰는 브러시도 버전 8). 보조 브러시의 여러 끝 이미지는 `dual.tips`(`tip.images`와 같은 목록 형식), 반복 방식은 `dual.selection`(`tip.selection`과 같은 값, 무작위는 생략), 뒤집기는 `dual.flip_x=1`·`dual.flip_y=1`·`dual.flip_x_rule`·`dual.flip_y_rule`(`tip.*`와 같은 값), 끝끼리 어둡게 비교는 `dual.darken=1`, 종이 질감은 `dual.texture`(이미지)·`dual.texture.depth`·`dual.texture.scale`·`dual.texture.mode`(`texture.*`와 같은 값)·`dual.texture.angle`(0은 생략), 산포 효과는 `dual.spray.*`(`spray.*`와 같은 키·기록 방식)입니다. 기존 8가지 모드와 기존 `dual.*` 키만 사용하는 브러시는 같은 버전·바이트를 유지합니다. 버전 7까지의 파일에 추가 모드 값이 있으면 읽을 수 없는 값으로 거부합니다.
- [수채화 경계](#水彩境界)를 쓰는 브러시: `water_edge.width`(너비)·`water_edge.opacity`(투명도 영향)·`water_edge.darkness`(명도 영향)는 항상 기록하며 `water_edge.after_stroke=1`(드래그 후 처리)·`water_edge.blur`(흐림 너비)는 기본값(끄기·0)이 아닐 때만 기록합니다.
- [넘침 방지](#はみ出し防止)를 켠 브러시: `refer.on=1`·`refer.margin`(색상 오차)·`refer.amount`(영역 확장/축소 양, 픽셀)·`refer.mode`(`square`·`round`·`darkest`)를 기록하고 영역 확장/축소가 켜져 있으면 `refer.expand=1`도 기록합니다. 꺼진 브러시는 값과 무관하게 기록하지 않습니다(`refer.on=1`이 없는 파일에 `refer.*`가 있으면 다시 쓸 때 바이트가 달라지므로 알 수 없는 항목으로 거부).

버전 8까지의 항목으로 기록할 수 없는 기능을 쓰는 브러시만 첫 줄을 `yolupainter-brush 9`로 씁니다(버전 8과 같은 방식에 추가로 기록). 다음 5가지이며 아무것도 쓰지 않는 브러시는 기존과 같은 버전·바이트입니다. 버전 8까지의 파일에 이 키가 있으면 알 수 없는 항목으로 거부합니다.

- [도구 속성에 표시할 행](#ツールプロパティに出す行)이 초기 상태와 다른 브러시: `rows.shown`(표시할 행 이름의 쉼표 구분 목록, 표 순서로 기록, 하나도 표시하지 않으면 빈 값). 초기 상태(이전 도구 속성의 행)와 같으면 기록하지 않고 해당 필드 없는 형식으로 읽습니다. 알 수 없는 행 이름은 읽을 수 없는 값으로 거부합니다.
- [화면상 크기로 지정](#画面上のサイズで指定)을 켠 브러시: `controls.size_by_screen=1`.
- 기울기의 [최댓값](#筆圧の応え)이 100%가 아닌 영향 요인이 있는 브러시: `influence.<項目>.tilt.max`(0~1, 기울기 입력만 지원하며 다른 입력에 이 키가 있으면 알 수 없는 항목으로 거부).
- [보정](#補正)의 속도에 따른 조절·끝 처리·후처리 보정이 있는 브러시(시작·끝 및 손떨림 보정처럼 가져온 브러시가 가진 설정): `assist.stabilizer_speed`(보정 유형, `fast`는 빠르게 그릴 때 약하게 보정, `slow`는 천천히 그릴 때 보정)·`assist.sweep`(끝 처리, 0~1)·`assist.post`(후처리 보정 켜기/끄기)·`assist.post.strength`(강도, 0~100)·`assist.post.by_speed`·`assist.post.by_view_scale`(속도에 따른 조절·확대율에 따른 조절)입니다. 기본값(끄기·0)은 생략하며 후처리 보정은 4개 중 하나라도 기본값(끄기·강도 10·두 조절 모두 켜짐)이 아니면 4개 모두 기록합니다.
- [연속 분사](#連続吹き付け)·[리본](#リボン)을 켠 브러시: `tip.continuous=1`·`tip.ribbon=1`(끄기는 생략).

브러시 끝 뒤집기 방식(없음·뒤집기·무작위·방향을 바꿀 때 뒤집기)은 하나의 설정으로 가집니다. 저장 형식은 바꾸지 않았습니다. 항상 뒤집기는 `tip.flip_x=1`(`tip.flip_y=1`), 무작위는 `tip.flip_x_rule=random`, 방향 변경 시 뒤집기는 `tip.flip_x_rule=fold`이며 버전 8까지의 파일도 같은 설정으로 열립니다(플래그와 규칙이 모두 있으면 규칙 우선).

```
yolupainter-brush 3
…（バージョン 1・2 と同じ項目）…
mix.mode=mix            （mix / smear。バージョン 8 は layer も）
mix.paint=0.5
mix.density=1
mix.stretch=0.5
mix.ground=layer        （layer / composite）
mix.space=perceptual    （バージョン 8。perceptual のときだけ）
mix.correction=2        （バージョン 8。0 でないときだけ）
mix.blur=5              （バージョン 8。固定値のときだけ。画素）
mix.load=0.4            （バージョン 8。1 でないときだけ）
mix.paint.pressure=1    （入のときだけ）
mix.paint.min=0.3       （0 でないときだけ）
mix.paint.curve=0:0,1:1 （直線でないときだけ）
mix.density.pressure=1
mix.density.min=…
mix.density.curve=…
```

- 숫자는 화면과 같은 f32 정밀도로 기록하며 다시 읽어도 같은 값입니다.
- 버전 3 항목이 버전 1·2 파일에, 버전 4 항목이 버전 1~3 파일에, 버전 5 항목([안티앨리어싱](#アンチエイリアス))이 버전 1~4 파일에, 버전 6 항목(최소 1픽셀)이 버전 1~5 파일에 있으면 「알 수 없는 항목」으로 거부합니다. 버전 10 이상은 건드리지 않고 건너뛰며 이유를 표시합니다. 버전 3까지만 아는 이전 앱은 버전 4 파일을, 버전 4까지만 아는 이전 앱(0.5.x까지)은 버전 5 파일을, 버전 5까지만 아는 이전 앱은 버전 6 파일을 같은 방식으로 「새 형식」으로 간주하여 건너뜁니다.
- 가져온 브러시는 출처(`import.source`)·표현하지 못한 항목(`import.gaps`)·파일에서 복사한 항목(`import.mapped`, CLIP STUDIO에서 가져온 브러시만, 항목 이름의 쉼표 구분 목록)을 버전을 올리지 않고 기록합니다. 복사한 항목은 가져올 당시 결과를 그대로 유지하며 이후 설정을 바꿔도 변하지 않습니다. 알 수 없는 이름은 건너뜁니다. `import.mapped`를 모르는 이전 앱은 이 항목이 있는 파일을 「알 수 없는 항목」으로 간주하여 이유와 함께 건너뜁니다.
- 0.4.x까지의 Unity 브리지 `.ylbrush`는 이 사용자 브러시 텍스트 형식과 별개이며 두 종류가 있었습니다. 에디터의 「브러시 저장·불러오기」는 `BrushState` JSON(`schema` 1~3, `JsonUtility`), `.ylp` 에셋의 휴대용 브러시는 ZIP(첫 항목은 비압축 `mimetype`, `state.json`의 `schema`는 1~3)입니다.
  두 읽기 구현 모두 이 텍스트 형식을 버전(1·2·3)과 관계없이 JSON으로 읽을 수 없거나 `mimetype`로 시작하지 않는다는 이유로 거부합니다(알림 없이 읽지 않음).
- 혼합 항목은 0.4.x까지의 Unity 브리지 `BrushState`에 없으며 `schema`를 올리지 않고 기록하면 `JsonUtility`가 알 수 없는 항목을 조용히 버립니다. 따라서 이 버전은 두 형식 어디에도 혼합을 기록하지 않습니다.
- `.ylp`에는 혼합 항목을 넣지 않습니다(`.ylp` 에셋의 브러시는 0.4.x까지의 Unity 브리지 휴대 형식 그대로 내용을 변경하지 않고 전달).

### 가져오기

Photoshop ABR은 혼합 브러시 설정 중 브러시 설명에 들어 있는 항목(젖음·혼합 흔들림)을 가져온 브러시의 「표현하지 못한 항목」에 표시합니다. 혼합 브러시의 기본값(젖음·불러오기·혼합)은 도구 옵션에 있고 브러시 설명에는 없으므로 복사할 수 없습니다. 젖음·혼합 흔들림의 키 이름(`wetnessControl`·`mixControl`)은 실제 ABR에서 아직 확인하지 않았습니다(합성 데이터 테스트만 수행). 실제 키 이름이 다르면 이 주석이 표시되지 않고 혼합 브러시 흔들림 설정은 알림 없이 가져오지 않습니다.

## 안티앨리어싱

둥근 브러시 끝의 가장자리와 작은 dab에 픽셀 계단(울퉁불퉁한 가장자리)이 생기지 않도록 하는 설정입니다. 브러시 상세 창의 「안티앨리어싱」과 패스의 브러시 항목에서 선택합니다(2D 캔버스와 3D 뷰 모두에 적용됩니다).

| 단계 | 가장자리 띠의 폭 |
| --- | --- |
| 없음 | 띠 없음(경도만으로 가장자리가 결정됩니다. 기존 수식) |
| 약 | 0.5픽셀 |
| 중 | 1픽셀 |
| 강 | 2픽셀 |

띠의 폭은 그리는 대상 텍스처의 픽셀(텍셀) 단위입니다. 3D 뷰에서도 텍스처 해상도와 모델이 보이는 모양을 바탕으로 텍셀 1개가 화면에서 몇 포인트인지 구해 띠를 텍셀 폭에 맞춥니다.

- 둥근 브러시 끝(원형도 1·이미지 없음)은 칠하는 텍셀마다 해당 위치의 텍셀이 화면에서 차지하는 크기(방향별)로 띠를 보정합니다. 가까이 가거나 멀어져도, 비스듬한 면에서도 띠는 텍셀 폭을 유지합니다. 단, dab 중심의 텍셀보다 2배 넘게 크게 보이는 텍셀에서는 띠가 dab의 도달 범위 안에 들어가는 폭으로 제한됩니다(그곳에서는 띠가 텍셀보다 좁아집니다).
- 납작한 원·이미지 브러시 끝·듀얼 브러시의 두 번째 브러시 끝은 dab 중심의 텍셀 크기 하나로 보정합니다(dab 안에서 텍셀 크기가 달라지는 곳에서는 근삿값입니다).
- dab 중심이 면 위에 없으면 직전에 면에 닿았던 dab의 값을 사용합니다.
- 3D 패스와 보이지 않는 면에도 칠하는 대칭 복사본(모델 공간의 구형 dab)은 삼각형별 텍셀 크기로 보정합니다.

<a id="式-1"></a>

### 수식

덮임은 픽셀 중심의 한 점에서 측정합니다. 중심으로부터의 거리를 반지름으로 나눈 값을 d, 경도를 h라고 합니다.

- **없음**: d가 h 이하이면 1, 1을 넘으면 0, 그 사이는 smoothstep(`t = (1 − d) / (1 − h)`, `t² (3 − 2t)`)입니다.
- **나머지 단계**: 흐림 폭을 `max(半径 × (1 − h), 帯)`로 하고, 띠의 중심을 없음 수식에서 덮임이 절반이 되는 지점(`d = (1 + h) / 2`. 경도 1이면 원래 반지름)에 둡니다. 띠가 흐림 폭을 넘는 곳만 달라지고, 눈에 보이는 두께(덮임이 절반이 되는 지점)는 변하지 않습니다.
  띠가 흐림 폭 이하인 부드러운 브러시 끝(에어브러시 등)·크고 부드러운 브러시 끝은 어느 단계에서든 없음과 같은 픽셀 결과를 냅니다.
- **납작한 원(원형도·각도)**: 띠는 가장자리에 수직인 방향의 폭입니다(거리의 기울기로 픽셀마다 보정). 띠 수식의 거리는 덮임이 절반이 되는 타원을 감싸는 상자 바깥까지의 거리보다 작아지지 않도록 제한하여, 가는 타원에서도 띠가 긴 축 끝 바깥으로 늘어나지 않습니다. 짧은 축이 띠의 절반보다 가는 타원은 짧은 축을 띠의 절반까지 넓히고, 해당 축의 농도로 면적을 유지합니다.
- **작은 dab**: 덮임이 절반이 되는 반지름이 띠의 절반보다 작은 축은 해당 축을 띠의 절반까지 넓히고, 해당 축의 농도를 `半径 / (帯の半分)`로 합니다. 1픽셀보다 작은 dab(중)은 닿은 픽셀에 1픽셀 분량의 농도를 놓는 대신 dab의 면적에 맞는 농도를 주변 픽셀에 나누어 놓습니다(픽셀 사이를 지나는 dab도 사라지지 않습니다). 약은 반지름 1픽셀보다 가는 선에서 띠를 1픽셀까지 넓힙니다(0.5픽셀 그대로라면 가는 선의 dab이 픽셀 중심에 걸리지 않아 사라지기 때문입니다).
- **이미지 브러시 끝**: 이미지 보간은 그대로 두고, 작은 dab의 농도에만 적용합니다(이미지 폭이 띠의 절반보다 좁은 방향을 띠의 절반까지 넓히고, 해당 방향의 농도를 곱합니다). 가장자리가 투명한 이미지는 놓는 위치에 따라 넓힌 가장자리에 픽셀 중심이 걸려 여전히 사라질 수 있습니다.
- 듀얼 브러시의 두 번째 브러시 끝·2D 대칭 복사본·흐리기·문지르기·복제도 같은 수식을 사용합니다.

### 기본값과 저장

- 앱의 기본 브러시와 내장 브러시 중 펜·붓·지우개 그룹에서 경도 0.5 이상인 둥근 브러시 끝은 **중**, 나머지 내장 브러시(에어브러시·이미지 브러시 끝·효과 브러시 등)는 **없음**입니다.
- 사용자 브러시 파일은 없음이 아닌 브러시만 첫 줄을 `yolupainter-brush 5`로 하고 `anti_alias=weak`(`weak` / `medium` / `strong`)를 기록합니다. 없음인 브러시는 기존 버전·동일한 바이트를 유지하며, 버전 4까지의 파일은 없음으로 읽습니다(이전에 저장한 브러시의 모양은 변하지 않습니다).
- 패스의 브러시는 `.ylp` 정본 버전 34에 들어갑니다([YLP_FORMAT.md](YLP_FORMAT.md)). 없음인 패스만 있는 문서는 이전 버전을 유지하고, 버전 33까지의 문서에 있는 패스는 없음으로 읽습니다. 새로 만드는 패스는 현재 브러시의 단계(기본값은 중)를 사용하므로 패스를 새로 만든 문서는 보통 버전 34가 되며, 0.5.x까지의 앱에서는 열 수 없습니다. 패스 프리셋(`path_presets/`)은 없음이 아닐 때만 `"anti_alias": "medium"`처럼 기록합니다.
- CLIP STUDIO 브러시(`.sut`)에서는 안티앨리어싱 값(`AntiAlias`)을 복사합니다([BRUSH_IMPORT.md](BRUSH_IMPORT.md)). 다른 형식(ABR·GIMP 등)에서 가져온 브러시는 없음(현재 모양)입니다.
- GPU 브러시 미리 보기(`yolu-gpu`의 `brush_dabs`)는 안티앨리어싱을 지원하지 않으며, 없음 이외의 설정은 이유를 표시하고 거부합니다(저장과 Undo의 정본은 core의 스트로크입니다).

## 색 변화

그리는 색의 색조·채도·명도를 dab마다 바꾸고 보조 그리기색 쪽으로 섞습니다. CLIP STUDIO의 「브러시 끝 색 변화」「보조 그리기색 혼합률」「스트로크별 무작위 변화」「변화 대상」에 해당하는 확장입니다. 기존 브러시(색 흔들림만 있는 브러시·Photoshop ABR에서 가져온 브러시 포함)는 색 변화를 가지지 않으며 픽셀과 파일 모두 변하지 않습니다.

| 항목 | 범위 | 기본값 |
|---|---|---|
| 브러시 끝 색조 | −360~360도 | 끔 |
| 브러시 끝 채도·명도 | −1~1(포인트의 1/100) | 끔 |
| 보조 그리기색 혼합률 | 0~1 | 0 |
| 스트로크별 색조 | 0~180도 | 끔 |
| 스트로크별 채도·명도·보조 그리기색 혼합률 | 0~1 | 끔 |
| 변화 대상 | 주색·주색과 보조색·보조색 | 주색 |

- **브러시 끝 변화량** = 값 × 해당 항목의 [영향 요소](#筆圧の応え) 계수의 곱입니다(색조·채도·명도·보조 그리기색 혼합률마다 영향 요소가 있습니다). 사용 중인 입력의 계수를 곱하며, 어떤 입력도 사용하지 않으면 1이므로 설정값 그대로 일정합니다. 색조·채도·명도의 영향 요소만 응답 최솟값을 −1~1로 설정할 수 있습니다(수식은 `最小値 + (1 − 最小値) × 曲線(x)` 그대로입니다). 무작위에 최솟값 −1이면 계수는 `−1 + 2u`(u는 0~1의 균등 난수)로, 기준에서 ±값의 균등한 변동이 생깁니다. 필압에 최솟값 0이면 계수는 필압 자체이며, 변화량은 필압 0에서 0, 필압 1에서 설정값이 됩니다. 값의 부호가 방향(＋는 증가·−는 감소)을 정합니다.
- **보조 그리기색 혼합률**은 영향 요소를 사용하지 않으면 dab마다 일정합니다(1이면 보조 그리기색 그대로). 무작위(최솟값 0)이면 0~값 사이에서 균등하게 변합니다. 브러시 끝 색 변화의 활성화 여부와 관계없이 적용됩니다.
- **스트로크별** 변화는 스트로크 시작 시 한 번만 무작위로 정합니다. 색조·채도·명도는 `値 × (2u − 1)`(±값), 보조 그리기색 혼합률은 `値 × u`(0~값)이며, 해당 스트로크의 모든 dab에 동일한 변화량을 더합니다. 브러시 끝 변화량과는 덧셈입니다(색조는 도 단위로 더하고 한 바퀴를 기준으로 순환합니다).
- **색을 만드는 방법**(dab 하나): 색 흔들림을 적용한 색(사용하지 않으면 그리기색)을 ① 보조 그리기색 쪽으로 혼합률만큼 섞고, ② HSV에서 색조·채도·명도를 더합니다. 섞기는 RGB에서 수행하며 알파는 그리기색을 유지합니다. 채도·명도는 더한 뒤 0~1로 제한합니다(위·아래 한계에서 멈춤). 보조 그리기색 혼합률은 브러시 끝과 스트로크별 값을 더한 뒤 0~1로 제한합니다.
- **변화 대상**: 이 앱은 항상 주 그리기색으로 그리므로 「주색」「주색과 보조색」은 브러시 끝과 스트로크별 변화를 적용하고, 「보조색」은 색조·채도·명도·스트로크별 변화를 적용하지 않습니다(색이 변하지 않습니다). 브러시 끝의 보조 그리기색 혼합률은 변화 대상과 관계없이 적용합니다.
- dab별 난수는 스트로크의 난수 시드로 결정되는 수열(색 흔들림·영향 요소·듀얼 브러시와 별도)에서 무작위를 사용하는 항목마다 색조·채도·명도·보조 그리기색 혼합률 순서로 하나씩 뽑습니다(값이 0인 항목도 무작위를 사용하면 뽑습니다). 스트로크별 4개 값은 또 다른 수열에서 시작할 때 뽑습니다. 2D의 그리기 지점과 3D 면의 dab은 같은 함수로 색을 만들므로 설정과 입력 지점의 배열이 같으면 같은 색 배열이 나옵니다.
- dab별 색이 필요한 때는 브러시 끝 변화를 켰거나, 보조 그리기색 혼합률이 0보다 크고 영향 요소에 따라 변할 때뿐입니다. 어느 쪽도 아니면 스트로크 시작 때 만든 색으로 칠합니다(변화가 없는 브러시와 같은 빠른 경로).
- 색 채널을 색으로 칠하는 브러시에만 적용됩니다(지우개·효과 브러시·데이터 채널·마스크에서는 색을 바꾸지 않습니다). GPU 브러시 미리 보기(`yolu-gpu`의 `brush_dabs`)는 둥근 브러시 끝만 사용하는 별도 경로로, 색 변화를 지원하지 않습니다. 저장과 Undo의 정본은 항상 core의 스트로크입니다.
- 저장은 위의 「저장」 설명과 같습니다. CLIP STUDIO의 `.sut`에 있는 색 변화를 복사합니다([BRUSH_IMPORT.md](BRUSH_IMPORT.md)).

## 분사 효과

그리기 지점 하나마다 브러시가 닿는 원 안에 브러시 끝을 입자로 흩뿌립니다. CLIP STUDIO의 「분사 효과」에 해당합니다. 분사 효과가 없는 브러시(기본값)는 픽셀과 파일 모두 기존과 같습니다.

| 항목 | 범위 | 기본값 |
|---|---|---|
| 입자 크기 | 0 초과 10000 이하(문서 픽셀 단위의 지름) | 10 |
| 브러시 크기에 연동 | 켬·끔 | 끔 |
| 입자 밀도 | 1~100 | 5 |
| 분사 편향 | −1~1 | 0 |
| 입자 방향 | −360~360도 | 0 |
| 방향에 더할 요소 | 없음·선 방향·분사 전체 방향·분사 중심에 집중 | 없음 |
| 방향 무작위 | 0~1(1이면 ±180°) | 끔 |

- 분사 효과를 켠 동안에는 그리기 지점의 분산(`jitter.scatter`)과 개수(`jitter.count`)를 사용하지 않고, 그리기 지점마다 다음 개수의 입자를 놓습니다.
- **입자 수** = `round(粒子密度 × 粒子密度の影響元の係数)`(반올림. 0이면 아무것도 놓지 않습니다).
- 브러시 반지름이 0인 그리기 지점(필압 0·시작과 끝 보정의 끝·크기 흔들림으로 0이 됨)에는 입자를 놓지 않습니다.
- **도달 반지름 R**은 해당 그리기 지점의 dab 반지름(필압·시작과 끝 보정·페이드·크기 흔들림을 적용한 뒤의 반지름)입니다. 입자의 중심은 그리기 지점의 중심에서 각도는 균등하게, 거리는 `R × u^(0.5 × 4^偏向)`(u는 0~1의 균등 난수)인 위치입니다. 편향 0은 원 안에 균등하게, +1은 중심 쪽으로, −1은 가장자리 쪽으로 모입니다. 입자 중심은 항상 반지름 R의 원 안에 있습니다.
- **입자 지름** = 입자 크기 × 입자 크기 영향 요소의 계수입니다. 브러시 크기에 연동을 켜면 여기에 「해당 dab의 지름 ÷ 설정된 브러시 지름」을 곱합니다(필압 등으로 브러시가 가늘어지면 입자도 작아집니다). [최소 1픽셀](#最低-1-ピクセル)을 켠 브러시는 입자 지름도 1픽셀 아래로 내려가지 않습니다.
- **입자 방향** = 입자 방향 + 더할 요소(선 방향: 선의 방향, 분사 전체 방향: 브러시 끝 각도 설정, 분사 중심에 집중: 입자 위치에서 그리기 지점 중심으로 향하는 방향) + 무작위(강도 × 균등한 ±180°)입니다. 브러시 각도·펜의 기울기 방향·각도 흔들림은 입자에 적용하지 않습니다.
- 입자 하나는 dab 하나이며, 불투명도·유량·경도·원형도·질감·브러시 끝 선택과 반전·색(색 흔들림과 [색 변화](#色の変化)의 브러시 끝 색도 입자별)은 기존 dab과 같은 규칙으로 정해집니다.
- [영향 요소](#筆圧の応え)는 입자 크기와 입자 밀도의 두 가지입니다(최솟값은 0~1). 입자 밀도의 난수는 그리기 지점마다, 입자 크기의 난수는 입자마다 뽑습니다.
- 난수는 스트로크의 난수 시드로 결정되는 분사용 수열(흔들림·색·영향 요소·듀얼 브러시·반전·재정렬·색 변화와 별도)에서 그리기 지점마다 입자 밀도의 난수(사용할 때), 입자마다 입자 크기의 난수(사용할 때)·거리·각도·방향의 난수(사용할 때) 순서로 뽑습니다. 2D의 그리기 지점과 3D 면의 dab은 같은 함수로 입자를 만들므로 설정과 입력 지점의 배열이 같으면 같은 입자 배열이 나옵니다(3D에서는 입자 크기의 문서 픽셀을 브러시 반지름과 같은 환산으로 모델 크기로 바꿉니다).
- GPU 브러시 미리 보기(`yolu-gpu`의 `brush_dabs`)는 둥근 브러시 끝만 사용하는 별도 경로로, 분사 효과를 지원하지 않습니다. 저장과 Undo의 정본은 항상 core의 스트로크입니다.
- CLIP STUDIO의 고정점은 지원하지 않습니다. 듀얼 브러시의 두 번째 분사 효과는 [듀얼 브러시](#デュアルブラシ) 절에 설명합니다. 저장은 위의 「저장」 설명과 같습니다. CLIP STUDIO의 `.sut`에 있는 분사 효과를 복사합니다([BRUSH_IMPORT.md](BRUSH_IMPORT.md)).

## 듀얼 브러시

주 브러시 끝과 같은 경로에 두 번째 브러시 끝의 dab을 자체 간격으로 놓으며, 스트로크 동안 픽셀마다 가장 큰 덮임을 누적합니다. 주 dab은 해당 dab 위치까지 놓인 두 번째 누적값과 혼합 모드로 합친 덮임으로 칠합니다. 기존 항목(브러시 끝·반지름·경도·간격·각도·원형도·분산·개수·8가지 모드)에 CLIP STUDIO의 「듀얼 브러시」에 해당하는 다음 항목을 추가했습니다. 추가 항목을 사용하지 않는 브러시(Photoshop ABR에서 가져온 브러시 포함)는 난수 수열·픽셀·파일 모두 기존과 같습니다.

| 항목 | 범위 | 기본값 |
|---|---|---|
| 혼합 모드 | 곱하기·어둡게·오버레이·색상 닷지·색상 번·선형 번·하드 믹스·빼기·일반·더하기(발광)·밝게·스크린·높이(선형) | 곱하기 |
| 주 브러시 크기에 연동 | 켬·끔 | 끔 |
| 농도 | 0~1 | 1 |
| 방향에 더할 요소 | 펜 방향·펜 축 회전·선 방향(여러 개 선택 가능) | 없음 |
| 방향 무작위 | 0~1(1이면 ±180°) | 0 |
| 두 번째 안티앨리어싱 | 없음·약·중·강 | 주 브러시와 같음 |
| 여러 브러시 끝 | 1~256장 | 없음(브러시 끝 1장) |
| 반복 방법 | 주 브러시 끝과 같은 6종 | 무작위 |
| 좌우·상하 반전 | 없음·반전·무작위·되돌아갈 때 반전 | 없음 |
| 브러시 끝끼리 어둡게로 합성 | 켬·끔 | 끔 |
| 종이 질감 | 이미지·농도·확대율·혼합 방식·회전(주 브러시의 종이 질감과 같음) | 없음 |
| 분사 효과 | 입자 크기·입자 밀도·분사 편향·입자 방향(주 브러시의 분사 효과와 같음) | 없음 |

- **혼합 모드**: 주 덮임을 m, 두 번째 누적값을 d(둘 다 0~1)라 할 때, 일반은 m(d를 사용하지 않음), 더하기(발광)는 min(1, m + d), 밝게는 max(m, d), 스크린은 1 − (1 − m)(1 − d), 높이(선형)는 m − d × (1 − m)입니다(기존 8가지를 포함해 m이 0인 곳은 0이며, 결과는 0~1로 제한합니다). 높이(선형)는 CLIP STUDIO의 설명(빼기와 비슷하지만 빼기보다 진함)에 맞춘 근사 수식입니다. 2D와 3D 면은 같은 수식으로 합칩니다.
- **주 브러시 크기에 연동**: 두 번째 반지름에 해당 그리기 지점의 주 브러시 반지름 ÷ 설정된 주 반지름(필압·시작과 끝 보정·페이드·기울기·속도를 적용한 뒤, 크기 흔들림을 적용하기 전)을 곱합니다. 끄면 두 번째 크기는 필압·시작과 끝 보정·페이드의 영향을 받지 않습니다(기존과 같음). [최소 1픽셀](#最低-1-ピクセル)을 켠 브러시는 주 반지름이 하한 때문에 남는 부분도 비율에 포함됩니다(주 선이 남아 있는 동안 두 번째 반지름도 0이 되지 않습니다).
- **농도**: 두 번째 dab이 누적값에 놓는 덮임에 곱합니다.
- **방향**: 두 번째 각도에 선 방향·펜이 기울어진 방향·펜 축 회전·무작위(강도 × 균등한 ±180°)를 주 브러시 끝 각도와 같은 규칙으로 더합니다.
- **[영향 요소](#筆圧の応え)**: 두 번째 크기(반지름에)·농도(농도에)·간격(다음 두 번째 dab까지의 간격에. 하한은 설정 간격의 0.01배)·두께(원형도에. 하한 0.01)의 4가지입니다(최솟값은 0~1). 입력(필압·기울기·속도)은 해당 두 번째 dab이 경로 위에 놓인 지점의 값입니다. 주 항목의 영향 요소와 별도로 유지합니다.
- 난수는 스트로크의 난수 시드로 결정되는 듀얼 영향 요소용 수열(흔들림·색·영향 요소·두 번째 분산·두 번째 브러시 끝·반전·재정렬·분사 효과·색 변화와 별도)에서 두 번째 dab을 놓을 때마다 크기·농도·간격·두께의 난수(사용하는 항목만), 방향의 난수(사용할 때) 순서로 뽑습니다. 2D의 그리기 지점과 3D 면의 dab은 같은 함수로 두 번째 dab을 만들므로 설정과 입력 지점의 배열이 같으면 같은 두 번째 dab 배열이 나옵니다.
- **두 번째 안티앨리어싱**은 2D 캔버스에 적용됩니다. 3D 면의 두 번째 dab은 기존처럼 가장자리를 넓히지 않는 수식을 사용합니다.
- **여러 브러시 끝·반복 방법·반전**: 두 번째 dab마다 주 브러시 끝과 같은 규칙으로 브러시 끝을 선택하고 반전을 정합니다(배치 순서대로 세며, 한 번만 순회·무작위로 한 번 순회는 배열을 모두 사용한 뒤에는 두 번째 dab을 놓지 않습니다).
- **브러시 끝끼리 어둡게로 합성**: 두 번째 누적값은 항상 픽셀마다 덮임이 큰 쪽을 남기므로, 켜거나 꺼도 그리는 방식은 같습니다(가져온 설정을 유지하기 위해 보관합니다).
- **종이 질감**: 주 브러시의 종이 질감이 상한에 적용하는 수식을 두 번째 dab이 누적값에 놓는 덮임에 적용합니다(곱하기는 덮임 × (1 − 농도 × (1 − 질감)), 다른 혼합 방식은 덮임 + (혼합한 값 − 덮임) × 농도). 질감은 캔버스에 고정하며 문서의 픽셀 위치에서 읽습니다(3D 면도 칠하는 텍셀의 문서 픽셀 위치).
- **분사 효과**: 두 번째 dab 위치에 주 브러시의 분사 효과와 같은 규칙으로 입자를 흩뿌립니다(도달 반지름은 두 번째 dab의 반지름, 브러시 크기 연동은 두 번째 반지름 ÷ 설정된 두 번째 반지름, 분사 전체 방향은 두 번째 각도). 켜진 동안에는 두 번째 분산·개수를 사용하지 않습니다. 입자 크기·입자 밀도의 영향 요소는 지원하지 않습니다.
- 두 번째 브러시 끝 선택(난수로 선택할 때)·무작위 반전·재정렬·분사 입자는 스트로크의 난수 시드로 결정되는 두 번째 수열(기존의 어느 수열과도 별도)에서 주 브러시 끝과 같은 순서로 뽑습니다. 여러 브러시 끝·반전·분산을 사용하지 않는 두 번째 브러시는 아무것도 뽑지 않습니다.
- RGB 값 적용·연속 분사·리본은 지원하지 않습니다. 저장은 위의 「저장」 설명과 같습니다. CLIP STUDIO의 `.sut`에 있는 듀얼 브러시를 복사합니다([BRUSH_IMPORT.md](BRUSH_IMPORT.md)).

## 연속 분사

브러시 상세의 「스트로크」 구분에 있는 항목입니다. 켜면 펜(또는 마우스)을 누르는 동안 브러시 지점이 간격만큼 이동하지 않아도 일정한 시간 간격마다 현재 브러시 지점(손떨림 보정 후의 지점)에 dab을 놓습니다. CLIP STUDIO의 「연속 분사」에 해당합니다. 끔(기본값)인 브러시는 픽셀과 파일 모두 기존과 같습니다.

- 거리 간격의 dab은 기존처럼 놓고, 입력 지점에서 거리 기준 dab을 하나도 놓지 않았을 때만 이전 dab 이후의 시간만큼 dab을 추가합니다. 느린 선일수록 dab이 많아져 진해지고, 멈춘 곳은 더 진해집니다. 한 번의 입력에서 추가하는 dab 수에는 상한이 있습니다(입력이 오래 끊겼을 때).
- 시간은 입력 지점의 시각입니다. 시간이 진행되지 않는 입력(같은 지점을 두 번 전달)에서는 dab을 추가하지 않습니다. 입력 지점의 배열이 같으면 픽셀도 같습니다.
- 펜을 멈춘 동안에는 화면의 입력 지점이 오지 않으므로 앱은 새 지점이 오지 않은 프레임에 마지막 지점의 위치·필압·기울기·회전과 현재 시각으로 지점 하나를 전달합니다(2D 캔버스와 3D 면).
- [후처리 보정](#補正)을 켠 동안에는 적용되지 않습니다(항목도 조작할 수 없습니다). 후처리 보정은 펜을 뗀 뒤 입력을 다듬어 다시 그리므로, 시간 기준으로 놓은 dab의 위치가 정해지지 않기 때문입니다.
- 추가한 dab의 시간 간격과 농도를 CLIP STUDIO의 분사와 동일한 값으로 설정한 것은 아닙니다(같은 선이 된다는 보장은 없습니다).
- 저장은 위의 「저장」 설명과 같습니다. CLIP STUDIO의 `.sut`에 있는 연속 분사를 복사합니다([BRUSH_IMPORT.md](BRUSH_IMPORT.md)). 듀얼 브러시의 두 번째 연속 분사는 지원하지 않습니다.

## 리본

브러시 상세의 「스트로크」 구분에 있는 항목입니다. 켜면 브러시 끝 이미지를 선 길이를 따라 이어 붙여 하나의 무늬로 만듭니다. CLIP STUDIO의 「리본」에 해당합니다. 끔(기본값)인 브러시는 픽셀과 파일 모두 기존과 같습니다.

- 이미지의 가로축을 선 방향에, 세로축을 선 폭에 맞춥니다(이미지 높이가 브러시 지름). 선 방향으로 이미지 한 장의 길이는 지름 × 이미지 폭 ÷ 높이입니다. dab 방향은 선 방향만으로 정하며, 브러시 끝 각도·기울기·회전·각도 흔들림은 사용하지 않습니다.
- 각 그리기 지점은 선에서 지금까지 복사한 위치부터 해당 지점의 선 길이 + 간격의 절반까지에 해당하는 띠만 복사합니다. 띠의 경계는 이전 띠의 끝과 같으므로 직선에서는 이음새에 빈틈이나 겹침이 없습니다. 굽은 선에서는 바깥쪽이 띠의 부채꼴 부분만큼 옅어지고 안쪽은 겹칩니다(보장하지 않습니다). 선 방향의 끝에서는 이미지 끝 픽셀을 늘여 읽습니다.
- 무늬의 진행은 복사한 길이를 해당 그리기 지점의 반지름으로 나누어 셉니다. 필압 등으로 두께가 변하면 무늬도 늘어나거나 줄어들면서 이어집니다.
- 여러 브러시 끝은 이미지 한 장을 모두 복사할 때마다 반복 방법의 순서로 다음 한 장을 선택합니다(무작위는 별도의 난수 수열에서 뽑습니다). 띠가 브러시 끝 경계를 넘으면 브러시 끝별 dab으로 나눕니다. 한 번만 순회·무작위로 한 번 순회에서 모두 사용하면 해당 스트로크의 나머지에는 아무것도 놓지 않습니다.
- 누른 지점에서는 선 방향을 아직 모르므로 이미지를 복사하지 않고 그 위치부터 복사를 시작합니다(움직이지 않는 클릭은 아무것도 놓지 않습니다). 시간 기준으로 놓은 dab(연속 분사)은 선 길이가 진행되지 않으므로 아무것도 복사하지 않습니다.
- 분사 효과를 켠 동안과 브러시 끝이 원형(이미지 없음)일 때는 적용되지 않습니다(항목도 조작할 수 없습니다).
- 2D 스트로크와 3D 면 스트로크는 같은 방식으로 띠를 정하며, 3D는 화면 지점으로 정합니다. 결과 바이트는 처리 경로(SIMD)와 스레드 수에 영향을 받지 않습니다.
- 저장은 위의 「저장」 설명과 같습니다. CLIP STUDIO의 `.sut`에 있는 리본을 복사합니다([BRUSH_IMPORT.md](BRUSH_IMPORT.md)). 듀얼 브러시의 두 번째 리본은 지원하지 않습니다.

## 수채 경계

선 가장자리에서 안쪽으로 이어지는 띠를 진하고 어둡게 만듭니다. CLIP STUDIO의 「수채 경계」에 해당합니다. 브러시 상세의 「수채 경계」 구분에서 변경합니다. 수채 경계가 없는 브러시(기본값)는 픽셀과 파일 모두 기존과 같습니다.

| 항목 | 범위 | 기본값 |
|---|---|---|
| 폭 | 0.1~20(문서 픽셀. 3D 면 스트로크에서는 화면 포인트) | 4 |
| 투명도 영향 | 0~1 | 0.3 |
| 명도 영향 | 0~1 | 0.3 |
| 드래그 후 처리 | 켬·끔 | 끔 |
| 흐림 폭 | 0~20(폭과 같은 단위. 드래그 후 처리일 때만 적용) | 0 |

- 가장자리는 스트로크의 덮임(해당 스트로크로 칠한 양)으로 정합니다. 덮임이 있는 픽셀마다 덮임이 0인 픽셀(스트로크 바깥)까지의 최단 거리 d(픽셀 중심 사이. 캔버스 바깥은 바깥으로 세지 않음)를 측정하고, **가장자리 강도** e = (폭 + 1 − d) ÷ 폭을 0~1로 제한합니다. 가장 바깥 픽셀(d = 1)에서 1, 폭만큼 안으로 들어가면 0입니다. 띠의 형태는 s = e^(3/4)입니다.
- **투명도 영향**: 픽셀의 불투명도 A(덮임. 스트로크 불투명도가 상한)를 min(1, A + 3 × 투명도 영향 × s)로 합니다.
- **명도 영향**: 칠하는 색의 R·G·B에 1 − 0.75 × 명도 영향 × s를 곱합니다(알파는 바꾸지 않습니다).
- 계수(3과 0.75)와 띠의 형태는 `.sut`에서 가져온 브러시의 선이 내보낸 선에 가까워지는 값입니다.
- 픽셀은 스트로크 전의 색·덮임·픽셀별 색(색 변화의 「그리기 지점별」·색 혼합·스텐실 색)으로부터 dab과 같은 합성 방식으로 다시 계산합니다. 투명도 영향과 명도 영향이 0이면 수채 경계가 없는 브러시와 바이트가 같습니다. 선택 영역의 양과 투명 픽셀 잠금도 dab과 동일하게 적용됩니다.
- **드래그 후 처리 끔**: 그리는 동안 가장자리가 보입니다. 입력(지점·직선의 끝·3D 면의 dab)마다 그때까지 칠한 상자를 폭만큼 넓힌 범위를 다시 계산합니다. 가장자리는 덮임만으로 정해지므로 입력을 나누는 방식에 관계없이 그리기를 마친 픽셀은 같습니다. 현재 면에서 바탕을 읽는 색 혼합(겹치기·늘이기)은 그리는 동안 붙인 가장자리를 바탕에 넣지 않고 가장자리가 없는 값으로 읽습니다(가장자리의 어둠이 다음 dab의 물감에 들어가 누적되지 않도록 하기 위함입니다).
- **드래그 후 처리 켬**: 그리는 동안 가장자리를 붙이지 않고 스트로크를 확정할 때 한 번만 스트로크가 닿은 범위에 가장자리를 붙입니다. 흐림 폭이 있으면 가장자리 강도 e를 반지름 = 흐림 폭인 박스 블러(끝의 1픽셀은 소수 가중치)로 가로·세로 방향으로 고르게 합니다(바깥 픽셀은 e = 1로 셉니다). 흐림 폭이 0이면 그리는 동안 붙였을 때와 같은 픽셀입니다.
- 가장자리도 스트로크와 함께 한 단계의 Undo로 처리합니다. 그리던 중 취소하면(Escape·포커스를 잃었을 때) 가장자리도 남지 않습니다. 가장자리를 계산하는 임시 영역도 스트로크 예산에 포함하며, 초과하면 스트로크를 취소합니다.
- 색 채널을 색으로 칠하는 브러시에만 적용됩니다(지우개·효과 브러시·색이 아닌 채널·마스크에는 적용되지 않습니다). 2D 대칭·3D 대칭 복사본에도 모든 복사본을 합친 덮임의 가장자리가 붙습니다.
- **3D 면 스트로크**: 폭과 흐림 폭을 화면 포인트로 해석하고, 중심 텍셀 하나의 화면 크기(면적으로 맞춘 변 길이)를 처음 알 수 있었던 dab의 값으로 텍셀 단위로 바꿉니다(스트로크 동안 고정. 변환한 값은 최대 64텍셀. 그 이전 dab에 붙인 가장자리도 정해진 값으로 다시 붙입니다). 가장자리는 텍스처 위에서 정하므로 UV 아일랜드의 경계에도 가장자리가 생깁니다.
- 입력마다 다시 계산하는 범위가 크면 타일별 값을 워커에서 구합니다(쓰기는 타일 순서로 하나의 스레드에서 수행). 결과 바이트는 처리 경로(SIMD)와 스레드 수에 영향을 받지 않습니다.
- GPU 브러시 미리 보기(`yolu-gpu`의 `brush_dabs`)는 수채 경계를 지원하지 않습니다. 저장과 Undo의 정본은 항상 core의 스트로크입니다.
- 저장은 위의 「저장」 설명과 같습니다. CLIP STUDIO의 `.sut`에 있는 수채 경계를 복사합니다([BRUSH_IMPORT.md](BRUSH_IMPORT.md)).

## 선 넘침 방지

참조 레이어(「레이어」 패널의 오른쪽 클릭 메뉴 「참조 레이어」로 표시한 레이어. 채우기 도구의 「비슷한 색」에서 「참조: 참조 레이어」와 같은 표시)의 선을 넘어 칠하지 않도록 합니다. CLIP STUDIO의 「참조 레이어의 선을 벗어나지 않기」에 해당합니다. 끔(기본값)인 브러시는 픽셀과 파일 모두 기존과 같습니다.

| 항목 | 범위 | 기본값 |
|---|---|---|
| 참조 레이어의 선을 벗어나지 않기 | 켬·끔 | 끔 |
| 색 허용 오차 | 0~100% | 12.5 |
| 영역 확대·축소 | 켬·끔 | 끔 |
| 영역 확대·축소량 | −100~100픽셀 | 2 |
| 확대·축소 방식 | 사각형·원형·가장 진한 픽셀까지 | 가장 진한 픽셀까지 |

- **참조 합성 결과**: 스트로크의 첫 dab 전에 표시된 레이어(그룹은 하위 항목도, 클리핑한 레이어는 바탕도)만 보이게 한 합성 결과(그리는 채널)를 고정합니다. 내용 필터나 생성기가 있는 레이어는 이를 적용한 뒤의 픽셀(흐림으로 퍼진 부분도)을 선으로 읽습니다(채우기 도구의 「비슷한 색」과 같은 합성입니다). 그리는 중 표시나 레이어가 변해도 해당 스트로크는 처음의 합성 결과를 유지합니다(참조 레이어 자체에 그려도 칠한 색으로 범위가 변하지 않습니다). 현재 문서에 표시된 레이어가 없으면 선 넘침 방지는 적용되지 않고 일반적으로 그립니다.
- **목표 색**: 스트로크의 첫 dab 중심 픽셀에서 참조 합성 결과의 색입니다.
- **dab별 범위**: dab을 감싸는 상자(캔버스 안)에서 dab 중심 픽셀부터 목표 색과 비슷한 픽셀을 상하좌우로 따라간 곳에만 칠합니다. 비슷한 색은 알파와 R·G·B 각각의 차이가 색 허용 오차 × 255 ÷ 100(반올림) 이하인 색입니다(채우기 도구의 「비슷한 색」의 RGB 차이와 같은 수식). 중심 픽셀이 목표 색과 비슷하지 않으면 해당 dab은 아무것도 칠하지 않습니다. 따라서 선을 가로질러 그리면 선 앞뒤 모두 칠하고 선 위의 픽셀은 칠하지 않습니다. 선 근처의 가장자리에는 선 너머 dab의 몫이 닿지 않으므로 조금 가늘어집니다.
- **영역 확대·축소**: dab의 범위를 설정량(반올림한 픽셀)만큼 넓힙니다. 원형은 설정량을 반지름으로 한 원(선택 영역 확장과 같은 원), 사각형은 가로세로 모두 설정량까지, 가장 진한 픽셀까지는 원형으로 넓힌 범위 안에서 참조의 농도(불투명도 × (255 − 휘도))가 낮아지지 않는 이웃으로만 넓힙니다(선의 가장 진한 곳에서 멈추며 선 너머의 열린 곳으로 나가지 않습니다). 음수 설정량은 범위 밖(선과 따라가지 못한 곳)에서 설정량만큼 떨어진 곳까지 줄입니다(dab 상자 바로 바깥의 선도 봅니다. 가장 진한 픽셀까지의 축소 방식은 원형과 같습니다). 넓힌 범위도 dab 형태 안쪽에만 칠합니다.
- 범위는 칠함·칠하지 않음의 두 가지이며, 범위 안쪽 픽셀은 선 넘침 방지를 사용하지 않을 때와 같은 수식으로 칠합니다. 상자 안의 참조가 모두 목표 색과 비슷한 dab은 범위를 만들지 않고 그립니다. 선택 영역·투명 픽셀 잠금·예산·그리는 중 취소는 기존 스트로크와 같으며 한 번의 실행 취소로 되돌립니다. 고정한 합성 결과에서 읽은 타일(최대 32 MiB까지 기억하며 넘으면 다시 읽음)과 범위를 구하는 작업 공간은 스트로크 예산에 포함합니다.
- 2D 대칭은 복사본마다 복사된 dab의 중심에서 범위를 구합니다(목표 색은 원본 dab에서 정한 색).
- 3D 면의 dab은 면의 UV가 가리키는 픽셀(캔버스 픽셀)에서 같은 작업을 수행합니다. dab의 픽셀을 상하좌우로 연결된 덩어리로 나누고, 중심 픽셀이 포함된 덩어리는 중심부터, 다른 덩어리(UV 이음새 너머·3D 대칭 복사본)는 덮임이 가장 큰 픽셀부터 따라갑니다(3D 문지르기·복제는 모든 덩어리에서 덮임이 가장 큰 픽셀부터). 패스 도구의 패스에는 적용되지 않습니다.
- 3D 면의 흐리기 dab은 안쪽 픽셀(중심을 포함한 덩어리는 중심부터)과 가장자리 픽셀(모든 덩어리에서 덮임이 가장 큰 픽셀부터)을 따로 구합니다. 따라서 같은 덩어리 안에서도 안쪽과 가장자리의 추적 시작점이 달라 선 근처에서는 범위가 2D 흐리기와 같다고 보장할 수 없습니다.
- 브러시 상세의 「선 넘침 방지」 구분에서 변경합니다(끄면 다른 항목은 조작할 수 없습니다. 영역 확대·축소량과 방식은 영역 확대·축소를 켰을 때만 가능). 저장은 위의 「저장」 설명과 같습니다. CLIP STUDIO의 `.sut`에 있는 선 넘침 방지를 복사합니다([BRUSH_IMPORT.md](BRUSH_IMPORT.md)). 벡터 중심선까지 칠하는 설정은 지원하지 않습니다.

## 브러시 끝 반복과 반전

이미지 브러시 끝이 여러 개 있는 브러시는 「브러시 끝」의 「반복 방법」에서 dab마다 어느 브러시 끝을 사용할지 정합니다.

| 반복 방법 | 선택 방식 |
|---|---|
| 반복 | 순서대로 사용하고 마지막 다음에는 처음으로 돌아감 |
| 왕복 | 순서대로 사용하고 끝에서 방향을 바꿔 돌아감(끝의 브러시 끝을 2번 연속 사용하지 않음) |
| 반복 안 함 | 순서대로 사용하고 마지막 브러시 끝을 계속 사용 |
| 무작위 | dab마다 무작위로 선택 |
| 한 번만 순회 | 순서대로 한 바퀴 돈 뒤 멈추고 이후에는 아무것도 놓지 않음 |
| 무작위로 한 번 순회 | 스트로크 난수 시드로 정한 순서로 한 바퀴 돈 뒤 멈춤 |

- 반전(좌우·상하 각각)은 「없음」「반전」「무작위」「되돌아갈 때 반전」입니다. 무작위는 dab마다 각 축에 대해 정하고, 되돌아갈 때 반전은 왕복에서 브러시 끝 번호가 되돌아가는 dab만 반전합니다.
- 「브러시 끝끼리 어둡게로 합성」(「스트로크」 구분)을 켜면 스트로크 안에서 dab이 겹치는 곳의 농도를 더하지 않고, 이전 값과 해당 dab만으로 도달하는 값 중 큰 쪽을 사용합니다. 색을 칠하는 브러시와 지우개에 적용되며 문지르기·복제·흐리기는 기존과 같습니다.
- 무작위·무작위로 한 번 순회·무작위 반전의 난수는 각각 별도의 수열에서 뽑으므로 이를 사용하지 않는 브러시의 선은 이전과 바이트가 같습니다. 2D와 3D는 같은 선택 방식을 거칩니다.
- 왕복의 끝 처리와 무작위로 한 번 순회의 정렬 방식이 CLIP STUDIO와 같은 결과를 내는지는 확인하지 않았습니다(가져올 때 「비슷한 동작」으로 알립니다).

## 종이 질감

「종이 질감」 구분의 이미지(질감)는 dab의 덮임에 적용합니다. 「종이 질감 회전」(도 단위. 0은 회전하지 않음)을 설정하면 이미지를 회전하여 베이크하는 대신 캔버스 픽셀을 반대 방향으로 회전한 위치에서 질감을 읽습니다. 회전 방향이 CLIP STUDIO와 같은지는 확인하지 않았습니다.

CLIP STUDIO의 `.sut`에 있는 종이 질감 밝기·대비는 가져올 때 질감 이미지에 베이크합니다(되돌릴 수 없습니다). 수식은 「덮임에 밝기 ÷ 100을 더하고, 0.5를 중심으로 ×(1 ＋ 대비 ÷ 100)만큼 넓힌 뒤 0~1로 제한」하며, 그다음 반전을 적용합니다. CLIP STUDIO와 같은 결과인지는 확인하지 않았으므로 가져올 때 「비슷한 동작」으로 알립니다([BRUSH_IMPORT.md](BRUSH_IMPORT.md)).

## 시작과 끝 보정

「시작과 끝 보정」 구분의 시작·끝 길이는 선의 시작과 끝을 가늘게 합니다. 계수는 「선 길이 ÷ 시작 길이」(끝은 「끝까지의 길이 ÷ 끝 길이」)입니다.

- **영향 대상**: 시작과 끝 보정을 적용할 항목을 영향 요소와 같은 8가지(크기·불투명도·유량·경도·원형도·질감 농도·물감 양·물감 농도)에서 선택하고, 항목마다 최솟값(0~100%)을 정합니다. 적용한 항목의 계수는 「최솟값 ＋ (1 − 최솟값) × 시작과 끝 보정 계수」입니다. 기본값은 크기만 선택·최솟값 0입니다.
- **클릭과 `Shift` 직선**: 누른 지점에서 min(브러시 반지름, 시작 길이)보다 멀어지지 않은 채 뗀 스트로크(펜 탭의 흔들림 포함)는 시작과 끝 보정을 적용하지 않고 전체 지름으로 놓습니다. `Shift` 직선은 시작 보정을 적용하지 않으며, 직선을 닫은 뒤 끝점에서 해당 경계보다 멀어지지 않고 떼면 끝 보정도 적용하지 않습니다. 길이 단위는 2D에서 문서 픽셀, 3D에서 화면 포인트입니다.
- 시작 보정이 있는 브러시는 손으로 그린 선인지 클릭인지 정해질 때까지(누른 지점에서 경계를 넘어 멀어질 때까지) dab을 놓지 않고 기다리므로 선의 첫 구간이 화면에 나타나는 시점이 그만큼 늦어집니다. 시작과 끝 보정이 없는 브러시는 기다리지 않습니다.

## 최소 1픽셀

브러시 설정의 「브러시 크기」에서 「최소 1픽셀」을 켜면 필압·페이드·기울기·속도·시작과 끝 보정·크기 흔들림으로 가늘어진 뒤의 dab 지름에 1픽셀 하한을 적용합니다(지름이 0이 되는 dab도 1픽셀로 남으므로 필압 0의 선과 시작·끝 보정의 끝부분도 끊기지 않습니다). 끔(기본값)은 기존과 같은 스트로크입니다.

- 자유롭게 그리는 스트로크(2D 캔버스와 3D 면)에 적용됩니다. 패스 도구(`P`)의 패스는 패스의 브러시 항목 설정(`BrushSettings`)만으로 그리므로 이 설정은 적용되지 않으며, 패스 도구를 선택한 동안에는 체크할 수 없습니다(패스 프리셋과 `.ylp`의 패스에도 포함되지 않습니다).
- 1픽셀은 문서 픽셀입니다. 3D 면에 칠할 때는 닿은 면의 텍스처 픽셀(텍셀)로 세며, 반지름을 텍셀의 절반 이상으로 합니다(텍스처 픽셀 밀도가 낮은 면에서도 1텍셀은 칠할 수 있습니다). 브러시 크기(문서 픽셀)를 모델 단위로 바꾸는 환산은 기존과 같습니다.
- dab 간격은 공칭 크기(필압 등으로 가늘어지기 전)로 정해지는 기존 수식을 유지합니다. 하한으로 1픽셀이 된 dab은 간격을 좁히지 않고 배치됩니다.
- 작은 dab의 안티앨리어싱 수식(확장과 농도)은 하한을 적용한 뒤의 크기에 적용됩니다. 지름 1픽셀 브러시로 그린 것과 같은 결과입니다.
- 저장은 위의 「저장」 설명과 같습니다. CLIP STUDIO의 `.sut`에 있는 `BrushAtLeast1Pixel`을 복사합니다([BRUSH_IMPORT.md](BRUSH_IMPORT.md)).

## 필압 응답

브러시 항목(크기·불투명도·유량·경도·원형도·질감 농도, 색 혼합의 양·농도, [색 변화](#色の変化)의 색조·채도·명도·보조 그리기색 혼합률)마다 입력(필압·기울기·속도·무작위)을 계수로 변환합니다. 입력마다 사용 여부·최솟값·곡선을 가집니다(항목 오른쪽 영향 요소 버튼으로 여는 「◯◯ 영향 요소 설정」 창에서 변경합니다. 기울기에만 최댓값도 있습니다). `係数 = 最小値 + (1 − 最小値) × 曲線(x)`(x는 입력값 0~1). 최솟값은 x = 0일 때의 계수(0~1. 색조·채도·명도 영향 요소만 −1~1), 곡선은 점을 지나는 단조 3차 에르미트 보간(점은 2~16개, 양 끝은 입력 0과 1, 간격은 0.02 이상, 값은 0~1)입니다. 최솟값 0·직선인 기본값은 입력 자체를 반환하며, 응답을 추가하기 전과 픽셀까지 바이트 단위로 같습니다. 사용 중인 입력의 계수를 곱합니다. 사용할 입력은 항목마다 정하며, 끈 입력의 최솟값과 곡선은 남습니다.

- **기울기 최댓값**(기울기 입력만. 0~100%, 기본값 100%): 계수는 `最小値 + (最大値 − 最小値) × 曲線(x)`가 됩니다(x는 수직일 때 1, 완전히 눕혔을 때 0). 최댓값이 100%인 응답은 최댓값을 갖기 전과 수식·픽셀이 같습니다. CLIP STUDIO의 `.sut`에 있는 기울기 최댓값(영향 요소 선두의 11번째 정수)은 100%까지 복사하며, 100%를 넘는 값은 100%로 바꾸고 가져오기 알림에 「기울기 최댓값」을 표시합니다. 기울기 곡선의 x 방향(CLIP STUDIO 화면 눈금은 왼쪽이 수평)은 실제 CLIP STUDIO로 그린 선과 비교하지 않았습니다.
- **부호가 있는 항목**(색조·채도·명도)의 영향 요소 무작위는 처음 켤 때 최솟값을 −100%로 설정합니다(기준에서 ±값의 변동).

## 화면상의 크기로 지정

브러시 설정의 「브러시 크기」에서 「화면상의 크기로 지정」을 켜면 지름이 문서 픽셀이 아닌 화면 포인트 크기가 됩니다. 스트로크를 시작할 때 `半径 = 画面上の大きさ ÷ 表示倍率`로 문서 픽셀로 변환해 고정합니다(표시 배율은 문서 픽셀 1개가 화면에서 몇 포인트인지). 스트로크 중 표시를 확대·축소해도 시작한 스트로크는 변하지 않습니다. 끔(기본값)은 기존과 같은 스트로크입니다.

- 2D 캔버스의 표시 배율은 캔버스 1픽셀의 화면 크기(포인트)입니다. 3D 면에서는 시작 지점 아래의 면에서 문서 픽셀 1개(브러시 반지름 단위)가 화면에서 몇 포인트인지를 사용합니다. 브러시 커서 원도 해당 크기입니다.
- 화면 포인트의 기준이 물리 픽셀인지 포인트인지는 HiDPI 실제 장치에서 확인하지 않았습니다.
- 패스 도구의 패스는 `Controls`가 없으므로 이 설정은 적용되지 않습니다(패스 도구를 선택한 동안에는 누를 수 없습니다).
- 저장은 위의 「저장」 설명과 같습니다. CLIP STUDIO의 `.sut`에 있는 `BrushSizeSyncViewScale`을 복사합니다([BRUSH_IMPORT.md](BRUSH_IMPORT.md)).

## 보정

브러시 상세의 「보정」 구분에 있는 항목입니다. 손떨림 보정(실의 길이)과 곡선은 기존 항목이며, 다음 3가지가 추가되었습니다. 모두 끔(기본값)인 브러시는 기존과 같은 스트로크입니다. 시작과 끝 보정·손떨림 보정과 마찬가지로 그리는 사람의 설정이며, 브러시에 포함되는 것은 가져온 브러시가 가진 부분뿐입니다(위의 「저장」). 2D 캔버스와 3D 면 모두에 적용됩니다. 길이와 속도의 단위는 2D에서 문서 픽셀, 3D에서 화면 포인트입니다(손떨림 보정의 실 길이와 같음). 속도는 영향 요소의 속도와 같은 브러시 속도를 스트로크의 「최대 속도」로 나눈 비율입니다.

- **속도에 따른 손떨림 보정**과 **보정 유형**: 실의 길이를 직전 브러시 지점의 속도로 바꿉니다. 「빠르게 그릴 때 약하게 보정」은 멈춰 있을 때 원래 실 길이를 유지하고 속도에 따라 짧게 합니다. 「느리게 그릴 때 보정」은 멈춰 있을 때 원래 실 길이를 유지하고 속도에 따라 짧게 하며, 느린 범위를 넘어서는 빠른 곳에서는 보정하지 않습니다.
- **끝 처리**(0~100%): 필압을 뺄 때 두께 등 필압에 따라 변하는 항목이 필압을 따라가는 속도를 억제합니다. 필압 감소는 브러시가 이동한 길이당 상한까지이며, 끝 처리 값이 클수록 상한은 작고 100%에서 가장 작아집니다(필압을 빠르게 뺀 선의 끝이 가늘어지지 않고 굵은 채로 끝까지 늘어납니다). 필압이 높아질 때는 그대로 따라갑니다. 끝 처리 0%는 기존과 같습니다. 시작과 끝 보정(끝 길이에 따라 가늘어짐)과는 별도의 방식으로, 둘 다 사용하면 둘 다 적용됩니다.
- **후처리 보정**(강도 0~100·속도에 따른 조정·표시 배율에 따른 조정): 그리는 동안에는 보정 없는 선을 보여주고 펜을 뗄 때 입력 지점의 배열을 다듬어 스트로크를 다시 그린 뒤 확정합니다. 다시 그린 결과는 그리기 전부터의 한 번의 Undo로 처리하며, 그리는 중 취소(Escape·포커스 상실)는 아무것도 남기지 않습니다. 다듬는 방법: 강도에 비례하는 허용 거리보다 작은 흔들림을 버리고(남길 점을 원래 선에서 허용 거리보다 벗어나지 않는 꺾은선의 꼭짓점으로 선택), 해당 꺾은선을 허용 거리와 같은 폭으로 부드럽게 합니다. 곧은 변은 그대로 곧게 유지하고 모서리는 허용 거리만큼의 둥근 정도만 남깁니다. 시작점과 끝점은 움직이지 않습니다. Shift 직선의 모서리에서 나누며 모서리는 움직이지 않습니다. 필압·시각·기울기·회전은 원래 지점의 값을 사용합니다.
  - 속도에 따른 조정: 빠르게 그린 곳일수록 속도에 따라 허용 거리를 줄입니다.
  - 표시 배율에 따른 조정: 허용 거리를 화면 포인트로 정합니다(화면을 확대해 그리면 문서 픽셀 기준으로 작아지고, 축소해 그리면 커집니다). 표시 배율은 화면상의 크기로 지정과 마찬가지로 스트로크 시작 시의 값입니다. 끄면 허용 거리를 문서 픽셀로 정합니다.
  - 3D 면에서는 화면 지점의 배열을 다듬은 뒤 면에 다시 그립니다(펜을 뗀 뒤 다음 칠하기에서 그때까지의 픽셀을 되돌린 다음 다시 그리며, 나머지는 다른 입력처럼 프레임마다 칠합니다).
  - 입력 지점은 펜을 뗄 때까지 기억하므로 기억한 분량도 한 스트로크의 예산에 포함합니다(예산을 넘으면 스트로크를 취소합니다). 자를 따라 그리는 스트로크에서는 손떨림 보정과 마찬가지로 후처리 보정을 끕니다.
  - 다시 그리기는 CPU에서만 수행합니다(저장과 Undo의 정본은 항상 core의 스트로크입니다).

CLIP STUDIO의 `.sut` 가져오기는 보정 유형·끝 처리·후처리 보정(베지어 곡선 제외)을 복사하며, 모서리 날카롭게 하기는 알림만 표시합니다([BRUSH_IMPORT.md](BRUSH_IMPORT.md)).

<a id="消すモード"></a>

## 지우기 모드

「지우기」 구분의 「지우기」 체크(및 「지우기 모드」 명령. 기본 키는 없으며 설정 화면에서 할당)를 켠 동안에는 브러시 도구에서도 현재 브러시 그대로 지웁니다(2D 캔버스와 3D 면. 빠른 마스크일 때는 선택 펜의 지우기 쪽). 브러시에 저장하지 않으며 도구나 브러시를 바꿔도 유지되는 임시 전환입니다. 펜의 지우개 끝과 마찬가지로 스트로크를 시작할 때 지우기 상태로 고정합니다. 효과 브러시(흐리기·문지르기·복제)는 지우기 모드 동안 일반 형태로 지웁니다.

<a id="ツールプロパティに出す行"></a>

## 도구 속성에 표시할 항목

브러시 상세 각 항목의 맨 왼쪽 눈 버튼으로 해당 항목을 도구 속성 패널에도 표시할지 정합니다. 표시할 항목은 브러시마다 기억하며 브러시와 함께 저장합니다(위의 「저장」. 「기본값으로 되돌리기」는 값만 되돌리고 눈 표시는 바꾸지 않습니다). 도구 속성 항목의 순서는 상세 구분 순서입니다. 눈 표시가 없는 이전 형식의 브러시와 기본 브러시는 이전 도구 속성에 표시되던 항목(지름·불투명도·유량·경도·간격·손떨림 보정. 효과 브러시에서는 흐림 반지름·문지르기 강도)에 눈 표시가 켜진 상태로 열립니다.


<a id="グループと並び"></a>

## 그룹과 순서

사용자 브러시 파일(`brushes/brush-<番号>.ylbrush`)의 `group=`은 해당 브러시의 원래 그룹입니다. 어느 도구의 어느 그룹에 어떤 순서로 표시할지는
파일이 아닌 설정 폴더의 `tools.json`(도구 순서. [SUBTOOLS.md](SUBTOOLS.md)의 「도구 순서」)에 들어 있습니다. `group=`은
처음 순서로 되돌릴 때의 위치, 순서에 없는 새 파일(이전 앱이 추가한 파일 등)을 추가할 위치, 순서를 지원하지 않는 이전 앱(0.4.x까지)의 정렬 방식에만 사용합니다.

순서에 있는 브러시는 하나마다 파일 하나가 있으며, 내장 브러시는 설정 등록·이름 변경 전까지 내장 브러시를 가리킨 채로 유지되고 두 번째 위치에 놓으면 복사 파일을 만듭니다.
순서에서 제거해도 파일은 삭제되지 않습니다. 파일 형식(버전 1~4)은 순서 기능을 위해 바꾸지 않았습니다.
