# 경로


경로 도구 (`P`)는 점을 차례로 지나는 편집 가능한 곡선을 2D 캔버스와 모델 표면에 그립니다. 점이나 설정을 수정할 때마다 곡선에서 픽셀을 다시 그립니다. 키 조작은 [GUIDE_KEYS.md](GUIDE_KEYS.md)에 있습니다.

<a id="パスを引く"></a>

## 경로 그리기

1. 왼쪽 도구 모음에서 경로 도구 (`P`)를 선택하고 그릴 레이어를 선택합니다.
2. 캔버스 또는 3D 보기의 모델 표면을 눌러 첫 점을 놓습니다. 일반 레이어를 선택한 상태라면 그 위에 새 경로 레이어가 만들어집니다. 경로 레이어나 채우기 레이어를 선택한 상태라면 해당 레이어의 경로가 됩니다.
   점을 놓기 전에 레이어만 만들려면 “레이어” 메뉴 (오른쪽 클릭 메뉴에도 있음)의 “새 경로 레이어”를 사용합니다. 선택한 레이어 바로 위에 점이 없는 경로를 가진 레이어를 만들고 경로 도구로 전환합니다. 처음 놓는 점 (2D 또는 3D 모두)은 그 레이어의 경로가 됩니다.
3. 계속 누르면 끝에 점이 추가됩니다. 곡선 위를 누르면 해당 구간에 점이 삽입되며, 점을 잡아 드래그하면 이동합니다.
4. 선택한 점은 `Delete` (`Backspace`)로 삭제합니다. 선택한 점이 없다면 마지막 점을 삭제합니다.
5. `Enter`로 해당 경로의 편집을 마칩니다. 다음에 누른 점은 같은 레이어에서 새 경로를 시작합니다. `Esc`는 드래그 중이라면 드래그를 취소하고, 그렇지 않으면 점 선택을 해제하며, 선택한 점도 없다면 편집을 마칩니다.

점이 3개 이상이면 도구 모음의 “닫기”로 고리를 만들 수 있습니다 (시작점과 끝점이 같은 위치가 됩니다). 고리는 “열기”로 되돌릴 수 있습니다. `Shift`를 누른 채 드래그하면 사각형으로 둘러싼 점들을 함께 선택할 수 있으며, 두께·모서리·핸들·삭제가 모두에 적용됩니다.

점 조작 1회가 실행 취소 1회에 해당합니다. 점 드래그는 놓을 때 다시 그리며, 포커스를 잃으면 그 시점까지 확정합니다. 캔버스 밖에는 점을 놓을 수 없습니다. 경로 레이어에는 직접 그릴 수 없으며, 잠긴 레이어나 그리는 도중에는 편집을 거부합니다.

<a id="点の太さを変える"></a>

## 점의 두께 바꾸기

도구 모음의 “두께”는 선택한 점의 두께 (필압 대신 사용)입니다. 점마다 다르게 설정하면 곡선을 따라 부드럽게 변합니다. 경로 브러시에서 “두께로 지름 변경”, “두께로 불투명도 변경”, “두께로 흐름 변경”을 켜면 그리는 크기와 농도에 영향을 줍니다.

<a id="角と取っ手で曲がりを決める"></a>

## 모서리와 핸들로 굽힘 조절

점의 앞뒤는 처음에는 부드럽게 연결됩니다. 선택한 점에서 다음과 같이 바꿀 수 있습니다.

- “모서리”: 해당 점에서 곡선을 꺾습니다. 점을 더블 클릭해도 전환됩니다.
- “핸들”: 점에 핸들이 나타나며 핸들을 드래그해 굽힘을 정합니다. 표시하는 것만으로 모양이 바뀌지는 않습니다. 드래그하면 반대편 핸들이 방향을 맞춰 따라옵니다. 드래그를 시작한 뒤 `Alt`를 누르면 움직인 쪽만 바뀝니다 (누른 채 시작하면 시점 조작이 됩니다). `Ctrl`을 누른 채 드래그하면 양쪽을 같은 비율로 늘립니다.
- 같은 버튼을 다시 누르면 부드러운 점으로 돌아갑니다.

<a id="1-つのレイヤーに何本ものパスを置く"></a>

## 1개 레이어에 여러 경로 배치

도구 속성의 “경로”에는 레이어의 경로가 위에서부터 나열됩니다 (위쪽이 나중에 그려짐). 행을 누르면 해당 경로를 편집하며, 더블 클릭하면 이름을 바꿀 수 있습니다. 눈 아이콘으로 숨긴 경로는 픽셀에 반영되지 않지만 점과 설정은 남습니다.

아래 아이콘은 새 경로 (`Enter`)·경로 복제·위로 이동·아래로 이동·경로 삭제입니다. 오른쪽 클릭 메뉴에는 이름 바꾸기·표시·복사·붙여넣기·복제·설정 붙여넣기·위치 붙여넣기·위로 이동·아래로 이동·경로 삭제가 있습니다. 복사한 경로는 다른 레이어에 붙여넣을 수 있으며, 경로가 없는 레이어에 붙이면 새 경로 레이어가 됩니다. “설정 붙여넣기”는 브러시와 그릴 채널 조합만, “위치 붙여넣기”는 점의 위치만 복사합니다.

1개 레이어에는 경로를 최대 256개 둘 수 있으며, 모두 2D이거나 모두 3D여야 합니다. 나중 경로가 위에 겹쳐지고, 지우개 경로는 앞선 경로의 픽셀을 지웁니다.

<a id="パスで何を描くか"></a>

## 경로로 그릴 내용

“경로 브러시”의 “종류”에서 곡선을 따라 그릴 대상을 선택합니다.

| 종류 | 그리는 내용 |
|---|---|
| 스트로크 | 원형 브러시 팁이나 이미지 브러시 팁을 곡선을 따라 나열합니다 |
| 리본 | 에셋 이미지를 곡선을 따라 나열합니다. “배치 방식”에는 이미지를 1개씩 놓는 “나열” (간격은 “나열 간격”)과 경로 전체에 이미지 1장을 늘이는 “늘이기”가 있습니다. 에셋에 이미지가 없으면 선택할 수 없습니다 |
| 채우기 | 닫힌 곡선의 안쪽을 채웁니다. 열린 경로는 끝점에서 시작점까지 닫아 채웁니다 |
| 문지르기 | 곡선을 따라 앞쪽 픽셀을 끌어옵니다. “강도”를 변경할 수 있습니다 |
| 지우개 | 곡선을 따라 지웁니다 |

브러시 팁은 “브러시 팁”에서 원형·내장 팁·현재 브러시 팁 중 선택합니다. 이미지 팁에서는 “각도”와 곡선의 진행 방향에 맞춰 회전하는 “경로 따르기”를 사용할 수 있습니다. 지름 (리본은 “너비”)·경도·앤티앨리어싱·간격·불투명도·흐름은 경로별로 보유합니다.

“브러시 사용”은 현재 브러시와 도구 속성의 “그릴 채널”에서 선택한 채널 조합으로 경로를 다시 그립니다. 조합을 선택했다면 경로 1개가 여러 채널을 한 번에 그립니다 ([GUIDE_FILL.md](GUIDE_FILL.md)). 종류·브러시·채널 조합·브러시 팁·깊이·대칭 켜짐 여부는 “프리셋”에서 이름을 지정해 저장할 수 있습니다 (설정 폴더의 `path_presets/`).

<a id="3d-のモデルの上のパス"></a>

## 3D 모델 위의 경로

3D 보기에서도 같은 조작으로 경로를 그릴 수 있습니다. 점은 모델의 삼각형에 연결되며 `.ylp`에 저장됩니다. 다른 텍스처 세트의 면과 모델 밖에는 점을 놓을 수 없습니다.

- 경로는 포즈를 적용하지 않은 형상 (FBX의 휴지 포즈) 위에 그리므로, 포즈를 변경해도 UV 위의 두께와 간격은 바뀌지 않습니다.
- 곡선에서 표면을 찾는 깊이는 처음에는 점 사이 거리와 브러시 크기로 결정됩니다. “투영 깊이 자동 설정”을 끄면 “투영 깊이”를 직접 정할 수 있습니다. 얕게 설정하면 표면에서 떨어진 부분은 그리지 않습니다.
- 채우기 종류는 모든 점이 1개의 UV 아일랜드 안에 있을 때만 그릴 수 있습니다.
- 다른 모델에서 그린 경로에는 “다른 모델에 그린 경로입니다”가 표시되며 편집할 수 없습니다.
- 다시 그릴 때는 현재 3D 보기에서 숨긴 면 (숨기기 모드. 해당 보기의 눈이 열려 있을 때)과 눈을 닫은 텍스처 세트의 면을 건너뛰고 그 아래의 면에 그립니다 ([GUIDE_3D.md](GUIDE_3D.md)의 “면 숨기기 (숨기기 모드)”). 점의 위치는 바뀌지 않습니다.
- 모델을 교체하면 가까운 동일 머티리얼의 면에 다시 연결해 그립니다. 다시 연결할 수 없는 경로는 현재 픽셀을 남기고 경로를 제거합니다 (“모두” 잠근 레이어의 경로만 이전 모델과의 연결을 유지합니다). 결과는 건수와 첫 번째 이유로 알립니다.

<a id="対称と向き"></a>

## 대칭과 방향

“대칭”을 켜면 반사한 경로도 함께 그립니다. 켤 때 해당 경로의 레이어에서 보이고 적용 중인 대칭자의 값을 경로에 복사합니다 (2D 경로는 2D 대칭자, 3D 경로는 3D 대칭자. 적용 중인 대칭자가 없으면 켤 수 없음). 선대칭 (대각선·6개 이상의 선도 포함)과 회전 대칭을 모두 복사할 수 있습니다. 3D 경로에는 선대칭 2개 (거울 평면 1개)의 대칭자만 복사할 수 있으며, 포즈가 적용된 동안에는 켤 수 없습니다. 경로가 자체 값을 보유하므로 나중에 자를 움직여도 그려진 경로는 바뀌지 않습니다. 반사한 쪽에는 별도 점이 없으며 그릴 때 생성합니다. “방향 반전”은 점 순서를 뒤집어 브러시 팁이나 리본의 방향을 바꿉니다.

<a id="塗りつぶしレイヤーにパスを置く"></a>

## 채우기 레이어에 경로 배치

채우기 레이어를 선택하면 속성의 “경로” 섹션에 있는 “경로 추가”에서 경로 도구로 새 경로를 시작할 수 있습니다. 경로는 채우기와 효과 위에 겹쳐지며 효과의 영향을 받지 않습니다. 채우기 레이어의 경로는 픽셀로 변환할 수 없습니다.

<a id="画素にする"></a>

## 픽셀로 변환

도구 모음의 “래스터화” (레이어 오른쪽 클릭의 “경로 래스터화”도 동일)는 현재 픽셀을 남기고 경로를 제거해 일반 레이어로 되돌립니다.

<a id="古いバージョンや-unity-へ渡す"></a>

## 이전 버전 또는 Unity로 전달

경로 2개 이상·경로 종류·브러시 팁·대칭·모서리나 핸들·채우기 레이어의 경로 중 하나라도 사용한 `.ylp`는 독립 실행형 0.4.x와 0.4.x까지의 Unity 브리지에서 열 수 없습니다. 전달 시 주의 사항은 [GUIDE_FILES.md](GUIDE_FILES.md)에 있습니다.
