# 키 목록


키보드와 마우스·펜 조작 목록입니다. 키와 마우스 조합은 앱의 “편집 → 설정…”에서 “단축키” 구분을 열어 확인하고 바꿀 수 있습니다(아래의 “단축키 바꾸기”). 아래 “기본 할당” 표는 앱의 표에서 만든 변경 전 할당입니다. Mac에서는 표의 `Ctrl`을 `Command`로 읽어 주세요(메뉴에도 `Cmd`로 표시). 단, 모드 파이 메뉴의 `Ctrl+Tab`은 Mac에서도 `Control`입니다.

<a id="ショートカットを変える"></a>

## 단축키 바꾸기

“편집 → 설정…”(`Ctrl+,`) 왼쪽에서 “단축키”를 누르면 키와 마우스 조합을 확인하고 바꿀 수 있습니다. 아래에 나열된 구분(어디서나·시점/페인트/편집/포즈/숨기기/진행 중 조작/파이 메뉴)을 선택하고 오른쪽 표에서 작업 이름·키·마우스를 확인합니다.

| 작업 | 입력 |
|---|---|
| 키 바꾸기 | 키 필드를 누르고 지정할 키를 누릅니다(보조 키만으로는 확정되지 않음). `+` 필드로 키를 하나 더 추가합니다. 누르는 동안만 적용되는 키(`Space` 등)와 진행 중 조작 키는 보조 키 없는 키 하나만 가능합니다 |
| 취소 / 키 해제 | 입력 대기 중 `Esc` / `Backspace` |
| 마우스 조합 바꾸기 | 마우스 필드를 누른 뒤 해당 필드 위에서 보조 키와 함께 지정할 버튼(왼쪽·오른쪽·가운데·뒤로·앞으로)을 누릅니다. 버튼과 보조 키가 모두 바뀝니다. 스텐실 회전 중 각도 간격 행은 보조 키만 바뀝니다(보조 키 없이 누르면 확정되지 않음) |
| 이름으로 찾기 / 키로 찾기 | 표 위 필드에 이름 입력 / “키로 찾기”를 누르고 찾을 키를 누릅니다(모든 구분에서 해당 키의 행만 표시. 다시 누르면 돌아감). 설정 창 맨 위의 “설정 찾기”는 다른 설정 항목을 찾는 필드이며 이 표를 필터링하지 않습니다 |
| 한 행을 기본값으로 / 전체를 기본값으로 | 바꾼 행 오른쪽 끝의 표시 / 아래의 “기본값으로 되돌리기” |
| 내보내기 / 불러오기 | 아래의 “내보내기…” / “불러오기…”(키·마우스·파이 메뉴 전체. 불러오기는 현재 변경을 대체합니다. 알 수 없는 작업은 건너뛰고 개수를 알림) |

- 같은 구분·같은 상황에서 같은 키가 다른 작업을 가리키면 해당 행이 빨갛게 표시되고 상대 작업 이름이 도구 설명에 나옵니다. 충돌이 남아 있는 동안 변경한 할당은 적용되지만 파일에는 저장하지 않습니다(아래쪽 바에 이유 표시).
- 모드 구분(페인트·편집·포즈·숨기기)의 키가 “어디서나” 구분의 같은 키보다 먼저 처리되는 것은 충돌이 아닙니다(도구 설명에 우선 처리되는 작업 표시).
- 마우스에서는 2D·3D 표시를 움직이는 작업(움직이지 않고 놓았을 때의 작업 포함)을 보조 키 없는 왼쪽 버튼으로 지정하면 그리기와 충돌합니다. 2D 캔버스는 표시 이동·선택 영역 생성 방식·스포이트 순서로 누름을 확인하므로 같은 조합뿐 아니라 앞 작업의 조합에 보조 키만 추가한 조합을 뒤 작업에 지정해도 충돌합니다(예: 회전이 `Alt`＋왼쪽 버튼일 때 선택 영역 추가를 `Alt+Shift`＋왼쪽 버튼으로 설정).
- 마우스 조합은 표시되지 않은 보조 키를 추가해 눌러도 일치합니다(`Alt`＋왼쪽 버튼 회전은 `Alt+Shift`＋왼쪽 버튼으로도 회전). 움직이지 않고 놓았을 때의 작업과 2D 스포이트는 지정한 보조 키가 정확히 일치할 때만 적용됩니다.
- 클립보드(복사·잘라내기·병합하여 복사·붙여넣기) 키와 `Esc`·`Enter`·`Backspace`의 정해진 동작, 편집 모드에서 오브젝트를 선택하는 왼쪽 클릭은 바꿀 수 없습니다.
- 변경한 할당은 설정 폴더의 `keymap.json`에 기본값과 달라진 부분만 저장합니다. 읽을 수 없는 `keymap.json`이 있으면 기본 키로 시작하여 알리고 파일은 지우지 않고 남깁니다(다음 저장 때 `keymap.broken.json`으로 옮긴 뒤 작성. 같은 이름이 있으면 `keymap.broken-2.json`처럼 번호 추가).
- “파이 메뉴” 구분에서는 파이를 선택하고 이름·여는 키·8곳의 항목(작업·다른 파이·yolu-ops 명령·기록한 액션)을 정합니다. `+`로 파이를 추가하고 휴지통 표시로 삭제합니다(기본 제공 모드·시점 파이는 내용만 바꿀 수 있음).
- 메뉴·도구 설명의 키는 변경한 할당을 따라갑니다(현재 모드에서 적용되는 키만 표시).
- 도구 키(페인트 구분의 도구 행)는 행 오른쪽 필드(제목은 “마우스·동작 방식”)에서 키마다 동작 방식을 선택할 수 있습니다.
  - **누르면 전환**(기본값): 누르면 해당 도구로 전환합니다. 놓아도 돌아가지 않습니다.
  - **누르는 동안만**: 누르는 동안만 해당 도구가 되며 놓으면 누르기 전 도구(브러시 설정 포함)로 돌아갑니다.
  - **짧게 누르면 전환·길게 누르면 누르는 동안만**: 0.25초 이내에 놓으면 해당 도구를 유지합니다. 0.25초보다 길게 누른 뒤 놓거나 누르는 동안 그리면 놓았을 때 누르기 전 도구로 돌아갑니다.
  - 그리는 도중 놓으면 해당 선(선택 모양·그라데이션·도형·자 드래그 포함)을 다 그린 뒤 돌아갑니다(2D·3D, 마우스·펜 모두. 다각형 선택은 닫거나 취소할 때까지 돌아가지 않음). 같은 선을 그리는 중 같은 키를 다시 누르면 그대로 이어갑니다. 누르는 동안 도구 모음·다른 키·파이 메뉴·브러시 목록에서 도구나 브러시를 선택하면 돌아가지 않고 그 선택을 유지합니다. 누르는 동안 다른 “누르는 동안만” 키를 누르면 쌓이며, 나중에 누른 키를 놓으면 먼저 누른 키의 도구로, 먼저 누른 키를 먼저 놓았으면 나중 키를 놓을 때 최초 도구로 돌아갑니다. 모드를 바꿀 때는 놓은 것으로 처리하고 누르기 전 도구로 돌아간 뒤 전환합니다. 창이 포커스를 잃거나 메뉴·대화 상자가 열리거나 텍스트 입력 필드를 사용하기 시작하면 놓은 것으로 처리합니다. 이미 선택한 도구의 키를 눌러도 아무것도 바뀌지 않습니다. 누르는 동안 돌아갈 도구 버튼에 점이 붙습니다. `Shift` 같은 보조 키가 포함된 키는 보조 키를 먼저 놓아도 본 키를 놓을 때까지 유지됩니다.

## 모드와 파이 메뉴

모드는 페인트·편집·포즈·숨기기의 4가지입니다. 그리기는 페인트 모드에서만 가능합니다. 도구 키, 브러시 크기(`[` / `]`), 색 교환과 기본 색(`X` / `D`), 경로와 점 그라데이션 키, 빠른 마스크(`Shift+Q`), 이동·변형 화살표 키, 화면 색 가져오기(Windows), 픽셀을 바꾸는 키(선택 영역 지우기의 `Delete`, 잘라내기의 `Ctrl+X`, 붙여넣기의 `Ctrl+V`, 아래와 병합의 `Ctrl+E`, 보이는 레이어 병합의 `Ctrl+Shift+E`)는 페인트 모드에서만 적용됩니다. 메뉴와 버튼 조작은 모든 모드에서 사용할 수 있습니다(메뉴에도 현재 모드에서 적용되는 키만 표시).

| 작업 | 입력 |
|---|---|
| 모드 파이 메뉴 | `Ctrl+Tab`(포인터 위치에 열림. 마우스 버튼을 누르는 동안과 드래그 도중에는 열리지 않음) |
| 파이 메뉴 항목 선택 | 키를 누른 채 항목 방향으로 움직인 뒤 놓습니다. 바로 놓으면 열린 상태를 유지하므로 항목을 클릭합니다. `1`~`8`(위에서 시계 방향)로도 선택할 수 있습니다 |
| 파이 메뉴 닫기 | `Esc`·오른쪽 클릭·가운데 클릭. 키를 길게 누른 뒤 움직이지 않고 놓아도 닫힙니다 |

<a id="編集とポーズのモード"></a>

## 편집과 포즈 모드

편집 모드에서는 3D 뷰의 흰 표시로 채우기 투영 상자·데칼, 그라데이션 데칼, 필터 도형, 점 그라데이션 점, 3D 경로, 3D 자를 선택하고 `G`·`R`·`S`로 움직입니다. 포즈 모드에서는 선택한 본을 움직입니다. 2D 캔버스에서는 움직일 수 없습니다(보기 전용).

| 작업 | 입력 |
|---|---|
| 오브젝트 선택(편집) | 3D 뷰의 표시 클릭(해당 오브젝트의 레이어도 선택). 겹친 표시는 같은 곳을 다시 클릭하면 다음 오브젝트를 선택합니다. 아무것도 없는 곳을 클릭하면 해제합니다 |
| 이동 / 회전 / 크기 조절 | `G` / `R` / `S`(포인터 위치에서 시작하며 마우스 이동량에 따라 변경. 점은 이동만 가능). 도구 바의 이동·회전·크기 조절을 선택하고 표시(포즈 모드는 선택한 본의 면)에서 왼쪽 드래그해도 같습니다(놓으면 확정. 펜도 가능) |
| 축 지정 | `X` / `Y` / `Z`(다시 누르면 오브젝트 방향의 축, 3번째는 축 없음). `Shift+X` / `Shift+Y` / `Shift+Z`는 해당 축을 제외한 평면입니다. 투영 상자·데칼·도형·본의 크기 조절 축은 처음부터 오브젝트 방향의 축입니다(다시 누르면 축 없음) |
| 값 입력 | 숫자·`.`·`-`(부호 전환)·`Backspace` |
| 확정 / 취소 | 왼쪽 클릭 또는 `Enter` / 오른쪽 클릭 또는 `Esc`(취소하면 시작 전으로 돌아가며 실행 취소 기록에도 남지 않음) |
| 스냅 | `Ctrl`을 누르는 동안(기본값은 이동 0.1·회전 5°·크기 조절 0.1. 옵션 바에서 변경 가능). `Shift+Tab`으로 항상 스냅(이때 `Ctrl`은 반대로 작용) |
| 위치 / 회전 / 크기 되돌리기 | `Alt+G` / `Alt+R` / `Alt+S` |
| 선택한 오브젝트 표시 숨기기 / 모두 표시(편집) | `H` / `Alt+H` |
| 선택한 오브젝트 삭제(편집) | `Delete`(투영 상자·데칼과 점 그라데이션의 마지막 점은 지울 수 없음. 계속 눌러도 하나만 삭제) |
| 도형 핸들 숨기기 / 표시(편집) | `Q` |

숨기기 모드에서는 `H`로 선택한 UV 아일랜드 면을 숨기고 `Alt+H`로 모두 표시하며 `Ctrl+A`·`Ctrl+D`로 모두 선택·선택 해제합니다(아래 표의 “숨기기”. 사용법은 [GUIDE_3D.md](GUIDE_3D.md)의 “면 숨기기(숨기기 모드)”).

한 번의 이동·회전·크기 조절이 한 번의 실행 취소 단위입니다(본은 포즈 실행 취소 한 단계). 3D 경로는 확정할 때 이동한 점을 가까운 표면의 점으로 다시 배치합니다(그린 면과 같은 방향을 향한 면만. 얇은 판 앞면에 그린 경로는 뒷면으로 이동하지 않음). 표면에서 너무 멀리 떨어진 점이 있으면 확정할 수 없으므로 계속 움직이거나 취소하세요. 숨긴 레이어(그룹 눈 아이콘을 끈 경우 포함)의 오브젝트는 선택하거나 움직일 수 없습니다.

## 그릴 때의 보조 키

| 작업 | 입력 |
|---|---|
| 이전 스트로크 끝에서 직선 그리기 | 브러시·지우개에서 `Shift` ＋클릭(이전 점이 없으면 `Shift`를 누른 채 드래그하여 방향을 45° 단위로 고정. 2D·3D, 마우스·펜 모두) |
| 복제 원본 지정 | 복제 브러시에서 `Alt` ＋클릭(움직이지 않고 놓음. 2D·3D 모두. 움직이면 2D는 회전하고 3D는 아무 동작도 하지 않음) |
| 모든 도구에서 색 가져오기(스포이트) | 2D는 오른쪽 버튼 누르기(누른 채 움직이면 포인터 견본 색이 따라옴. 놓은 곳의 색을 가져옴. `Esc`로 취소). 3D는 오른쪽 버튼을 움직이지 않고 놓기(움직이면 시점 회전만 수행). 폴리곤 채우기에서 오른쪽 버튼은 아일랜드 메뉴입니다 |
| 도형을 45° 단위·정사각형·정원으로 만들기 / 중심에서 그리기 | `Shift` / 드래그 시작 후 `Alt` |
| 자에 스냅 켜기·끄기 | `Ctrl+1` |
| 특수 자에 스냅 켜기·끄기 | `Ctrl+2` |
| 스냅할 특수 자 전환 | `Ctrl+4`(포인터가 올라가 있는 뷰 공간의 특수 자를 순환. 어느 뷰 위에도 없으면 마지막으로 도구를 눌러 그리기 시작한 뷰. 그것도 없으면 그릴 대상이 3D 뷰뿐일 때는 3D, 그렇지 않으면 2D) |
| 그리는 스트로크·도형이나 자 드래그·선택 진행 중·경로 점 이동 취소 | `Esc`(진행 중인 작업이 없으면 선택한 점을 해제하고 점도 없으면 선택 영역 해제. 입력 필드·메뉴·창이 사용 중이면 그쪽이 우선) |

<a id="視点の操作と-alt"></a>

## 시점 조작과 `Alt`

시점 조작은 2D와 3D에서 일관되게 맞췄습니다. `Alt`는 버튼을 누르는 순간 함께 누르고 있으면 시점 조작(2D는 `Alt`＋왼쪽 드래그로 표시 회전, 3D는 `Alt`＋오른쪽 드래그로 스냅 회전)이며, 버튼을 누른 뒤 누르면 해당 도구의 보조 동작(도형·사각형·타원의 “중심에서”, 경로 핸들 꺾기 등)입니다. 2D에서 `Alt`를 누른 채 선택 영역이나 도형 드래그를 시작하면 표시 회전이 됩니다. 3D의 `Alt`＋왼쪽 드래그는 시점도 움직이지 않고 그리기도 시작하지 않습니다(움직이지 않고 놓아 복제 원본을 정하는 동작은 기존과 같음).

다음 조합은 더 이상 사용할 수 없습니다. 3D의 `Shift` ＋오른쪽 드래그와 `Alt`＋`Shift`＋왼쪽 드래그(이동. `Shift`를 눌러도 오른쪽 드래그는 회전), 2D의 `R` ＋왼쪽 드래그와 `Shift` ＋가운데 버튼 드래그(회전. `Shift`를 눌러도 가운데 버튼 드래그는 이동), 2D의 `Alt` ＋클릭 임시 스포이트(`Alt` ＋왼쪽 드래그는 회전으로, 스포이트는 오른쪽 버튼으로 변경), 3D의 `Alt` ＋왼쪽 드래그 회전(스냅 회전은 `Alt`＋오른쪽 드래그로 변경. 자유 회전은 오른쪽 드래그), 3D에서 `Alt`를 누른 채 오른쪽 버튼을 누르기 시작하고 오른쪽 버튼을 유지하면서 `Alt`를 놓은 뒤 `W`/`A`/`S`/`D`/`Q`/`E`로 시점을 움직이는 조작(해당 누름은 스냅 회전. 오른쪽 버튼만으로 시작한 회전 중 이동은 사용 가능).

## 상황별 키와 추가 설명

- 선택 영역 도구는 누르기 시작할 때 `Shift`(추가)·`Ctrl`(제거)·`Shift+Ctrl`(교차)를 함께 누르면 생성 방식이 바뀝니다(옵션 바에서도 선택 가능. 선택 펜은 `Shift`가 선택 펜, `Ctrl`이 선택 지우개). 누르기 시작한 뒤의 `Shift`는 가로세로 비율 고정, `Alt`는 중심에서 만들기입니다.
- 다각형 선택은 `Enter`(시작점 또는 더블클릭도 가능)로 닫고 `Backspace`로 마지막 점을 지웁니다. 이동·변형은 `Enter`로 확정, `Esc`로 취소하며 화살표 키로 1픽셀(`Shift`와 함께 누르면 10픽셀) 움직입니다.
- `Ctrl+J`는 선택 영역이 있으면 선택 영역을 복사하여 새 레이어로 만들고, 없으면 레이어를 복제합니다.
- 경로 도구의 `Delete` / `Backspace`는 선택한 점(없으면 마지막 점)을 지웁니다. 점 그라데이션의 점을 선택하고 있으면 해당 점을 지웁니다.
- 레이어 목록에서는 `Ctrl` ＋클릭으로 추가·해제, `Shift` ＋클릭으로 범위 선택, `Ctrl+Shift` ＋클릭으로 범위를 추가 선택합니다.
- 확대·축소는 휠로도 가능합니다. `Ctrl+Space` ＋왼쪽 드래그는 좌우로 움직이며 누른 점이 중심입니다(움직이지 않고 놓으면 확대, `Alt`도 누르면 축소).
- 2D 표시 회전은 15° 단위이며 `Shift`도 누르면 자유롭게 회전합니다. 3D 스냅 회전(`Alt`＋오른쪽 드래그)은 누른 곳에서 약 40포인트 움직이면 드래그한 방향(가로와 세로 중 큰 쪽)으로 현재 시점에서 90° 옆의 축 시점(정면·후면·오른쪽·왼쪽·위·아래)으로 전환합니다. 한 번의 드래그에서는 한 번만 전환하며 계속 회전하려면 놓았다가 다시 누릅니다.
- 표시를 오른쪽으로 돌리는 것은 `^` 문자이며 `=` 키로도 회전합니다(배열에 따라 키 위치가 다르기 때문).
- 3D 뷰에서 오른쪽 버튼을 누르는 동안 `W` / `S`·`A` / `D`·`Q` / `E`로 시점을 앞뒤·좌우·아래위로 움직입니다(`Shift`로 빠르게. 이 동안 해당 키는 도구 전환 등에 사용되지 않음). 정투영 중 `W` / `S`는 확대·축소입니다.
- 3D 축 시점(정면·후면·오른쪽·왼쪽·위·아래)과 정투영 전환은 시점 파이 메뉴와 3D 뷰 오른쪽 위 축 표시로 사용합니다(둘 다 기본 키가 할당되어 있지 않음). 축 시점을 선택하거나 스냅 회전으로 축 시점으로 바꾸면 정투영이 되며 축에서 벗어나면 원근으로 돌아갑니다([GUIDE_3D.md](GUIDE_3D.md)의 “축 시점과 정투영”).
- 편집 모드의 `H`는 선택한 오브젝트 표시를 숨기므로 2D 표시의 좌우 반전은 “보기 → 표시 좌우 반전”에서 사용합니다.
- 스텐실은 `Y`를 누른 채 왼쪽 드래그로 회전(`Shift`로 15° 단위), 가운데 버튼 드래그 또는 `Ctrl` ＋왼쪽 드래그로 이동, 오른쪽 드래그 또는 `Alt` ＋왼쪽 드래그로 크기를 바꿉니다(2D·3D 모두). `N`을 누르는 동안은 사용하지 않습니다.
- 왜곡 도구에는 기본 키가 없습니다.
- `Tab`은 메뉴 바와 뷰만 남겨 UI를 숨기며 다시 누르면 복원합니다([GUIDE_START.md](GUIDE_START.md)의 “UI 숨기기”).
- 목록(레이어·브러시·에셋 등) 위에서 오른쪽 버튼을 누른 채 움직이면 목록이 스크롤됩니다. 왼쪽 도구 모음 위에서 오른쪽 버튼을 누른 채 움직이면 포인터가 지나간 도구를 선택합니다. 움직이지 않고 놓으면 오른쪽 클릭 메뉴가 열립니다.
- “지우기 모드”와 “이전과 같은 설정으로 내보내기”에는 기본 키가 없습니다(“단축키”에서 할당 가능).

<a id="ペン"></a>

## 펜

사이드 버튼은 오른쪽 버튼으로 취급합니다(2D에서는 색 가져오기, 3D에서는 회전·움직이지 않고 놓으면 색 가져오기. 2D 폴리곤 채우기에서는 아무 동작도 하지 않음). `Space`·`Ctrl+Space`는 마우스 왼쪽 버튼과 같은 동작을 합니다. `Alt`를 누른 펜촉 접촉은 2D에서는 표시 회전이며 3D에서는 시점을 돌리지도 그리지도 않습니다. 3D 스냅 회전은 `Alt`를 누른 채 사이드 버튼으로 접촉합니다. 그리는 것은 `Ctrl`도 사이드 버튼도 누르지 않은 펜촉(및 지우개 끝)뿐이며, `Shift`를 누른 펜촉은 직선이 됩니다(2D·3D 모두).

- 패널을 되돌리려면 “창 → 패널 배치 되돌리기”를 사용하세요.
- `.ylp`는 창에 끌어놓아도 열 수 있습니다.
