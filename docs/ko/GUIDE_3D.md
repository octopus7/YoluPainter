# 3D 뷰와 모델


모델을 3D 뷰에서 보고 움직이며 표면에 그리는 방법을 설명합니다. FBX 열기, 포즈 지정, 메시 맵 베이크, 겹친 UV 처리, Unity에서 열기도 다룹니다.

<a id="3d-ビューを動かす"></a>

## 3D 뷰 움직이기

오른쪽 드래그로 회전합니다. `Alt`＋오른쪽 드래그는 스냅 회전이며, 드래그한 방향(가로와 세로 중 큰 쪽)으로 현재 시점에서 90° 옆의 축 시점(정면·후면·오른쪽·왼쪽·위·아래)으로 전환합니다. 한 번의 드래그에서는 한 번만 전환하며 계속 회전하려면 놓았다가 다시 누릅니다(축 시점이 아니면 가장 가까운 축 시점에서 옆으로 이동). `Alt`＋왼쪽 드래그는 3D 뷰에서 아무 동작도 하지 않습니다. 오른쪽 버튼을 누르는 동안 `W` / `S`로 앞뒤, `A` / `D`로 좌우, `Q` / `E`로 아래위로 시점을 움직일 수 있습니다(`Shift`로 빠르게). 가운데 버튼 드래그 또는 `Space`＋왼쪽 드래그로 이동하고 휠 또는 `Ctrl+Space`＋왼쪽 드래그로 확대·축소합니다. 오른쪽 버튼을 움직이지 않고 놓으면 해당 면의 값을 그리기 색으로 가져옵니다(스포이트. 폴리곤 채우기에서는 아일랜드 메뉴). 3D 뷰 위에서 `.`을 누르면 현재 텍스처 세트의 면을 화면에 맞추며, 오른쪽 위의 “모델 전체가 보이는 위치로 되돌리기”는 전체를 맞춥니다. 전체 키는 [GUIDE_KEYS.md](GUIDE_KEYS.md)에 있습니다.

<a id="軸の視点と正投影"></a>

### 축 시점과 정투영

3D 뷰 오른쪽 위 아이콘 아래에 축 표시(X는 빨강·Y는 초록·Z는 파랑 원)가 있습니다. 축 이름이 있는 원을 누르면 해당 축 쪽에서 보는 시점이 됩니다(X는 오른쪽, Y는 위, Z는 정면 시점. 이름 없는 작은 원은 반대쪽인 왼쪽·아래·후면). 가운데 원을 누르면 원근과 정투영을 전환합니다(정투영 중에는 가운데 원이 흰색으로 채워짐). 표시 위를 드래그하면 회전합니다. 조명·환경·톤 매핑 설정 패널을 열고 있는 동안은 표시가 나오지 않습니다. 시점 파이 메뉴에도 정면·후면·오른쪽·왼쪽·위·아래 시점과 정투영 전환이 있습니다(파이를 여는 키는 기본으로 할당되어 있지 않습니다. [GUIDE_KEYS.md](GUIDE_KEYS.md)의 “단축키 바꾸기”).

축 시점을 선택하거나 스냅 회전(`Alt`＋오른쪽 드래그)으로 축 시점으로 전환하면 정투영이 됩니다. 회전하여 축 방향에서 벗어나면 원근으로 돌아갑니다. 가운데 원·파이 메뉴로 전환한 투영은 회전해도 돌아가지 않습니다. 설정 창의 “3D 뷰”에서 “축 방향에서 정투영”을 끄면 축 방향에서도 원근을 유지합니다.

정투영에서는 멀리 있는 것과 가까이 있는 것이 같은 크기로 보이며, 브러시 원도 깊이에 관계없이 같은 크기로 표면에 그립니다. 그리기·색 가져오기·선택·경로 점 배치는 정투영에서도 보이는 위치에 맞습니다. 휠 확대·축소는 보이는 범위 크기를 바꾸고, 오른쪽 버튼을 누른 동안의 `W` / `S`도 앞뒤 이동 대신 확대·축소가 됩니다. 원근으로 되돌리면 그때의 크기를 유지하며 원근이 됩니다. 시점(방향과 투영)은 파일에 저장하지 않습니다.

## 모델 열기

모델이 없는 동안 3D 뷰에는 “새 프로젝트…”(파일 메뉴의 새 프로젝트와 같음)와 “테스트 큐브 불러오기”가 표시됩니다. 모델은 새 프로젝트와 프로젝트 설정의 “모델 선택…”, 포즈 패널의 “FBX 열기”, 창에 .fbx 끌어놓기 중 하나로 엽니다. Unity에서 열려면 이 페이지 마지막의 Live Link를 보세요.

모델의 머티리얼마다 텍스처 세트가 연결되며 “텍스처 세트” 패널에서 전환합니다. 그릴 수 있는 것은 현재 세트의 머티리얼 면뿐입니다(여러 머티리얼이 있는 세트에서는 그중 어느 면에나 그릴 수 있음).

## 3D 표시 바꾸기

3D 뷰 왼쪽 위 드롭다운(“3D 표시”)에서 표시할 대상을 선택합니다. 3D 뷰를 추가하면 뷰마다 선택할 수 있습니다(아래의 “3D 뷰 추가하기”).

- 머티리얼(PBR)(Unity Standard와 같은 BRDF. Roughness·Metallic·Normal·Emission이 보임)
- 중립
- 채널만(Color·Roughness·Metallic·Normal·Emission·Height와 현재 텍스처 세트의 사용자 채널). 사용자 채널은 이름으로 찾으며 같은 이름의 채널이 없는 텍스처 세트의 면은 체크무늬로 표시됩니다
- 메시 맵만(베이크한 메시 맵. 모든 텍스처 세트의 면에 해당 세트에서 베이크한 맵을 표시하며, 베이크하지 않은 세트의 면은 체크무늬로 표시)

오른쪽 위에는 아이콘 2개가 있습니다.

- “조명·환경·톤 매핑”: 설정 패널을 엽니다.
- “모델 전체가 보이는 위치로 되돌리기”.

설정 패널은 3개 탭으로 나뉩니다.

- “표시”: 환경(없음·하늘·스튜디오. 밝기·회전·배경에 표시·흐림), 조명(강도·방위·높이·그림자·부드러움), 톤 매핑(없음·뉴트럴·ACES, 노출)과 “기본값으로 되돌리기”. 조명 강도 1은 Unity의 흰색·강도 1 방향광과 같은 밝기입니다.
- “화질”: 안티앨리어싱과 블룸.
- “시점”: 회전 중심과 줌 중심.

3D 뷰에 업로드하는 표시용 텍스처는 UV 밖으로 색을 확장하므로 멀리서 보아도 아일랜드 가장자리가 번지지 않습니다(저장과 내보내기는 바뀌지 않음). GPU 메모리 예산 등으로 3D 이미지가 축소되어 있으면 오른쪽 위에 표시가 나옵니다. 재질 표현의 자세한 비교 방법과 속도는 [PREVIEW.md](PREVIEW.md)에 있습니다.

## 3D 뷰 추가하기

3D 뷰 탭 줄 오른쪽의 “＋”(“3D 뷰 추가”)로 3D 뷰를 추가할 수 있습니다(전체 최대 8개). 추가한 뷰는 다른 패널처럼 도크 안에서 나누어 배치하거나 별도 창으로 꺼내거나 ×로 닫을 수 있습니다(첫 번째 3D 뷰는 닫을 수 없음). 다른 방향에서 동시에 보거나 결과 채널과 메시 맵을 나란히 보는 용도입니다.

- 뷰가 2개 이상이면 탭 제목은 “3D 뷰·머티리얼”, “3D 뷰 2·거칠기”처럼 뷰 이름과 표시 종류가 됩니다.
- 카메라(시점·정투영)와 표시 종류(왼쪽 위 드롭다운)는 뷰마다 따로 가집니다. 조명·환경·톤 매핑·화질 설정은 모든 뷰가 공유합니다.
- 모델·텍스처 세트·칠하기 설정·포즈는 공통이며 어느 뷰에서 그려도 결과는 모든 뷰에 나타납니다.
- 입력을 받는 것은 포인터가 올라가 있는 뷰입니다(뷰가 2개 이상이면 해당 뷰 가장자리에 가는 선 표시). 스트로크 도중 다른 뷰로 나가도 스트로크는 시작한 뷰의 카메라로 끝까지 그립니다.
- 저장하는 것은 뷰 배치(화면 배치)뿐입니다. 뷰별 카메라와 표시 종류는 저장하지 않으므로 다시 열면 메시 맵·사용자 채널 표시가 머티리얼로 돌아가 있을 수 있습니다.

오른쪽 도크의 “머티리얼” 패널에서 “외관”은 텍스처 세트마다 “표준(PBR)” 또는 “lilToon”을 선택합니다. lilToon으로 설정하면 lilToon 외관을 재현하여 그리며 색 설정·노멀 맵·광택 설정·확장 설정 값을 필드에서 수정할 수 있습니다. “lilToon 템플릿”은 켠 기능의 마스크로 사용할 사용자 채널을 만들고 할당합니다.

Unity에서 받은 머티리얼 값은 “Unity 값”에 표시되며, “Unity에 맞추기”로 필드에서 바꾼 값을 제거하고 Unity 값으로 그립니다. 셰이더 이름이 비슷하다는 이유만으로 lilToon으로 그리지 않습니다([PREVIEW.md](PREVIEW.md)).

## 3D 모델에 그리기

3D에는 페인트 모드에서 그립니다([GUIDE_START.md](GUIDE_START.md)의 “모드”). 3D 뷰에서 사용할 수 있는 도구는 브러시·지우개·스포이트·버킷·폴리곤 채우기·사각형 선택·타원형 선택·올가미·다각형 선택·자동 선택·선택 펜·ID 색으로 선택·경로·그라데이션·도형·자입니다(경로는 [GUIDE_PATHS.md](GUIDE_PATHS.md), 그라데이션·도형·자는 아래의 “화면에서 드래그하여 그리기”, 사각형 선택부터 4가지와 자동 선택·선택 펜은 “화면에서 드래그하여 선택하기”). 이동과 변형·왜곡·텍스트는 2D 캔버스에서만 사용합니다. 빠른 마스크가 켜져 있는 동안 3D 뷰의 브러시와 지우개도 2D 캔버스처럼 선택 펜·선택 지우개로 동작하여 누른 면의 텍스처 픽셀을 선택 영역에 추가하거나 제거합니다(지름·경도·불투명도·필압은 현재 브러시 사용. 한 스트로크가 한 번의 실행 취소. 레이어 픽셀은 바꾸지 않음). 빨간 오버레이는 3D 뷰 표면 위에도, 2D 캔버스에도 표시됩니다([GUIDE_SELECT.md](GUIDE_SELECT.md). 3D 뷰 표면의 선택 영역은 아래의 “화면에서 드래그하여 선택하기”).

브러시 설정은 3D 뷰에서도 2D 캔버스와 같은 수식으로 적용됩니다. 지름·경도·안티앨리어싱(띠 너비는 텍스처 픽셀)·유량·불투명도·필압, 이미지 브러시 끝(각도·원형도·좌우 반전과 상하 반전·선 방향 따르기), 스트로크(손떨림 보정·곡선), 시작과 끝·페이드, 펜 기울기·회전·속도, 화면상의 크기로 지정(시작점의 면에서 화면 크기로 결정), 흔들림, 텍스처, 듀얼 브러시, 색·색 흔들림(“찍기마다 적용” 포함)·색 혼합·지우개·스텐실, 효과 브러시(흐림·손가락·복제)가 적용됩니다.

- 정렬이 “카메라”(기본값)일 때 브러시 끝 모양은 화면에서 결정하고 카메라에서 표면으로 투영하여 칠합니다(표면 방향을 따라 붙이는 방식이 아님). “Tangent | Wrap”일 때는 브러시 끝 모양을 표면을 따른 거리로 읽어 표면에 맞춰 붙입니다.
- 찍기는 2D와 마찬가지로 선 길이에 따라 간격마다 배치합니다. 입력 점이 촘촘하게 오거나 성기게 와도 스트로크 농도와 페이드 길이는 같습니다. 간격은 구간 시작 면의 깊이에서 지름을 화면 크기로 환산하여 결정합니다(정렬이 “Tangent | Wrap”이면 표면이 시선에 대해 기울수록 화면 간격을 줄여 표면을 따른 간격으로 만듦).
- 손떨림 보정·시작과 끝·속도에 사용하는 길이와 속도는 3D 뷰에서 화면 포인트로 측정합니다(2D 캔버스에서는 문서 픽셀).
- 텍스처는 칠하는 위치의 문서 픽셀 좌표로 읽습니다. 2D에서 그린 곳과 3D에서 그린 곳의 질감 결이 맞습니다.
- 3D 대칭은 문서의 3D 대칭자(모델 공간)가 정하는 복사입니다. 선 대칭은 브러시 끝을 거울면에서 좌우 반전하고(선이 4개 이상이면 축 주위로 회전한 복사도 포함), 회전 대칭은 브러시 끝을 축 주위로 회전합니다. 2D 대칭자도 적용되며 칠한 텍스처 픽셀을 캔버스 위에서 복사합니다([GUIDE_PAINT.md](GUIDE_PAINT.md)의 “대칭으로 그리기”). 3D 대칭자 만드는 방법은 아래 “화면에서 드래그하여 그리기”의 “자”를 보세요.
- 한 번의 작업 메모리에 들어가지 않는 붓 자국이 있으면 2D 캔버스처럼 스트로크 전체를 취소합니다(일부만 칠해진 상태를 남기지 않음).
- 큰 브러시를 빠르게 움직이면 화면이 멈추지 않도록 한 프레임의 칠하기 시간(및 칠한 부분을 3D 표시에 반영하는 시간)을 8~40밀리초로 나눕니다. 밀린 작업의 예상 시간이 약 0.3초를 넘으면 시간을 늘려 따라잡고, 넘지 않으면 8밀리초를 유지합니다. 칠하기는 펜보다 조금 늦게 따라가며 펜을 놓은 뒤에도 다 칠할 때까지 계속됩니다(기준은 0.5초 이내. 펜이 매우 빠르고 길게 움직이거나 문서가 커서 칠하기가 따라가지 못하면 지연이 선 길이에 비례하여 늘어남). 펜을 놓은 뒤 칠하기가 끝날 때까지의 사이에 다음 작업(실행 취소·저장·새 선·도구 키·휠·창 닫기 등)을 시작하면 먼저 남은 부분을 칠하고 확정한 뒤 그 작업을 받습니다. `Esc`도 같으며 놓은 뒤의 선을 버리지 않습니다(놓기 전 `Esc`는 선 전체 취소). 칠하기가 끝나면 한 번의 실행 취소 단위가 됩니다.

3D 칠하기 필드는 “브러시 상세” 창의 “스트로크” 구분 안에 “3D” 제목으로 나열됩니다(3D 뷰가 표시되고 모델이 있을 때만). 값은 브러시별이 아닌 앱 전체 설정이며 모든 브러시에 같은 값이 적용됩니다(설정 파일에 저장).

| 필드 | 동작 |
|---|---|
| 정렬 | “카메라”(기본값)는 화면 위의 브러시 모양을 카메라에서 표면으로 투영합니다. “Tangent \| Wrap”은 브러시 모양을 표면을 따른 거리로 읽어 모서리나 곡면 너머로도 같은 크기로 감싸며 칠합니다(카메라에서 보이지 않는 쪽과 UV 이음새 너머도 칠함. 브러시 중심의 면과 반대 방향을 향하는 면은 “뒷면도 칠하기”가 꺼져 있으면 칠하지 않음). “Tangent \| Wrap” 중에는 “가려진 곳도 칠하기”와 “표면 방향에 따라 약하게”를 사용하지 않습니다 |
| 가려진 곳도 칠하기 | 브러시 원 안에서 앞쪽 면에 가려진 곳에도 칠합니다 |
| 뒷면도 칠하기 | 카메라를 등진 면에도 칠합니다 |
| 표면 방향에 따라 약하게 | 표면이 시선에 대해 기울수록 옅게 칠합니다(“약해지기 시작”·“칠하지 않는 각도”. 기본으로 켜져 있으며 80°부터 약해지고 85°에서 칠하지 않음) |
| 이음새 번짐 | UV 아일랜드 가장자리 밖으로 칠하는 너비(텍스처 픽셀. 기본 2 px, 최대 16 px)이며, 3D 뷰에서 그린 곳의 이음새에 선이 나타나지 않도록 합니다. 내보내는 이미지의 UV 밖은 내보내기 “패딩”으로 색을 확장합니다([GUIDE_FILES.md](GUIDE_FILES.md)의 “PNG로 내보내기”) |

### 화면에서 드래그하여 그리기

그라데이션과 도형은 3D 뷰 화면에서 드래그하여 모양을 결정합니다. 놓는 순간 카메라에서 보이는 면에 투영하여 그립니다(드래그하는 동안에는 아무것도 바꾸지 않음. `Esc`로 취소). 정투영도 같습니다. 자는 모델 표면을 누르고 드래그한 뒤 놓는 순간 3D 자를 만듭니다(아래의 “자”). 도구 속성 필드는 2D 캔버스와 같습니다.

- **그라데이션**: 보이는 표면의 텍스처 픽셀마다 해당 픽셀이 화면에 투영되는 위치의 색으로 칠합니다. 선형이면 시작점 쪽은 시작점 색, 끝점 쪽은 끝점 색, 그 사이는 2D와 같은 보간입니다. 선택 영역·마스크에 그릴 때·머티리얼로 칠할 때의 동작도 2D와 같습니다.
- **도형의 “채우기”**: 화면의 모양 안에 투영되는 보이는 면을 칠합니다. 가장자리는 2D 캔버스 “채우기”처럼 텍스처 픽셀을 4 × 4점으로 살펴 모양 안에 있는 점의 비율로 칠합니다(브러시의 “안티앨리어싱”으로 바뀌지 않음). 2D처럼 대칭은 사용하지 않습니다. 사각형의 “모서리 둥글기”는 화면 포인트로 측정합니다.
- **도형의 “선으로 그리기”**: 윤곽을 3D 뷰의 브러시 스트로크로 그립니다. 브러시 설정과 대칭이 적용됩니다(필압은 일정하며 손떨림 보정과 곡선은 사용하지 않음. 2D와 같음).
- 그라데이션과 도형의 “채우기”는 브러시 “3D” 필드와 관계없이 가려진 곳과 뒷면을 칠하지 않습니다. “표면 방향에 따라 약하게”와 “이음새 번짐”은 필드 설정을 따릅니다.
- 그라데이션과 도형은 놓는 순간 한 번의 실행 취소 단위가 됩니다. 잠긴 레이어·읽기 전용 텍스처 세트·한 번의 작업 메모리에 들어가지 않는 경우에는 아무것도 바꾸지 않고 거부합니다.
- **자**: 자 도구로 모델 표면을 누르고 드래그하면 선택한 레이어에 3D 자를 만듭니다(도구 속성의 “편집 레이어에 만들기”를 끄면 새 “자” 레이어에 생성). 3D 자는 모델 공간의 값이며 레이어에 속하고 `.ylp`에 저장합니다(시점을 회전해도 모델의 같은 위치에 유지. 2D 캔버스 자와는 별도). 누른 곳이 모델 밖이면 만들지 않습니다. 놓는 순간 만들며 한 번의 실행 취소 단위입니다(`Esc`로 취소).
  - **직선자·평행선·동심원·원근**: 누른 면의 점이 `a`, 놓은 점이 `b`이며(표면에 닿지 않는 곳은 누른 점을 지나 카메라를 향하는 평면 위의 점), 누른 면의 노멀이 자의 방향입니다. 드래그하지 않고 놓으면 만들지 않습니다. 원근의 1점과 2점은 도구 속성에서 선택합니다.
  - **대칭**: 드래그하면 누른 면의 점을 지나고 화면에서 그은 선과 시선을 포함하는 평면이 첫 거울면이 됩니다(`Shift`를 누르면 거울의 노멀을 모델 X·Y·Z 중 가장 가까운 축으로 스냅). 드래그하지 않고 놓으면 모델 경계의 중심을 지나는 X 거울이 됩니다. 선 수와 선 대칭은 도구 속성에서 결정합니다.
  - 특수 자(평행선·동심원·원근·대칭)는 만들면 표시가 붙고 “특수 자에 스냅”이 켜집니다(3D 특수 자는 2D와 별도로 하나만 적용). “스냅할 특수 자 전환”(`Ctrl+4`)은 포인터가 올라가 있는 뷰 공간의 특수 자를 순서대로 전환합니다. 어느 뷰 위에도 없으면 마지막으로 도구를 눌러 그리기 시작한 뷰 공간(브러시·도형·그라데이션·채우기·자 등으로 누른 뷰)을 전환하며, 그것도 없으면 그릴 대상이 3D 뷰뿐일 때는 3D, 그렇지 않으면 2D 캔버스 공간을 전환합니다.
  - **표시**: 보이는 3D 자가 3D 뷰 위에 겹쳐 표시됩니다(표시 범위와 눈 아이콘은 2D 자와 같음). 대칭은 선 대칭 2개이면 거울면의 사각형과 축 선, 그 외에는 축 선과 축에 수직인 면 위의 중심에서 뻗는 선입니다. 직선자는 a·b를 지나는 선과 끝의 원, 평행선은 방향선 여러 개, 동심원은 원 3개, 원근은 소실점과 거기에서 뻗는 선입니다. 적용되지 않는 자(특수 자는 표시가 없는 것, 직선자는 “자에 스냅”이 꺼진 경우)는 옅게 표시하며, 선택한 자(선택 레이어에 만든 직후의 자와 속성 행에서 선택한 자. “편집 레이어에 만들기”를 끄고 만든 자는 선택되지 않음)는 주황색으로 그립니다. 2D 자는 3D 뷰에 표시하지 않습니다.
  - **스냅**: “자에 스냅”·“특수 자에 스냅”이 켜져 있는 동안 3D 뷰의 브러시와 지우개 스트로크 점을 그리기 시작 시 카메라로 화면에 투영한 선에 스냅합니다(스트로크 도중 카메라는 움직이지 않음). 직선자는 a·b를 투영한 직선에, 그리기 시작점이 선 가까이(화면에서 약 26포인트)에 있을 때만 스냅합니다. 평행선은 누른 면의 점을 지나는 `a`→`b` 방향 선에, 원근은 누른 면의 점과 소실점을 잇는 선에(2점이면 처음 움직인 방향에 가까운 쪽) 스냅합니다. 동심원은 `a`를 지나는 축(자의 방향) 주위에서 누른 면의 점과 같은 높이의 원(누른 점을 지나는 원으로, 누른 점에서 떨어진 원으로 뛰지 않음)을 256등분하여 화면에 투영한 선에 스냅합니다(표시하는 고리는 `a` 높이의 원). 누른 곳이 모델 밖이면 직선자 이외에는 스냅하지 않습니다. 대칭은 스냅하지 않고 복사합니다.

3D 손가락과 복제는 UV 아일랜드 이음새를 가로질러 읽습니다. 복제 원본은 `Alt`를 누르고 움직이지 않은 채 놓는 클릭으로 정합니다(`Alt`＋왼쪽 버튼을 누른 채 움직여도 3D 뷰에서는 아무 동작도 하지 않음). “정렬”은 이전 스트로크의 위치 관계를 이어가며 “모든 레이어에서”는 보이는 레이어의 합성 결과를 읽습니다. 두 설정은 2D 캔버스와 같습니다. 3D 원본은 표면의 점으로 정해지므로 3D 뷰만 표시한 동안에는 복제의 “오프셋 X”·“오프셋 Y” 필드가 비활성화됩니다. 텍스처 세트를 바꾸면 원본 위치를 지웁니다.

`Shift`를 누르며 클릭하면 이전 스트로크 끝(표면에 닿은 마지막 점)에서 클릭한 점까지 직선을 그릴 수 있습니다(마우스와 펜 모두. 이전 점이 없으면 `Shift`를 누른 채 드래그할 때 처음 움직인 방향을 45° 단위로 고정). `Ctrl`을 누른 접촉은 펜으로는 그리지 않고 마우스로는 그립니다. 손가락 등의 터치 압력은 필압이 됩니다. 이것도 2D 캔버스와 같습니다([GUIDE_PAINT.md](GUIDE_PAINT.md)). 버킷의 “비슷한 색”도 누른 면의 UV가 가리키는 픽셀부터 2D와 같은 범위를 칠합니다.

### 화면에서 드래그하여 선택하기

사각형 선택(`M`)·타원형 선택(`Shift+M`)·올가미(`L`)·다각형 선택(`Shift+L`)은 3D 뷰 화면 위에서 모양을 결정합니다. 놓는 순간(다각형은 `Enter`·시작점·더블클릭으로 닫는 순간) 카메라에서 보이는 표면의 텍스처 픽셀에 투영하여 2D 캔버스와 같은 선택 영역으로 만듭니다(드래그 중에는 아무것도 바꾸지 않음). 원근과 정투영 모두 같습니다. 자동 선택(`W`)은 누른 면의 텍스처 픽셀에서 2D 캔버스와 같은 자동 선택을 수행합니다.

- 가려진 곳과 카메라를 등진 면은 선택하지 않습니다. 브러시 “3D” 필드의 “가려진 곳도 칠하기”·“뒷면도 칠하기”와 관계없습니다. “표면 방향에 따라 약하게”와 “이음새 번짐”은 필드 설정을 따릅니다(약해진 곳은 선택량이 옅어지며 번짐 픽셀은 선택됨).
- 가장자리는 텍스처 픽셀을 4 × 4점으로 살펴 모양 안에 있는 점의 비율로 정합니다(2D 캔버스의 타원·올가미·다각형과 같음). 사각형은 “모서리 둥글게”(화면 포인트로 측정)를 켰을 때만 가장자리가 매끄럽고, 다른 모양은 “안티앨리어싱”을 따릅니다.
- “새로 만들기”·“추가”·“제거”·“교차”(옵션 바와 `Shift`·`Ctrl`), “가로세로 비율 고정”·“중심에서”(누르기 시작한 뒤의 `Shift`·`Alt`도 포함)는 2D 캔버스와 같습니다. 움직이지 않고 놓으면 “새로 만들기”일 때 선택 영역을 해제합니다.
- 올가미와 다각형의 점은 시점을 회전해도 화면의 같은 곳에 남습니다(표면에 붙지 않음). 다각형을 만드는 도중에는 `Backspace`와 `Ctrl+Z`로 마지막 점을 지웁니다.
- 자동 선택은 2D 캔버스처럼 누른 픽셀에서 텍스처 위의 비슷한 색으로 연결된 범위를 선택합니다. 모델 위의 연결은 보지 않으므로 보이지 않는 면의 픽셀과 UV 이음새 너머 픽셀도 텍스처에서 비슷한 색으로 연결되어 있으면 선택합니다. 누른 곳이 모델에 닿지 않으면 아무것도 선택하지 않고 이유를 알립니다.
- `Esc`·창 포커스 상실·도구 변경 시 드래그 중인 모양과 찍은 점을 아무것도 선택하지 않고 버립니다. 놓기 이벤트를 놓친 경우(창 밖에서 놓음·펜 누름을 OS가 가져간 경우 등)도 아무것도 선택하지 않습니다(2D 캔버스는 마지막 위치로 선택).
- 한 번의 선택이 한 번의 실행 취소 단위이며 선택 영역은 텍스처 세트별로 `.ylp`에 저장됩니다. 읽기 전용 텍스처 세트에서는 누르는 순간 거부하며, 한 번의 작업 메모리에 들어가지 않으면 선택 영역을 바꾸지 않고 거부합니다.
- 선택 펜·선택 지우개(`S`)는 3D 뷰에서 누른 면의 텍스처 픽셀을 칠해 선택 영역에 추가·제거합니다(빠른 마스크의 브러시·지우개와 같은 경로). 지름·경도·불투명도·필압은 현재 브러시를 사용하며 표면 위 크기는 3D 브러시와 같은 규칙(모델 크기에 대한 비율)을 따릅니다. 추가·제거 여부는 `Shift`(추가)·`Ctrl`(제거)·펜의 지우개 끝·선택 지우개 옵션으로 결정하며 2D 캔버스와 같습니다. 대칭은 사용하지 않습니다. 한 스트로크가 한 번의 실행 취소 단위입니다. `Esc`로 버리고 포커스를 잃거나 OS가 펜 누름을 가져가면 그때까지를 선택합니다(3D 브러시와 같음).
- 선택 영역은 3D 뷰의 보이는 면 위에도 가장자리(흰색과 검은색 점선)로 표시됩니다(현재 텍스처 세트의 면만. 점선은 흐르지 않고 정지해 있음. 빠른 마스크 중에는 가장자리 대신 빨간 오버레이. 선택 펜으로 칠하는 동안은 추가할 쪽에 파랑, 제거할 쪽에 주황 오버레이도 표시). 확대·축소해도 선 두께는 바뀌지 않습니다. 가장자리는 텍스처 위에서 그리므로 모델 위에서 이음새를 가로질러 이어지는 선택 영역이어도 이웃 아일랜드 픽셀이 선택되지 않았으면 이음새에 선이 나타납니다(3D 선택 도구는 이음새 번짐 픽셀도 선택하므로 번짐 너비 안에서는 나타나지 않음). 가장자리와 오버레이 이미지는 문서와 같은 크기의 GPU 메모리를 사용하며 3D 이미지 예산(설정의 “GPU 메모리”)에 포함됩니다. 들어가지 않으면(문서 너비나 높이가 GPU 텍스처 상한을 넘는 경우 포함) 표시하지 않고 3D 뷰 모서리의 경고 아이콘으로 알립니다.

## 오브젝트를 선택하고 움직이기(편집 모드)

편집 모드에서는 3D 뷰에 보이는 레이어의 오브젝트 표시(흰 점)가 나타납니다. 대상은 채우기 투영 상자와 데칼(투영이 UV이면 없음), 그라데이션 데칼, 필터 도형, 모델 공간의 점 그라데이션 점, 3D 경로(현재 모델에서 그린 것), 3D 자(표시를 켠 것. 표시 범위와 관계없이 표시가 나옴)입니다.

- 표시를 클릭하면 해당 오브젝트와 레이어를 선택합니다. 선택한 오브젝트의 표시와 테두리·선은 주황색이 됩니다. 도형에는 채우기나 필터 필드에서 편집할 때와 같은 핸들도 나타납니다(`Q`로 숨길 수 있음).
- 표시가 겹쳐 있으면 같은 곳을 다시 클릭하여 다음 오브젝트를 선택합니다. 아무것도 없는 곳을 클릭하면 선택을 해제합니다.
- `G`(이동)·`R`(회전)·`S`(크기 조절)는 포인터 위치에서 시작하며 마우스를 움직인 양에 따라 바뀝니다. `X`·`Y`·`Z`로 축을 정하고(한 번 더 누르면 오브젝트 방향의 축. 크기 조절은 처음부터 오브젝트 방향의 축), 숫자로 값을 입력할 수 있습니다. 왼쪽 클릭 또는 `Enter`로 확정하고 오른쪽 클릭 또는 `Esc`로 취소합니다. 전체 키는 [GUIDE_KEYS.md](GUIDE_KEYS.md)의 “편집과 포즈 모드”에 있습니다.
- 키를 사용하지 않을 때는 왼쪽 도구 바에서 이동·회전·크기 조절을 선택하고 표시에서 왼쪽 드래그합니다(놓으면 확정. 드래그 중에도 `X`·`Y`·`Z`와 `Ctrl` 스냅이 적용됨. 펜도 사용 가능). 키로 시작했을 때도 바의 해당 도구가 강조됩니다.
- 한 번의 이동·회전·크기 조절이 한 번의 실행 취소 단위입니다. 움직이는 동안에는 거친 미리 보기로 따라갑니다.
- 점은 이동만 가능합니다. 3D 경로는 경로 전체를 움직이며 확정할 때 점을 가까운 표면의 점으로 다시 배치합니다. 그린 면과 같은 방향을 향한 면에만 배치하므로 얇은 판 앞면에 그린 경로가 뒷면으로 이동하지 않습니다(표면에서 너무 멀리 떨어진 점이 있으면 확정할 수 없음).
- `Alt+G`·`Alt+R`·`Alt+S`로 도형의 위치·회전·크기를 생성했을 때와 같은 배치(모델 외형에 맞춘 위치)로 되돌립니다.
- 3D 자는 표시가 두 점의 중간(직선·평행선·2점 원근) 또는 중심(동심원·대칭·1점 원근은 `a`)에 나타납니다. 선택하면 선이 주황색이 되고 이동 화살표와 회전 고리(크기 핸들은 나오지 않음), 끝점 사각형이 표시됩니다. 끝 사각형은 직선·평행선·2점 원근에서는 `a`와 `b`, 동심원과 대칭에서는 `b`(반지름·첫 선)이며, 드래그할 때 표면에 닿으면 그 면의 점으로, 닿지 않으면 이전 점을 지나 카메라를 향하는 평면 위로 움직입니다. `G`·`R`·`S`에서 이동은 `a`·`b`를 움직이고, 회전은 중심 주위로 `a`·`b`와 방향을 돌리며, 크기 조절은 중심에서 `a`·`b`까지의 거리를 바꿉니다(자 방향은 바꾸지 않음. 축을 제한한 크기 조절에서는 `a`·`b`가 해당 축을 따라 늘어나므로 `a`→`b` 방향이 바뀜). 축을 두 번째 누르면 자 방향의 축이 됩니다(X는 `a`→`b`, Y는 자 방향, Z는 X와 Y에 수직). 모두 연속적으로 바꾸는 작업이며 확정하는 순간 한 번의 실행 취소 단위가 됩니다. `Alt+G`는 중심을 모델 경계의 중심으로, `Alt+R`은 방향을 모델 축으로(자 방향을 가까운 축으로, `a`→`b`를 그다음 가까운 축으로), `Alt+S`는 `a`~`b` 거리를 모델 외형 대각선의 4분의 1로 되돌립니다.
- `H`로 선택한 오브젝트 표시를 숨기고 `Alt+H`로 모두 표시합니다(표시만 바뀌며 파일은 바뀌지 않음). `Delete`로 선택한 오브젝트를 지웁니다(투영 상자와 데칼은 채우기 레이어의 투영이므로 지울 수 없음. 자는 지울 수 있고 실행 취소로 복원됨).

숨긴 레이어(그룹의 눈 아이콘을 끈 경우 포함)의 오브젝트는 표시가 나오지 않으며 선택할 수 없습니다. 에셋 이미지를 3D 뷰 모델에 끌어놓아 데칼을 배치하면 편집 모드에서는 배치한 데칼을 선택합니다. 필드의 “3D 뷰에서 편집”을 눌렀을 때도 해당 오브젝트를 선택합니다. 2D 캔버스에서는 움직일 수 없습니다(편집 모드의 2D는 보기 전용). 움직일 수 있는 오브젝트는 한 번에 하나입니다.

## 포즈 지정하기

FBX의 본이 있는 모델을 읽으면 속성과 같은 그룹에 “포즈” 탭이 나타납니다(별도 창으로도 꺼낼 수 있음).

1. “본” 트리에서 본을 선택하면 포즈 모드로 들어가고 3D 뷰에 기즈모 고리가 나타납니다. 고리를 왼쪽 드래그하여 돌리며 표면을 눌러 본을 선택할 수도 있습니다. 옵션 바 왼쪽 끝의 모드 드롭다운, `Ctrl+Tab` 모드 파이 메뉴, 메뉴 바의 “보기 → 모드”, 포즈 패널 상단 버튼으로도 전환할 수 있습니다([GUIDE_START.md](GUIDE_START.md)의 “모드”). 포즈 모드에서는 그리지 않습니다(2D 캔버스도 보기 전용). 선택한 본은 `G`·`R`·`S` 또는 도구 바의 이동·회전·크기 조절을 선택한 뒤 본의 면에서 왼쪽 드래그하여 움직일 수 있습니다(사용법은 편집 모드와 같음. [GUIDE_KEYS.md](GUIDE_KEYS.md)의 “편집과 포즈 모드”).
2. 선택한 본의 위치·회전·크기는 수치로도 수정할 수 있습니다(회전은 Unity 인스펙터와 같은 순서의 오일러 각). 항목·본·본과 자식·전체 및 BlendShape를 하나씩 되돌릴 수 있습니다.
3. 포즈 작업 하나가 포즈 실행 취소 한 단계입니다(포즈 모드에서는 `Ctrl+Z`). 프리셋과 테이크는 그리는 도중에는 적용할 수 없습니다.

FBX 안에 테이크(애니메이션)가 있는 모델에는 “테이크” 구역이 표시됩니다. 테이크 상자와 프레임 슬라이더를 선택하고 “포즈로 적용”을 누르면 해당 시각의 본과 BlendShape 가중치를 현재 포즈에 적용합니다(슬라이더를 움직이기만 해서는 적용하지 않음). 적용한 뒤에도 직접 수정할 수 있습니다.

“포즈 프리셋”은 현재 포즈에 이름을 붙여 설정 폴더의 `pose_presets/`에 남깁니다. 휴지 포즈와 다른 본의 위치·회전·크기 차이를 본 이름 경로로 보관하므로 같은 이름의 본이 있는 모델에 적용할 수 있습니다(BlendShape는 포함하지 않으며 맞지 않는 본은 이유와 함께 건너뜀). 이름을 눌러 적용·좌우 반전하여 적용·현재 포즈로 덮어쓰기·이름 변경·삭제할 수 있습니다. 좌우 반전은 `.L`/`.R`·`_L`/`_R`·`Left`/`Right`·左/右(왼쪽/오른쪽) 이름 규칙으로 짝 본에 옮깁니다.

“면 숨기기”는 선택한 본의 영향을 받는 면(면의 3정점 가중치 평균이 “임곗값” 이상. “자식 포함”이면 자손도 포함)을 현재 3D 뷰에서 숨깁니다(뷰별 숨김이며 아래 “면 숨기기(숨기기 모드)”의 “본으로 숨기기”와 같음). 숨긴 면은 그리기·영역·스포이트 판정에도 사용하지 않습니다(2D 캔버스와 저장에는 영향 없음). 숨김 방식은 이름을 붙여 `hide_presets/`에 남길 수 있으며 여러 개를 동시에 켤 수 있습니다.

프로젝트 모델의 포즈는 `.ylp`에 저장되며 같은 모델을 열면 복원됩니다(맞지 않는 본이나 BlendShape는 이유와 함께 건너뜀).

## 면 숨기기(숨기기 모드)

옷 아래 면에 그리거나 경로를 만들 때, 또는 몸체만·옷을 입힌 상태·다른 포즈를 나란히 비교할 때 3D 뷰마다 면을 숨깁니다. 숨기기 모드는 페인트·편집·포즈와 나란히 있는 네 번째 모드이며, 옵션 바 왼쪽 끝의 모드 드롭다운·`Ctrl+Tab` 파이 메뉴·“보기 → 모드”로 들어갑니다([GUIDE_START.md](GUIDE_START.md)의 “모드”).

- **선택**: 왼쪽 도구 바의 “UV 아일랜드 선택”으로 면을 누르거나 “사각형으로 선택”으로 둘러싸면 해당 UV 아일랜드를 선택합니다(`Shift`로 추가, `Ctrl`로 제거). `Ctrl+A`로 모두 선택하고 `Ctrl+D`로 선택을 해제합니다. 숨김 단위는 UV와 3D 위치 양쪽에서 변이 연결된 면입니다(좌우 UV가 겹친 모델에서도 반대쪽 면까지 함께 숨기지 않음).
- **숨기기·복원**: `H`로 선택한 면을 숨기고 `Alt+H`로 모두 표시합니다(바의 버튼도 같음).
- **서랍**: 각 뷰 오른쪽 끝의 손잡이에서 “숨긴 항목”·“본으로 숨기기”·“프리셋”·“숨기기 설정”(“숨긴 면 윤곽 표시”·“숨긴 뒤에도 선택 유지”) 필드가 나옵니다. 열고 닫기는 뷰별로 적용됩니다.
- **셸프**: 페인트·숨기기·포즈 모드에서는 각 뷰 왼쪽 아래에 작은 컨트롤이 표시됩니다. 눈 아이콘으로 해당 뷰의 숨김 방식을 적용·해제하고, ▽로 “숨기기 프리셋”과 “포즈 프리셋”(“현재 포즈”·“초기 포즈”와 저장한 프리셋)을 선택합니다. 둘 다 해당 뷰에만 적용됩니다. 포즈 프리셋을 표시하는 뷰에는 회전 기즈모가 나오지 않습니다.
- **본 고리**: 숨기기와 포즈 모드에서는 모든 본 위치에 고리가 표시됩니다. 포즈 모드에서 고리를 누르면 표면보다 우선하여 해당 본을 선택합니다.

숨김 방식은 뷰별로 적용되며 숨긴 뷰에서는 그리기·영역 도구·스포이트·경로 다시 그리기도 숨긴 면을 건너뛰고 아래 면에 닿습니다. 2D 캔버스·저장·내보내기는 바뀌지 않습니다. 숨김 상태·서랍과 셸프 열림 상태·숨기기 설정은 저장하지 않으며 실행 취소에도 포함하지 않습니다. 모든 면을 숨기는 방식과 그리기 도중의 변경은 거부합니다. 숨기기 프리셋에는 본으로 숨기기 항목만 남습니다(UV 아일랜드 선택은 모델별이므로 남지 않음).

## 메시 맵 베이크하기

“텍스처 세트” 패널 아래쪽 바의 “메시 맵 베이크…” 버튼(불꽃 아이콘. 바가 좁아 버튼이 가려지면 세트 행의 오른쪽 클릭 메뉴에서 “메시 맵 베이크…”)으로 3D 뷰 모델에서 체크한 텍스처 세트마다 월드 노멀·위치·앰비언트 오클루전(AO)·곡률·두께·접선 공간 노멀·높이·ID·벤트 노멀·불투명도를 베이크합니다. 별도 스레드에서 진행하며 진행 표시와 취소 기능이 있습니다.

“메시 맵 베이크…”는 기본 키가 없는 작업으로 “단축키”의 “어디서나·시점” 표에도 있으며 키를 할당하거나 파이 메뉴 항목으로 만들 수 있습니다([GUIDE_KEYS.md](GUIDE_KEYS.md)).

왼쪽 목록에서 맵을 체크하고 “체크한 맵 베이크”를 누릅니다. 목록 오른쪽의 상태(최신·오래됨·미생성·미확인)와 눈 아이콘으로 베이크한 맵을 2D 캔버스에 겹쳐 볼 수 있습니다. “공통 설정”에는 여백과 안티앨리어싱, “베이크 위치”(자동·GPU·CPU)가 있습니다.

- 자동은 사용 가능한 하드웨어 GPU가 있으면 GPU, 없으면 CPU로 베이크합니다. GPU를 사용할 수 없거나 예산을 넘거나 도중에 실패하면 이유를 표시하고 CPU로 다시 베이크합니다.
- GPU에서 광선을 쏘는 맵(AO·두께·벤트 노멀)은 RT 코어(하드웨어 레이 트레이싱. Windows는 Vulkan, macOS는 Metal)가 있는 GPU라면 RT 코어로 베이크합니다. 같은 광선을 RT 코어를 사용하는 경로와 사용하지 않는 경로(compute) 양쪽으로 쏘아 결과가 일치할 때만 사용하며, 일치하지 않거나 사용할 수 없으면 compute로 베이크합니다. 사용한 경로는 베이크 창의 마지막 베이크 행에 표시되며, 사용하지 않은 이유는 해당 행을 가리키면 표시됩니다. 드라이버가 멈추는 PC에서는 “편집 → 설정…”의 “표시”에서 “베이크에서 RT 코어 사용”을 끄면 항상 compute로 베이크합니다(기본값은 켜짐). 환경 변수 `YOLUPAINTER_BAKE_RAY_QUERY=0`으로도 끌 수 있습니다.
- GPU 값은 CPU와 모든 바이트가 일치하지 않습니다(AO·두께·벤트 노멀은 최대 약 3%. 측정값은 [`crates/yolu-gpu/README.md`](https://github.com/YozoraKurage/YoluPainter/blob/main/crates/yolu-gpu/README.md)).
- 하이 폴리 투영은 선택할 수 없으므로 접선 공간 노멀·높이·불투명도는 균일합니다.

베이크한 맵은 `.ylp`에 세트별로 저장됩니다. 모델이나 설정이 바뀐 맵은 “오래됨”으로 표시하며 내보내기 AO에도 사용하지 않습니다.

<a id="id-マップと手動の色"></a>

### ID 맵과 수동 색상

ID 맵은 “색 구분 방식”(슬롯·메시·UV 아일랜드·메시 부품)마다 단색으로 구분해 칠합니다. ID 색으로 선택 도구(`Shift+W`) 속성의 “부품 수동 색상”에서 부품별 색을 정할 수 있습니다(16진수로도 지정 가능하며 “자동”으로 복원). 수동 색상은 ID 맵의 색이 되고 `.ylp`에 저장됩니다. 다른 모델에서 지정한 색은 전부 해제하는 것만 가능합니다.

## 겹친 UV 다루기

같은 텍셀을 2개 이상의 삼각형이 덮는 UV(거울처럼 겹친 좌우 등)에서는 베이크가 어느 한 아일랜드의 값을 굽습니다. 칠할 때는 겹친 양쪽에 같은 픽셀이 놓이므로 한쪽에만 그릴 수 없습니다(스트로크가 겹친 텍셀에 닿으면 세트별로 한 번만 알림).

- 보기: 메뉴 바 “보기”에서 “겹친 UV”를 켜면 2D 캔버스에 겹친 텍셀의 색과 겹침에 관련된 아일랜드 가장자리가 표시됩니다. 색과 불투명도는 “편집” → “설정…”의 “UV 와이어프레임” 행 오른쪽 견본에서 바꿉니다.
- 베이크 우선순위 결정: 베이크 창의 “겹친 UV”에서 “우선순위”로 겹친 텍셀에 어느 값을 베이크할지 선택합니다. “번호”는 번호가 작은 삼각형(기본 설정), “면적”은 3D 면적이 큰 아일랜드, “+X”·“−X”는 모델의 +X 또는 −X 쪽 아일랜드(거울 대칭의 한쪽)입니다. “0~1 밖의 아일랜드 베이크 안 함”도 선택할 수 있습니다.
- 아일랜드 직접 선택: “우선할 아일랜드”·“베이크하지 않을 아일랜드”의 ＋를 누른 뒤 2D 캔버스 또는 3D 뷰에서 아일랜드를 누르면 목록에 추가됩니다(추가된 아일랜드를 다시 누르면 제거, `Esc`로 종료). 오른쪽 개요도에서는 아일랜드를 누르고 메뉴의 “우선하기”·“베이크 안 함”·“제거”를 선택할 수 있습니다. 가리킨 아일랜드는 캔버스와 3D 뷰에서도 강조됩니다.
- 폴리곤 채우기에서도 사용: 폴리곤 채우기에서 2D 캔버스 또는 3D 뷰의 아일랜드를 오른쪽 클릭하여 “우선 베이크”·“베이크 안 함”을 선택할 수 있습니다. 2D에서 겹친 곳을 연속해서 누르면 이전 칠하기를 취소하고 다음 아일랜드를 칠합니다.

베이크 우선순위는 텍스처 세트별로 `.ylp`에 저장되며 한 번의 실행 취소로 되돌릴 수 있습니다. 직접 선택한 아일랜드는 삼각형 수·UV·슬롯·렌더러가 같은 모델에서만 사용할 수 있습니다.

## Unity에서 열기(Live Link)

같은 PC의 Unity 에디터에서 씬의 모델(아바타 등)을 이 앱으로 열 수 있습니다. Unity Live Link 창에서 열면 이 앱이 FBX와 이미지를 읽고 머티리얼별로 텍스처 세트를 만들어 포즈와 머티리얼 값을 적용합니다. 그린 뒤 내보내면 Unity가 작성된 PNG를 가져옵니다. “파일”의 “Live Link”에서 수신을 켜고 끌 수 있으며, 사용법은 [UNITY.md](UNITY.md), 전달 사양은 [LIVELINK.md](LIVELINK.md)에 있습니다.
