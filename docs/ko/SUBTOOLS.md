# 보조 도구와 도구 속성

왼쪽 도킹 영역 위에는 현재 선택한 도구의 보조 도구 목록·설정·브러시 크기가 세로로 배치된 세 패널에 나뉘어 표시됩니다. 도구를 바꾸면 내용도 바뀝니다.
세 패널은 별도 탭이므로 다른 패널처럼 드래그하여 배치를 바꾸거나 별도 창으로 꺼내거나 「창」 메뉴에서 열 수 있습니다.
오른쪽 「속성」에는 도구 설정 대신 선택한 레이어(페인트 레이어·마스크·채우기·조정·효과 행)의 내용만 표시합니다. 위쪽 옵션 모음은 해당 도구에서 자주 쓰는
2~3개 항목만 표시하며 도구 속성과 같은 값을 보여 줍니다(별도 값을 갖지 않음).

<a id="構成"></a>

## 구성

초기 배치는 위에서부터 다음 순서입니다.

1. **보조 도구**(패널): 도구별 목록입니다(아래 표). 행을 누르면 해당 보조 도구의 설정이 현재 설정이 됩니다. 선택한 행은 파란색이며 설정을 변경한 채로 둔 행에는
   「변경됨」 표시가 붙습니다.
2. **도구 속성**(패널): 현재 도구의 전체 설정입니다. 옵션 모음과 같은 값의 필드도 여기에 있습니다. 브러시·지우개·채우기·폴리곤 채우기·그라데이션·도형·
   경로·스포이트에는 끝에 「칠할 채널」 구역이 있습니다(여러 채널을 한 번에 칠하는 설정, 초기에는 접혀 있음). 마스크에 그리는 동안에는 이 구역이 레이어 마스크 필드로 바뀝니다.
3. **브러시 크기**(패널): 정해진 직경의 원들입니다. 크기가 있는 도구(브러시·지우개·선택 펜)에서만 원이 표시됩니다.

내용이 패널에 모두 들어가지 않으면 해당 패널 안에서만 스크롤합니다(목록은 목록 안에서, 도구 속성은 패널 안에서).

## 도구별 보조 도구

| 도구 | 보조 도구 목록 |
|---|---|
| 브러시 | 브러시 그룹(탭, 처음에는 펜·붓·에어브러시·효과·특수이며 가져오면 가져오기 그룹 추가). 그룹과 내부 브러시는 도구별로 직접 배치할 수 있습니다(아래 「도구 배치」) |
| 지우개 | 지우개 그룹(브러시와 공유하지 않음). 배치 방법은 브러시와 같습니다 |
| 채우기 | 비슷한 색상·삼각형·연결된 메시·UV 아일랜드·머티리얼 |
| 폴리곤 채우기 | 삼각형·연결된 메시·UV 아일랜드·머티리얼 |
| 그라데이션 | 선형·방사형과 끝점(투명으로·보조색으로)의 조합 |
| 도형 | 직선·사각형·타원 |
| 자 | 직선자·평행선·동심원·원근(1점)·원근(2점)·대칭자(선대칭 2개)·회전 대칭(6개) |
| 스포이트 | 선택한 레이어·모든 레이어(초기에는 모든 레이어, 저장한 보조 도구는 저장된 값 유지) |
| 이동·변형 | 일반·자유·원근·메시 |
| 유동화 | 밀기·시계 방향 회전·반시계 방향 회전·축소·팽창·복원 |
| 선택 도구 | 사각형·타원·올가미·다각형·자동 선택·ID 색상 선택·선택 펜(도구 모음의 선택 그룹과 같은 순서, 행을 누르면 도구가 바뀜) |
| 경로 | 경로(1개) |

브러시와 지우개 목록은 `.ylbrush` 브러시입니다. 다른 도구 목록은 설정 조합입니다(채우기는 범위 종류·허용 오차·인접·참조·색차·틈 닫기·영역 확장/축소·빈 부분 채우기·닫힌 영역 최대 면적·대칭자에 스냅).
설정을 바꿔 다른 보조 도구의 설정과 정확히 같아지면 선택 표시가 그 보조 도구로 이동합니다. 다른 보조 도구로 바꿔도 수정한 설정은 기억하며 다시 돌아오면
그 설정으로 복원합니다(파일에 저장하지는 않음).

## 내 보조 도구

목록 아래 바의 버튼으로 되돌리기·복제·현재 설정으로 새 보조 도구 만들기(＋)·삭제를 할 수 있습니다. 행을 더블 클릭하여 이름을 바꾸고 오른쪽 클릭 메뉴의 「현재 설정 등록」으로
변경한 설정을 해당 보조 도구의 기준으로 삼을 수도 있습니다. 내장 보조 도구는 삭제하거나 이름을 바꿀 수 없습니다(브러시와 지우개는 아래 「도구 배치」에서 설명한 대로 배치에서 제거 가능).

브러시와 지우개는 설정 폴더의 `brushes/`에 `.ylbrush`로 저장합니다. 다른 도구는 설정 폴더의 `subtools/`에 도구별 파일 하나
(`fill.ylsubtool`·`polygon-fill.ylsubtool`·`gradient.ylsubtool`·`shape.ylsubtool`·`ruler.ylsubtool`·`eyedropper.ylsubtool`·`move.ylsubtool`·`liquify.ylsubtool`)로 저장합니다.
사용자 보조 도구가 하나도 남지 않으면 파일을 삭제합니다. 보조 도구는 `.ylp`에 포함되지 않습니다.

<a id="ファイルの形式yolupainter-subtools-1"></a>

### 파일 형식(`yolupainter-subtools 1`)

첫 줄은 `yolupainter-subtools 1`이며 나머지는 `key=value` 행입니다(UTF-8, 최대 512 KiB, 빈 줄은 건너뜀).

```text
yolupainter-subtools 1
tool=fill
preset.1.name=自分のバケツ
preset.1.by_color=true
preset.1.tolerance=48
```

- `tool`은 두 번째 줄이며 파일 이름의 도구와 같아야 합니다.
- `preset.<番号>.name`은 이름(최대 40자)입니다. 그 외는 도구 필드 이름이며 숫자는 Rust 표기 그대로, 선택값은 이름(`kind=triangle` 등)으로 씁니다.
  없는 필드는 기본값으로 읽으므로 필드가 늘어나도 이전 파일을 읽을 수 있습니다.
- 번호는 1부터 시작하고 보조 도구는 번호 순으로 나열합니다(내장 항목이 먼저). 도구 하나당 최대 256개입니다(256개는 어떤 도구의 어떤 값이든 파일 하나의 한도 안에 들어감. 256개에 도달하면 추가·복제를 이유와 함께 거부).

알 수 없는 항목·중복 항목·범위를 벗어난 값·이름 없는 보조 도구·다른 도구의 파일·너무 많은 보조 도구가 있으면 해당 파일만 건너뛰고 시작 시 알립니다.
(다른 도구 파일은 읽습니다.) 더 최신 버전의 파일은 건드리지 않고 건너뜁니다. 읽지 못한 파일이 있는 도구에서는 그 파일을 손상시키지 않도록 보조 도구의 추가·복제·
삭제·이름 변경·등록을 거부합니다. 채우기의 「대칭자에 스냅」(`snap_symmetry`)은 0.6.0에서 추가된 필드이며 이 필드가 없는 이전 파일은 켜짐으로 읽습니다. 0.6.0이 쓴 채우기 파일은 0.5.x에서 알 수 없는 항목으로 간주하여 건너뜁니다. 기록은 임시 파일에 쓰고 다시 읽어 확인한 뒤 마지막 한 번의 교체로 확정합니다(도중에 종료되어도 이전 버전 유지).

이 형식의 파일은 독립 실행형만 사용합니다(`.ylp`에 포함되지 않으므로 0.4.x까지의 Unity 브리지 읽기·쓰기와는 무관).

<a id="ツールの並び"></a>

## 도구 배치

왼쪽 도구 모음(도구 순서·구분선·이름·아이콘)과 브러시·지우개 도구의 그룹(그룹 순서·이름·내부 브러시 순서)은
직접 바꿀 수 있습니다. 배치는 설정 폴더의 `tools.json`에 저장하며 `.ylp`에는 포함하지 않습니다. 배치 조작은 문서 편집이 아니므로 실행 취소 기록에 포함되지 않습니다.
(보조 도구와 같습니다.)

- **도구 모음**: 오른쪽 클릭 메뉴에 「도구 추가 ▸ 브러시/지우개」(모음에서 제거한 내장 도구가 있으면 그 아래 표시)·「이름 변경」·「아이콘 변경」
  (라이선스가 있는 아이콘 묶음에서 고른 29개)·「앞에 구분선 추가」·「이 도구 삭제」·「초기 배치로 되돌리기…」가 있습니다. 드래그하여 순서를 바꿉니다(`Esc`로 취소).
  브러시와 지우개 도구는 여러 개 둘 수 있고 각각 자체 그룹을 가집니다(좋아하는 브러시 묶음을 도구 하나로 만들 수 있음). 다른 내장 도구는
  모음에 하나만 둘 수 있으며 모음에서 제거해도 키와 메뉴로 사용할 수 있습니다. 브러시와 지우개 도구는 각각 마지막 하나를 삭제할 수 없습니다. `B`·`E` 키는
  현재 도구가 같은 종류면 유지하고, 아니면 모음의 첫 번째 해당 도구로 전환합니다.
- **그룹 탭**: 「＋」로 그룹 추가, 더블 클릭으로 이름 변경, 오른쪽 클릭으로 추가·이름 변경·복제·삭제를 합니다. 드래그하여 탭 순서를 바꾸고
  도구 모음의 브러시·지우개 도구 위에 놓으면 그 도구로 이동합니다(내부 브러시도 함께 이동하며 지우기 여부는 대상 도구가 결정).
- **브러시 행**: 드래그하여 순서를 바꾸고 탭이나 도구 위에 놓으면 다른 그룹으로 이동합니다. `Ctrl`을 누른 채 놓으면 복사본을 만듭니다. 오른쪽 클릭의 「복제」로 복사본을 만들고 「삭제」로 배치에서 제거합니다.
- **브러시 추가**(목록 아래 바의 「＋」): 종류(내장·함께 제공하는 Krita·Photoshop·CLIP STUDIO·기타 가져온 항목·내 브러시)별 목록과
  이름 검색 창을 엽니다. 행을 눌러 여러 항목을 선택하고 「추가」로 현재 그룹 끝에 넣습니다.
- **삭제**(도구·그룹·브러시)는 배치에서만 제거합니다. 브러시 파일은 남으며 「브러시 추가」 창의 내 브러시·가져온 항목에서 되돌릴 수 있습니다.
  파일을 지우는 기능은 해당 창의 오른쪽 클릭 메뉴 「파일 삭제…」뿐입니다(실행 취소할 수 없어 확인을 요청).
- **초기 배치로 되돌리기**(확인 후): 내장 도구·그룹·브러시를 초기 배치로 되돌리고 내 브러시는 각 파일의 원래 그룹(`.ylbrush`의 `group=`)
  뒤에 다시 나열합니다. 파일은 삭제하지 않습니다. 도구와 그룹의 이름·배치는 복원할 수 없습니다.
- **가져오기**(ABR·CLIP STUDIO 등): 현재 브러시 도구(현재 도구가 브러시가 아니면 현재 브러시가 속한 브러시 도구)의 「가져오기」 그룹
  (공간이 있는 첫 번째 그룹, 없으면 도구 끝에 만들고 가득 차면 다음 그룹 생성) 끝에 넣습니다. 지우개 도구의 「가져오기」 그룹에는 넣지 않습니다.
  가져온 브러시를 모두 제거해도 탭은 남습니다.
- **한도**: 도구는 64개, 그룹은 도구당 64개, 그룹 하나의 브러시는 512개까지입니다. 초과하는 작업은 이유를 알리고 거부합니다.
  초기 배치·「초기 배치로 되돌리기」·이전 앱이 추가한 파일을 배치할 때 한 그룹에 다 들어가지 않으면 같은 내장 그룹을 다음에 만들고 나머지를 넣습니다.
  그룹도 한도에 도달하면 배치에 넣지 않으며(파일은 유지) 「브러시 추가」 창에서 넣을 수 있습니다.

<a id="並びのブラシは写し"></a>

### 배치에 있는 브러시는 복사본

배치의 브러시는 항목 하나당 `.ylbrush` 하나입니다. 내장 브러시는 설정을 등록하거나 이름을 바꾸기 전까지 내장 항목을 가리키며(`b:<id>`),
같은 내장 브러시는 전체 배치에서 한 곳에만 있습니다. 두 번째를 배치하면(복제·`Ctrl`로 복사·「브러시 추가」로 다시 넣기) 복사본 파일을 만듭니다.
복사본을 바꿔도 원본은 바뀌지 않으며 원본 브러시(내장·함께 제공하는 Krita·가져온 파일)를 바꿔도 배치의 복사본은 바뀌지 않습니다. 배치에 없는 내 브러시
(제거한 항목)를 「브러시 추가」로 넣을 때는 복사하지 않고 해당 파일을 그대로 사용합니다(제거했다 다시 넣을 때마다 파일이 늘어나지 않도록 함).
함께 제공하는 Krita 브러시를 넣으면 복사본 파일이 생기며 이후에는 내 브러시 종류에 표시됩니다.

<a id="ファイルの形式toolsjson"></a>

### 파일 형식(`tools.json`)

설정 폴더 바로 아래(`brushes/` 옆)의 JSON입니다(UTF-8, 최대 1 MiB).

```json
{
  "format": "yolupainter-tools",
  "version": 1,
  "known_tools": ["brush", "eraser", "fill", "…"],
  "known_brushes": ["standard", "hard-round", "…"],
  "user_brushes_through": 12,
  "tools": [
    { "tool": "brush", "groups": [
        { "group": "pen", "brushes": ["b:standard", "u:3"] },
        { "name": "インク", "brushes": ["u:7"] } ] },
    { "tool": "eraser", "groups": [ { "group": "eraser", "brushes": ["b:standard-eraser"] } ] },
    { "tool": "fill" },
    { "tool": "select-rectangle", "gap": true },
    { "tool": "brush", "name": "水彩", "icon": "paint-brush", "groups": [ { "name": "グループ", "brushes": [] } ] }
  ]
}
```

- `tools`는 도구 모음의 위에서부터 순서입니다. `tool`은 도구 테이블의 id, `name`이 없으면 도구 테이블의 이름(언어에 따라 변경), `icon`은 선택 가능한 아이콘 이름,
  `gap`은 해당 도구 앞의 구분선입니다.
- `groups`는 브러시와 지우개 도구만 가집니다. `group`(내장 그룹 id)이 있고 `name`이 없으면 내장 이름을 사용합니다(언어에 따라 변경).
- `brushes`의 `b:<id>`는 내장 브러시, `u:<番号>`는 설정 폴더의 `brushes/brush-<番号>.ylbrush`입니다.
- `known_tools`·`known_brushes`는 기록 시점에 알고 있던 내장 도구와 브러시입니다. 읽을 때 여기에 없는 내장 항목(새 버전에서 추가된 항목)은
  도구라면 모음 끝에, 브러시라면 해당 내장 그룹 끝에 추가합니다. 사용자가 제거한 항목은 known에 있으므로 돌아오지 않습니다.
- `user_brushes_through`는 기록 시점에 존재한 사용자 브러시 파일 번호의 최댓값입니다. 배치에 없는 파일 중 이보다 큰 번호의 파일
  (이전 앱이 추가한 파일·배치를 기록하기 전에 종료된 경우의 파일)은 파일의 원래 그룹(`group=`)에 추가합니다. 이 이하의 번호는 사용자가 제거한 것으로 보고 표시하지 않습니다.

읽을 수 없는 부분(JSON이 아님·구조가 다름·한도 초과·같은 브러시 또는 같은 도구가 두 곳에 있음·그룹을 가질 수 없는 도구에 그룹이 있음·브러시나 지우개 도구가 없음)이
있으면 파일 전체를 읽을 수 없는 것으로 처리하고 초기 배치로 시작하며 알립니다. 원본 파일은 같은 폴더의 `tools.broken.json`(이미 있으면 `tools.broken-2.json` …)으로 옮겨 보관합니다.
보관할 수 없으면 배치를 저장하지 않습니다(원본을 덮어쓰지 않음). 알 수 없는 도구 id는 해당 항목만 건너뜁니다.
알 수 없는 내장 브러시와 폴더에는 있지만 읽을 수 없는 브러시 파일(손상·새 버전·동기화 중 등)의 항목은 화면에 표시하지 않고 기억해 두며
배치를 다시 쓸 때 원래 그룹의 원래 위치에 기록합니다(읽을 수 있게 된 뒤 시작하면 원래 위치에 표시). 해당 그룹의 항목 한도(512)에는 기억해 둔 항목도 포함합니다.
폴더에 없는 파일 항목은 기억하지 않으며 다시 쓰면 사라집니다. 「초기 배치로 되돌리기」는 새로 배치하므로 기억해 둔 항목도 복원되지 않습니다.
배치에 기록되어 있지 않던 읽을 수 없는 파일은 나중에 읽을 수 있어도 자동 배치되지 않으며 「브러시 추가」 창의 내 브러시에서 넣을 수 있습니다.
더 최신 버전의 파일은 건드리지 않고 초기 배치를 사용하며 배치를 바꾸는 작업(배치에 넣는 가져오기도 포함)은 이유와 함께 거부합니다.
기록은 임시 파일에 쓰고 다시 읽어 확인한 뒤 마지막 한 번의 교체로 확정합니다.

`tools.json`이 없으면(이 배치 기능이 없는 버전에서 업데이트한 경우) 기존 브러시 순서(`brushes/order.conf`)와 각 파일의 `group=`에서 이전과 같은 배치를 만듭니다.
`order.conf`는 더 이상 쓰지 않습니다(삭제하지도 않음). 배치 기능이 없는 이전 앱(0.4.x까지)은 `tools.json`을 읽지 않고 기존처럼 `order.conf`와 `group=`으로 배치하므로
배치에서 제거한 브러시와 복사본도 이전 앱에서는 원래 그룹에 표시됩니다. 이 형식은 독립 실행형만 사용하며 0.4.x까지의 Unity 브리지 읽기·쓰기와는 무관합니다.
