# 사용 방법

YoluPainter는 2D 캔버스와 3D 뷰 양쪽에 그려서 3D 모델의 텍스처를 만드는 앱입니다. 레이어, 마스크, 효과, 채널별 페인팅을 사용하고 작업을 `.ylp`에 저장한 뒤 PNG나 PSD로 내보냅니다.

이 사용 설명서는 하려는 작업별로 페이지가 나뉘어 있습니다. 처음 사용한다면 「시작하기」부터 읽어 주세요.

<a id="頁の一覧"></a>

## 페이지 목록

- [시작하기](GUIDE_START.md): 화면 구성, 모드, 프로젝트 만들기와 열기, 첫 스트로크, 2D 화면 이동, 패널 배치, 알림과 로그
- [그리기](GUIDE_PAINT.md): 브러시와 지우개, 브러시 구성 변경, 필압과 그리기 감각, 직선·도형·자, 대칭, 채우기와 그라데이션, 색상, 스텐실, 텍스트
- [선택과 변형](GUIDE_SELECT.md): 선택 영역 만들기와 사용, 저장된 선택 영역, 이동·변형, 복사와 붙여넣기
- [레이어와 채널](GUIDE_LAYERS.md): 레이어·그룹·병합·잠금·레이어 세트·마스크·조정 레이어, 채널과 노멀 설정
- [채우기와 효과](GUIDE_FILL.md): 채우기 레이어, 필터와 생성기, 에셋과 라이브러리, 액션
- [경로](GUIDE_PATHS.md): 2D와 3D 경로, 경로 목록, 모서리와 핸들, 종류, 브러시 끝
- [3D 뷰와 모델](GUIDE_3D.md): 3D 뷰 조작과 외관, 3D 뷰 추가, 3D에 그리기, FBX와 포즈, 면 숨기기(숨김 모드), 메시 맵 베이킹, 겹치는 UV
- [저장·내보내기·가져오기](GUIDE_FILES.md): 저장, 배포용 저장, 내보내기, PSD와 PNG, 복구, 큰 문서
- [설정](GUIDE_SETTINGS.md): 「편집 → 설정…」의 항목
- [키 목록](GUIDE_KEYS.md): 단축키 변경, 모드와 파이 메뉴, 키보드·마우스·펜 조작

- [보조 도구](SUBTOOLS.md): 보조 도구와 도구 배치의 저장 형식
- [그라데이션 맵](GRADIENT_MAP.md): 램프 영역 사용 방법
- [3D 뷰의 질감](PREVIEW.md): 3D 뷰 외관의 공식
- [PSD](PSD.md): PSD 읽기와 저장의 지원 범위
- [복구](RECOVERY.md): 복구 파일 위치와 디스크 사용량
- [배포용으로 저장](SAVE_FOR_DISTRIBUTION.md): 배포용 `.ylp`에 남는 항목과 제외되는 항목
- [.ylp 형식](YLP_FORMAT.md): 작업 파일 사양
- [Live Link](LIVELINK.md), [Unity 연동](UNITY.md): Unity 연결과 `.ylp` 전달
- [명령줄](CLI.md), [AI 도우미에서 조작하기(MCP)](MCP.md): 화면 없는 조작과 AI를 통한 조작
