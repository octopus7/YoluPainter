# 그리기

브러시와 지우개, 펜 필압, 직선·도형·자, 대칭, 채우기와 그라데이션, 색상, 스텐실, 텍스트의 사용 방법입니다. 채우기 레이어와 머티리얼로 칠하는 방법은 [GUIDE_FILL.md](GUIDE_FILL.md), 경로는 [GUIDE_PATHS.md](GUIDE_PATHS.md), 3D 뷰에 그리는 방법은 [GUIDE_3D.md](GUIDE_3D.md)에 있습니다.

<a id="ブラシで描く"></a>

## 브러시로 그리기

브러시(`B`)와 지우개(`E`)는 2D 「캔버스」와 「3D 뷰」 모두에 그릴 수 있습니다. 지우개는 지우개 목록에서 마지막으로 선택한 지우개로 지웁니다. 그릴 대상은 「레이어」 패널에서 선택한 레이어(마스크를 선택했으면 마스크)의 칠할 채널입니다.

왼쪽 「도구 속성」 패널에는 브러시 상세 설정에서 눈 버튼을 켠 행이 나열됩니다(처음에는 직경·불투명도·흐름·경도·간격·손떨림 보정). 직경은 `[`와 `]`로도 바꿀 수 있습니다. 그 아래 「브러시 크기」 패널에는 정해진 직경의 원들이 있습니다(브러시·지우개·선택 펜일 때만 표시). 브러시와 지우개에서는 도구 속성 하단 바의 오른쪽 버튼(「브러시 상세 설정」)으로 모든 설정을 구역별로 나눈 창을 엽니다. 창을 이동할 수 있으며 열린 상태로 그릴 수 있습니다.

상세 설정의 각 행 왼쪽 눈 버튼으로 해당 행을 도구 속성에도 표시할지 정합니다(브러시별로 저장). 영향 요인이 있는 행(직경·불투명도·흐름·경도·원형도·질감 농도·물감 양과 농도·색상 변화의 색조 등)은 오른쪽 영향 요인 버튼으로 「○○ 영향 요인 설정」 창을 엽니다. 필압·기울기·속도·무작위 중 사용할 요인과 각각의 최솟값(기울기는 최댓값도) 및 곡선을 정할 수 있습니다. 도구 속성 행의 영향 요인 버튼도 같은 창을 엽니다.

| 구역 | 내용 |
|---|---|
| 브러시 크기 | 직경, 화면상 크기로 지정, 최소 1픽셀, 크기 흔들림 |
| 잉크 | 불투명도·흐름, 아래 색상을 가져와 섞는 설정(유화·과슈·혼색 브러시에서 사용), 효과(흐림·문지르기·복제) |
| 색상 변화 | 브러시 끝의 색조·채도·명도·보조색, 스트로크별 무작위 변화, 변화 대상, 배경색으로의 흔들림 |
| 안티앨리어싱 | 없음·약·중·강(가장자리 픽셀의 계단을 부드럽게 함) |
| 브러시 모양 | 브러시 끝(끝 이미지·경도·원형도·각도·선 방향 따라가기·반복 방식·뒤집기), 산포 효과, 스트로크(간격·연속 분사·리본, 3D 페인팅 방법은 [GUIDE_3D.md](GUIDE_3D.md)), 종이 질감 |
| 보조 브러시 모양 | 두 번째 브러시 끝 겹치기(끝·산포 효과·스트로크·종이 질감) |
| 수채화 경계 | 선 가장자리를 진하고 어둡게 함(너비·투명도 영향·명도 영향·드래그 후 처리·흐림 너비) |
| 지우기 | 지우기 모드 |
| 보정 | 손떨림 보정, 속도에 따른 손떨림 보정, 보정 유형, 끝 처리, 후처리 보정(강도·속도에 따른 조절·확대율에 따른 조절), 곡선 |
| 시작과 끝 | 시작과 끝, 페이드, 시작과 끝의 영향 대상 |
| 넘침 방지 | 참조 레이어의 선을 넘지 않기, 색상 오차, 영역 확장/축소(양·방식) |

「지우기」의 「지우기」를 켜 둔 동안에는(「지우기 모드」 명령에 키를 할당하여 전환할 수도 있음) 브러시 도구에서도 현재 브러시 그대로 지웁니다. 이 설정은 브러시에 저장하지 않으며 도구를 바꿔도 유지됩니다.

항목별 사양은 [BRUSH.md](BRUSH.md)에 있습니다. 잉크의 색상 혼합(혼합 방식·혼색 모드·휘도 보정·번짐 강도·초기 물감 양 등)은 [BRUSH.md의 「색상 혼합(두껍게 칠하기)」](BRUSH.md#色の混ぜ厚塗り)에 설명되어 있습니다.

「넘침 방지」의 「참조 레이어의 선을 넘지 않기」를 켠 브러시(CLIP STUDIO에서 가져온 브러시 포함)는 참조 레이어([GUIDE_LAYERS.md](GUIDE_LAYERS.md), 오른쪽 클릭의 「참조 레이어」로 표시)의 선을 넘어 칠하지 않습니다. 선을 가로질러 그리면 선 앞뒤는 칠하지만 선 위는 칠하지 않습니다. 참조 레이어 표시가 없으면 일반적으로 그립니다([BRUSH.md](BRUSH.md)의 「넘침 방지」).

복제 브러시는 `Alt`를 누른 채 클릭한 위치(움직이지 않고 놓기)를 원본으로 하여 다음 스트로크부터 복사합니다. 2D 캔버스와 3D 뷰 모두 같습니다(`Alt`+왼쪽 버튼을 누른 채 움직이면 2D에서는 화면 회전이 되고 3D에서는 아무것도 하지 않음). 원본 위치에는 십자 표시가 나타나며 2D에서는 그리는 동안 현재 복사 중인 점으로 이동합니다. 「정렬」을 켜면 원본을 정한 뒤 첫 스트로크의 시작점에서 원본까지의 오프셋이 결정되고 이후 스트로크는 같은 오프셋을 유지합니다(`Esc`로 취소한 스트로크나 아무것도 바꾸지 않은 스트로크에서는 결정하지 않고 다음 스트로크에서 결정). 결정된 오프셋은 지우개로 전환했다 돌아오거나 브러시를 다시 선택해도 유지됩니다. 끄면 스트로크마다 시작점이 원본에 맞춰집니다. 「모든 레이어 읽기」는 보이는 레이어의 합성 결과를 읽습니다. 이 두 설정은 2D와 3D가 공유합니다. 문서나 텍스처 세트를 바꾸면 원본 위치를 잊습니다. 원본을 정하지 않은 2D는 「잉크」의 「X 오프셋」「Y 오프셋」으로 복사합니다. 원본을 정한 2D에서는 이 필드에 결정된 오프셋이 표시되며 원본으로부터 정해진 오프셋은 브러시의 「변경됨」으로 집계하지 않습니다(필드에서 수정한 오프셋은 집계). 정렬하지 않을 때와 3D 뷰만 표시할 때는 이 필드로 결정되지 않으므로 비활성화됩니다.

어떤 도구를 선택했든 2D에서 오른쪽 버튼을 누르면(누른 채 움직이면 색상 미리보기가 따라오며 놓은 위치의 색상을 가져옴), 3D에서 오른쪽 버튼을 움직이지 않고 놓으면 일시적으로 스포이트가 됩니다. 폴리곤 채우기의 오른쪽 버튼은 아일랜드 메뉴입니다(`Alt`는 시점 조작). 그리는 동안에는 패널 컨트롤을 눌러도 아무 일도 일어나지 않습니다. 외관은 그리기 전 상태를 유지하며 회색으로 바뀌지 않습니다.

## 브러시 선택과 구성 변경

브러시는 「보조 도구」 패널의 목록에서 선택합니다. 그룹 탭(처음에는 펜·붓·에어브러시·효과·특수, 가져온 브러시가 있으면 가져오기)마다 각 브러시 이름과 해당 설정으로 그린 스트로크 미리보기가 나열됩니다. 지우개 목록은 브러시와 별도 그룹입니다. 설정을 바꾼 브러시에는 「변경됨」 표시가 붙습니다.

- 목록 아래 바의 버튼으로 원래 설정 복원, 복제, 현재 설정으로 새 브러시 만들기, 삭제를 할 수 있습니다. 행을 더블 클릭하면 이름을 바꿀 수 있습니다.
- 「브러시 추가」(바의 「＋」)는 내장 브러시·함께 제공하는 Krita·Photoshop·CLIP STUDIO 브러시·가져온 브러시·내 브러시를 종류별로 나열하고 이름으로 찾을 수 있는 창입니다. 선택한 브러시를 현재 그룹에 넣습니다.
- 다른 앱의 브러시(ABR·GBR·GIH·VBR·PNG·PAT)는 「브러시 가져오기」, CLIP STUDIO 브러시는 「CLIP STUDIO에서 가져오기」로 읽습니다. 창에 드롭해도 읽을 수 있습니다(PNG는 브러시 목록 위에 놓았을 때만, [BRUSH_IMPORT.md](BRUSH_IMPORT.md)).

### 도구 모음과 그룹의 순서 변경

왼쪽 도구 모음의 도구, 그룹 탭, 브러시 행은 드래그하여 순서를 바꿀 수 있습니다(`Esc`로 취소). 그룹 탭과 브러시 행을 브러시·지우개 도구 위에 놓으면 해당 도구로 이동합니다. 브러시 행을 `Ctrl`을 누른 채 놓으면 복사본을 만듭니다. 오른쪽 클릭 메뉴는 다음과 같습니다.

| 위치 | 메뉴 |
|---|---|
| 도구 모음 | 「도구 추가」「이 도구 삭제」「이름 변경」「아이콘 변경」「앞에 구분선 추가」「초기 배치로 되돌리기…」 |
| 그룹 탭 | 「그룹 추가」「이름 변경」「복제」「삭제」 |
| 브러시 행(지우개 행 포함) | 「브러시 설정…」「이름 변경」「복제」「그룹으로 이동」「현재 설정 등록」「되돌리기」「삭제」 |

「브러시 설정…」은 해당 브러시로 전환하고 「브러시 상세 설정」 창을 엽니다. 「이름 변경」은 행 안에서 이름을 수정합니다(`Enter`로 확정, `Esc`로 취소). 「그룹으로 이동」에는 해당 도구의 그룹이 나열됩니다(현재 그룹은 선택 불가). 브러시가 있는 다른 도구가 있으면 도구별 하위 메뉴에 그 그룹이 나열됩니다. 브러시 행을 드래그하는 동안 놓을 수 있는 그룹 탭이 강조됩니다. 그리는 중·배치 파일을 읽을 수 없는 상태·가져오는 중 등으로 사용할 수 없는 항목은 포인터를 올리면 이유가 나타납니다.

「도구 추가」에는 브러시와 지우개, 도구 모음에서 제거한 내장 도구가 나열됩니다. 브러시 도구와 지우개 도구는 여러 개 둘 수 있으며 각각 자체 그룹을 가지므로 좋아하는 브러시만 모은 도구를 만들 수 있습니다. 각각 마지막 하나는 삭제할 수 없습니다. 삭제는 배치에서만 제거하며 브러시 파일은 남깁니다. 배치는 설정 폴더의 `tools.json`에 저장되며 문서에는 포함되지 않습니다. 내 브러시는 같은 폴더의 `brushes/`에 있습니다(손상된 파일은 건너뛰고 시작 시 알림). 한도와 형식은 [SUBTOOLS.md](SUBTOOLS.md)에 있습니다.

## 펜의 그리기 감각 조절

- **필압**: 도구 속성의 직경·불투명도·흐름·경도 행 오른쪽 버튼으로 「○○ 영향 요인 설정」 창을 열고 해당 항목에 필압을 사용할지, 최솟값(필압 0일 때의 값)·곡선을 정합니다. 손가락이나 펜 입력이 터치로 전달되면서 압력을 보내면 그 값이 필압이 됩니다(2D 캔버스와 3D 뷰 모두, 다음의 「필압 조정」을 거침).
- **펜별 차이**: 「편집 → 설정…」의 「펜」에서 「필압 조정」의 하한·상한·곡선을 맞춥니다. 평소 힘으로 선을 몇 개 그린 뒤 「자동 조정」을 누르면 그린 선의 필압 분포로 정할 수 있습니다. 기기별 설정이며 문서나 브러시에는 포함되지 않습니다.
- **Windows 태블릿**: Windows는 기본적으로 Windows Ink에서 필압·기울기·회전·펜 뒤쪽 지우개·측면 버튼을 읽습니다. Wacom 등의 드라이버가 WinTab을 제공하는 PC에서는 「편집 → 설정…」의 「펜」에서 「펜 입력」을 WinTab으로 바꿀 수 있습니다(WinTab을 사용할 수 없으면 Windows Ink 유지).
- **Mac 태블릿**: Mac은 Wacom·XP-Pen 등의 드라이버가 macOS 표준 이벤트로 보내는 필압·기울기·펜 뒤쪽 지우개·측면 버튼을 읽습니다(시험 기능). 「편집 → 설정…」의 「펜」에서 「태블릿 필압(시험 기능)」으로 전환합니다(기본값 켜짐, 끄면 펜이 마우스처럼 그림).
- **선이 나타나기까지의 지연**: 기본적으로 화면 갱신을 수직 동기화까지 기다리지 않아 펜 입력부터 선이 표시되기까지의 지연을 줄입니다. 화면의 위아래가 어긋나는 현상(티어링)이 신경 쓰이면 「편집 → 설정…」의 「화면」에서 「수직 동기화」를 켭니다(지연이 늘어나며 다음 실행부터 적용).
- **손떨림 보정**: 도구 속성의 「손떨림 보정」(0~200 px)은 입력이 브러시를 끌어당기는 실의 길이입니다. 0이면 꺼집니다.
- **후처리 보정**: 「브러시 상세 설정」의 「보정」에서 「후처리 보정」을 켜면 펜을 뗄 때 선의 작은 흔들림을 정리하여 다시 그립니다(다시 그리기는 Undo 한 번으로 처리). 끝 처리·보정 유형과 함께 [BRUSH.md](BRUSH.md#補正)에 공식이 있습니다.
- **시작과 끝**: 선의 처음과 끝을 가늘게 하는 설정은 「브러시 상세 설정」의 「시작과 끝」에 있습니다.
- **연속 분사**: 「브러시 상세 설정」의 「스트로크」에서 「연속 분사」를 켜면 펜을 멈추고 누르는 동안에도 dab이 계속 놓여 천천히 그린 부분이 더 진해집니다(후처리 보정과 함께 사용할 수 없음).
- **리본**: 「스트로크」의 「리본」을 켜면 브러시 끝 이미지를 선을 따라 이어 붙여 끊김 없는 무늬를 만듭니다(이미지 브러시 끝에서만 가능, 산포 효과와 함께 사용할 수 없음).
- **3D 뷰에서도 적용**: 손떨림 보정·시작과 끝·흔들림 등의 설정은 3D 뷰에 그리는 선에도 같은 공식으로 적용됩니다. 손떨림 보정과 시작·끝 길이(px)는 3D 뷰에서는 화면상의 점 단위로 측정합니다([GUIDE_3D.md](GUIDE_3D.md)).

## 직선·도형·자

- **직선**: 브러시·지우개·효과 브러시에서 `Shift`를 누른 채 클릭하면 이전 스트로크의 끝점부터 클릭한 점까지 직선을 그립니다(실행 취소 한 번으로 복원). 그대로 드래그하면 이어서 일반적으로 그립니다. 이전 점이 없으면(문서나 텍스처 세트를 바꾼 뒤) 누른 점부터 시작하며 `Shift`를 계속 누른 채 드래그하면 처음 움직인 방향을 45° 간격으로 고정합니다. 마우스와 펜, 2D 캔버스와 3D 뷰 모두 같습니다. 3D 뷰에서는 이전 스트로크의 끝(표면에 닿은 마지막 점)을 표면상의 점으로 기억하고 현재 카메라로 화면에 투영한 점부터 클릭한 점까지 화면상의 직선을 그립니다(현재 투영에서 보이는 면에만 칠함). 모델이 바뀐 뒤나 한 번도 표면에 닿지 않은 스트로크 뒤에는 이전 점이 없는 것으로 취급합니다. `Ctrl`을 누른 채 접촉하면 펜은 그리지 않고 마우스는 그립니다(2D와 3D 동일).
- **도형**(`U`): 「직선」「사각형」「타원」을 드래그하여 정하고 그립니다. 「윤곽선」은 현재 브러시로 외곽을 하나의 스트로크로 그리고 「채우기」는 그리기 색상으로 도형 내부를 칠합니다(선택 영역이 있으면 그 안만). 사각형은 「모서리 반경」을 정할 수 있습니다. `Shift`로 45° 간격·정사각형·정원을 만들고, 드래그를 시작한 뒤 `Alt`를 누르면 중심에서 그리며 `Esc`로 취소합니다. 놓을 때 실행 취소 한 단계로 확정합니다. 3D 뷰에서도 사용할 수 있으며 화면에서 드래그한 도형을 보이는 면에 투영하여 그립니다([GUIDE_3D.md](GUIDE_3D.md)).
- **자**(`Shift+U`): 레이어(그룹 포함)에 붙는 자입니다. 종류는 「직선자」「평행선」「동심원」「원근」(1점·2점)「대칭」이며 캔버스를 드래그하여 배치합니다(직선자는 2점, 평행선은 지나는 점과 방향, 동심원은 중심과 반경, 원근은 1점일 때 소실점·2점일 때 두 소실점, 대칭은 중심과 첫 선의 방향을 드래그로 지정. 시작점에서 끝점으로 드래그). `Shift`를 누르면 방향이 45° 간격이 되며 「각도 간격」을 켜면 해당 간격(1~90°)의 배수가 됩니다. 배치한 자는 선택되며 핸들(원과 사각형)을 드래그하여 움직일 수 있습니다. 놓을 때 실행 취소 한 단계가 됩니다. 「삭제」로 선택한 자를 지웁니다. 여기서 선택하는 종류와 설정은 「앞으로 만들 자」의 설정이며 이미 배치한 자는 바뀌지 않습니다.
  - **부착 대상**: 「편집 레이어에 만들기」가 켜져 있으면 선택한 레이어(그룹)에 붙습니다. 끄면 선택한 레이어 바로 위에 새 「자」 레이어를 만들고 거기에 붙이며(레이어와 자가 실행 취소 한 단계, 선택한 레이어는 그대로 유지), 표시 범위는 「같은 그룹 안」이 됩니다.
  - **레이어 목록**: 자가 있는 레이어 행의 썸네일 오른쪽에 「자」 아이콘이 표시됩니다. 누르면 해당 행을 선택하고 속성의 「자」 구역을 엽니다. `Shift`를 누른 채 누르면 해당 레이어의 자 표시를 모두 켜거나 끕니다(하나라도 보이면 모두 숨기고 전부 숨겨져 있으면 모두 표시). 아이콘을 다른 행에 드래그 앤 드롭하면 자를 모두 해당 레이어(그룹)로 옮깁니다. 오른쪽 클릭 메뉴는 「표시」「표시 범위」「자 삭제」입니다. 모두 실행 취소 한 번으로 되돌립니다. 레이어 하나당 자는 최대 64개입니다.
  - **표시 범위**: 자마다 어떤 레이어에 그릴 때 보이고 작동할지 정합니다. 「모든 레이어」, 「같은 그룹 안」(그룹에 붙인 자는 그룹 내부, 그룹에 속하지 않은 레이어에 붙인 자는 문서 전체, 하위 중첩까지 포함), 「선택한 동안만」(기본값, 붙어 있는 레이어가 선택되었을 때이며 그룹은 내부 레이어가 선택되었을 때)입니다. 부착된 레이어 또는 상위 레이어의 눈을 끄면 자도 숨겨지고 작동하지 않습니다.
  - **속성의 「자」**: 선택한 레이어의 자가 나열됩니다. 행마다 표시 켜기/끄기, 스냅할 특수 자 표시, 이름(「대칭 6」 등), 2D/3D 구분, 삭제가 있습니다. 행을 누르면 해당 자를 선택하고 표시 범위(강조된 범위를 다시 누르면 숨김)와 종류별 값(직선자는 시작점·끝점, 평행선은 각도, 동심원은 중심, 원근은 1점·2점과 소실점, 대칭은 선 수·선대칭·각도·중심)이 나타납니다. 값 변경은 실행 취소 한 단계이며 슬라이더 드래그 전체도 한 단계입니다.
  - 자는 레이어와 함께 복제·삭제·저장되며 병합 시 결과 레이어로 모두 이동합니다(결과가 64개를 넘으면 병합 불가). 이미지 크기를 바꾸면 2D 자도 함께 이동합니다. 텍스처 세트별로 별도의 자를 가집니다.
- **스냅**: 「보기」 메뉴에 두 가지가 있습니다. 「자에 스냅」(`Ctrl+1`)은 직선자, 「특수 자에 스냅」(`Ctrl+2`)은 평행선·동심원·원근·대칭에 적용됩니다. 둘 다 브러시와 지우개 스트로크(`Shift` 직선 포함)의 점을 맞춥니다. 켜져 있는지는 옵션 모음 버튼에도 표시됩니다.
  - 직선자는 그리기 시작한 점이 자의 선에서 화면상 26포인트 이내일 때만 그 선에 맞춥니다(가까운 선이 여러 개면 가장 가까운 하나).
  - 특수 자는 보이는 것 중 「스냅할 특수 자」 표시가 있는 하나만 작동합니다(2D 캔버스와 3D는 각각 하나). 표시는 속성 행에서 지정합니다. 특수 자를 만들면 그 자에 표시가 붙고 「특수 자에 스냅」이 켜집니다. 표시가 여러 개면 위쪽 레이어(같은 레이어에서는 목록 뒤쪽)가 작동하며 표시가 없으면 작동하지 않습니다. 작동 중인 자는 진하게, 다른 특수 자는 흐리게 그립니다. 「스냅할 특수 자 전환」(`Ctrl+4`)은 보이는 특수 자를 차례로 순환합니다. 순환 대상은 포인터가 놓인 뷰(2D 캔버스 또는 3D 뷰)의 공간이며, 어느 뷰에도 없으면 마지막으로 도구를 사용해 그리기 시작한 뷰, 그것도 없으면 그릴 수 있는 대상이 3D 뷰뿐일 때는 3D이고 그 외에는 2D 공간입니다. 평행선·동심원·원근은 누른 점에서 맞출 대상을 정하고 대칭은 점을 맞추지 않고 복사합니다.
  - `Shift`와 함께 사용하면 자의 스냅 대상이 우선합니다.

## 대칭으로 그리기

「대칭」 자로 설정합니다. 자 도구에서 「대칭」을 선택하고 중심에서 바깥으로 드래그하여 배치합니다. 첫 선의 방향을 정하고 「선 수」(2~16)와 「선대칭」으로 복사본을 정합니다. 선대칭은 선 수가 짝수일 때만 가능하며 N개 선이면 원본을 포함하여 N개로 복사됩니다(N/2개 선을 각각 축으로 좌우 반사하고 N/2회 회전을 겹침). 끄면 회전 대칭이 되어 중심 둘레에 원본을 포함한 N개를 회전 복사합니다. 배치 후에는 속성의 「자」에서 선 수·선대칭·각도·중심을 바꿀 수 있습니다.

「특수 자에 스냅」이 켜져 있고 그릴 레이어에서 보이는 「스냅할 특수 자」가 대칭이면 브러시와 지우개 선이 복사됩니다. 모든 복사본이 원본과 같은 스트로크이므로 실행 취소 한 번으로 되돌립니다. 2D 캔버스와 3D 뷰 모두에 적용됩니다(3D 뷰에 그리면 칠한 텍스처 픽셀을 캔버스의 같은 축으로 복사하며, 모델 위가 아닌 UV 평면상의 복사). 문지르기와 복제 효과 브러시와 함께 사용할 수 없습니다(대칭이 작동 중이면 그리기를 시작하지 않음). 퀵 마스크 브러시와 지우개에는 대칭을 적용하지 않습니다. 채우기와 자동 선택([GUIDE_SELECT.md](GUIDE_SELECT.md))은 2D 캔버스에서 누른 점을 복사하고 각 범위의 합집합을 칠하거나 선택합니다(도구 속성의 「대칭자에 스냅」으로 전환).

자를 숨기거나 「특수 자에 스냅」을 끄면 대칭은 작동하지 않습니다. 축(중심에서 뻗는 선)은 자로 표시되며 하늘색입니다.

## 채우기

- **채우기**(`G`): 누른 곳을 칠합니다. 범위는 보조 도구에서 「비슷한 색상」「삼각형」「연결된 메시」「UV 아일랜드」「머티리얼」 중 선택합니다. 「칠하기」「지우기」를 선택할 수 있으며 현재 선택 영역이 있으면 그 안에만 적용됩니다. 「비슷한 색상」에는 「허용 오차」「인접」「참조」(편집 레이어·모든 레이어·참조 레이어), 「지각 색차」「틈 닫기」「영역 확장/축소」「빈 부분 채우기」가 있습니다. 3D 뷰에서는 누른 면의 UV가 가리키는 픽셀에서 2D 캔버스와 같은 범위를 구합니다(빈 부분 채우기는 따라 그린 면의 UV 픽셀을 통과한 선으로 구하며 면 밖과 UV 이음새에서는 연결하지 않음). 2D 캔버스에서 대칭자가 작동하고(「대칭으로 그리기」) 도구 속성의 「대칭자에 스냅」(기본값 켜짐)이 켜져 있으면 누른 점을 복사한 모든 점에서 같은 설정(범위·「비슷한 색상」 허용 오차·인접·현재 선택 영역 내부)으로 범위를 구하고 그 합집합을 한 번에 칠합니다(실행 취소 한 번). 캔버스 밖의 복사본은 사용하지 않고 같은 픽셀에 겹치는 복사본은 한 번만 처리합니다. 「영역 확장/축소」는 합집합에 한 번 적용합니다. 누른 점이 캔버스 밖이면 복사본만 칠하지는 않습니다. 빈 부분을 따라 칠하기와 3D 뷰에는 복사를 적용하지 않습니다(빈 부분 채우기가 켜져 있거나 2D 캔버스가 보이지 않는 동안은 이 전환을 누를 수 없음).
- **폴리곤 채우기**(`4`): 드래그로 지나간 범위를 계속 추가하고 놓을 때 실행 취소 한 단계로 묶습니다. 범위 종류는 「비슷한 색상」을 제외하면 채우기와 같습니다. 겹치는 UV 처리 방법은 [GUIDE_3D.md](GUIDE_3D.md)에 있습니다.
- 포인터 아래 범위는 3D에서는 면으로, 2D에서는 UV 윤곽선으로 강조됩니다.
- **그라데이션**(`Shift+G`): 2D 캔버스 또는 3D 뷰에서 드래그하여 시작점(그리기 색상)부터 끝점(투명 또는 보조색)까지 「선형」 또는 「방사형」으로 칠합니다. 선택한 레이어의 칠할 채널에 적용하며 마스크를 그리는 중이면 마스크에 칠합니다(「흰색(표시)」「검은색(숨김)」). 도구 속성의 「칠할 채널」에서 「여러 채널을 한 번에 칠하기」가 켜져 있으면 조합의 모든 채널에 칠하며 「두 머티리얼 사이」로 끝점을 다른 머티리얼로 설정할 수도 있습니다([GUIDE_FILL.md](GUIDE_FILL.md)). 3D 뷰에서는 보이는 면의 픽셀을 화면에 투영된 위치의 색상으로 칠합니다([GUIDE_3D.md](GUIDE_3D.md)).

## 색상 선택과 추출

- **색상 정하기**: 도구 모음 아래쪽의 기본색과 보조색 또는 「색상」 패널에서 정합니다. 「색상」은 색상환 또는 사각형과 색조 막대(오른쪽 위 버튼으로 전환), 16진수(`#RRGGBB`), 알파로 구성됩니다. `X`로 기본색과 보조색을 바꾸고 `D`로 초기 색상으로 되돌립니다.
- **색상 창**: 채우기 레이어 색상, lilToon 색상, 그라데이션 색상 등의 견본을 누르면 색상 창이 열립니다. 색상환, 16진수, 불투명도, 색상 세트의 색상으로 즉시 적용할 수 있습니다. 「그리기 색상 적용」으로 현재 그리기 색상을 넣습니다. 바깥을 눌러도 닫히지 않아 다른 필드를 조작하면서 색상을 바꿀 수 있습니다. `Esc`를 누르면 열었을 때의 색상으로 되돌리고 닫습니다.
- **색상 세트**: 「색상 세트」 패널에서 색상 묶음을 사용합니다(새로 만들기·복제·이름 변경·삭제, GPL과 ACO 가져오기, GIMP 팔레트 내보내기). 색상을 누르면 기본색이 되고 `Alt`를 누른 채 누르면 보조색이 됩니다. 「기록」과 네 모서리 색상의 「중간색」도 표시됩니다.
- **스포이트**(`I`): 2D 캔버스와 3D 뷰에서 누른 위치의 값을 칠할 채널의 그리기 색상으로 가져옵니다. 추출 중에는 포인터에 스포이트 그림과 원이 표시됩니다(위쪽 절반은 현재 색상, 아래쪽 절반은 포인터 아래 색상, 스칼라 채널은 회색 농도). 초기 설정은 모든 레이어의 합성 결과에서 가져옵니다(옵션 모음의 「모든 레이어 대상」, 끄면 선택한 레이어만 읽음). 2D 캔버스에서 모든 레이어는 현재 레이어 세트의 합성입니다([GUIDE_LAYERS.md](GUIDE_LAYERS.md)의 「레이어 세트」). 「여러 채널을 한 번에 칠하기」를 켜면 표준 6채널의 값을 도구 속성의 「칠할 채널」 값으로 가져옵니다.
- **화면 색상**(Windows만): 「편집」 메뉴의 「화면 색상 가져오기」(`Ctrl+Alt+I`)와 「창을 숨기고 화면 색상 가져오기」(`Ctrl+Alt+Shift+I`)로 데스크톱 색상을 가져옵니다.

## 스텐실을 통해 칠하기

화면에 반투명하게 겹친 이미지를 통해 2D 캔버스와 3D 뷰 모두에 칠할 수 있습니다. 효과 브러시(흐림·문지르기·복제)에도 적용됩니다. 설정은 「속성」의 「스텐실」 탭에 있습니다.

- 「이미지」: 「이미지 열기…」로 PNG를 읽습니다(PNG를 여기에 드롭해도 가능). 「스텐실 제거」로 사용을 중단합니다.
- 「읽기 방식」: 「양(마스크)」은 이미지 밝기를 칠해지는 양으로 사용합니다(흰색은 칠하고 검은색과 투명은 차단). 「색상」은 이미지 색상으로 칠합니다. 「자동」은 회색 이미지면 양, 그 외에는 색상으로 처리합니다. 「반전」은 양 모드에서 작동합니다.
- 반복(「반복 안 함」「가로 반복」「세로 반복」「가로세로 반복」), 「오버레이 불투명도」「크기」「각도」.
- `Y`를 누른 채 왼쪽 버튼 드래그로 회전하고(`Shift`로 15° 간격), 가운데 버튼 또는 `Ctrl`+왼쪽 버튼 드래그로 이동하며 오른쪽 버튼 드래그 또는 `Alt`+왼쪽 버튼 드래그로 크기를 바꿉니다(2D·3D 모두). 「배치 초기화」로 되돌립니다. 배치는 화면에 고정됩니다. `N`을 누르는 동안에는 스텐실을 사용하지 않습니다.

스텐실은 앱 상태이며 `.ylp`나 브러시 프리셋에 저장하지 않습니다.

## 텍스트 넣기

텍스트(`T`)는 2D 캔버스를 누른 위치부터 입력합니다. 첫 글자를 입력하면 텍스트 레이어가 추가됩니다. `Enter`로 줄바꿈하고 `Esc`로 입력을 마칩니다. 상자 밖을 누르면 입력을 마치고 그 위치에서 새 텍스트를 입력할 수 있습니다. 가나·한자 변환도 사용할 수 있습니다. 입력한 내용은 실행 취소 한 번으로 되돌리며 글자가 남지 않으면 레이어도 남지 않습니다.

- **다시 입력하기**: 텍스트 레이어를 선택하고 상자 안을 누르거나 이동·변형 도구(`V`)로 상자를 더블 클릭합니다.
- **나중에 변경하기**: 「글꼴」「크기」「색상」「줄 간격」「자간」「정렬」(왼쪽·가운데·오른쪽)「줄바꿈 너비」를 도구 속성·옵션 모음·레이어 속성의 「텍스트」에서 수정할 수 있습니다. 글꼴은 함께 제공하는 「BIZ UDPゴシック」(일반과 굵게), 「설치된 글꼴」, 「파일에서…」(`.ttf`·`.otf`·`.ttc`) 중에서 선택합니다.
- **텍스트 색상**: 도구 속성의 「텍스트 색상」에서 색상 원본을 선택합니다. 「그리기 색상」(초기 설정)은 새 텍스트를 그리기 색상으로 만들며, 텍스트 도구를 사용하는 동안 텍스트 레이어가 선택되어 있거나 입력 중이면 그리기 색상을 바꿀 때마다 텍스트도 같은 색상으로 바뀝니다(색상환 드래그는 실행 취소 한 번). 브러시 등 다른 도구에서 그리기 색상을 선택해도 선택된 텍스트의 색상은 바뀌지 않습니다. 잠긴 레이어는 바꾸지 않습니다. 이때 「색상」 필드는 그리기 색상을 표시하며 누르면 그리기 색상의 색상 창이 열립니다. 「도구 색상」은 필드의 색상으로 새 텍스트를 만들고 필드 색상을 바꾸면 텍스트 색상도 바뀝니다(그리기 색상을 따르지 않음). 색상 원본 선택은 앱이 열려 있는 동안만 기억합니다. 텍스트는 레이어 하나당 한 색상이며 글자마다 색상을 지정할 수 없습니다. 레이어 속성의 「텍스트」 색상 필드는 해당 레이어만의 색상을 표시하고 변경합니다.
- **이동·변형**: 텍스트 레이어의 위치·회전·크기를 바꿉니다. 뒤집기, 가로세로 비율을 바꾸는 확대, 기울이기, 선택 영역 내부만 변형하기는 할 수 없습니다.
- **래스터화**: 직접 그릴 수 있는 레이어로 바꾸려면 「레이어」 메뉴 또는 오른쪽 클릭의 「텍스트 래스터화」로 현재 픽셀을 남기고 텍스트 값을 제거합니다. 그릴 채널은 Color입니다.
- **글꼴은 `.ylp`에 포함되지 않습니다.** 위치·이름·내용의 SHA-256만 기억합니다. 열 때 글꼴을 찾을 수 없는 레이어는 그려진 픽셀 그대로 표시하며 다시 입력하는 것을 거부합니다. 내용이 다른 같은 이름의 글꼴을 찾으면 알리고, 다시 입력하면 그 글꼴로 다시 그립니다.

텍스트 레이어가 있는 문서는 0.4.x에서 열 수 없습니다. PSD에는 픽셀 레이어로 내보냅니다. 형식은 [YLP_FORMAT.md](YLP_FORMAT.md)에 있습니다.
