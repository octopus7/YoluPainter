# 채우기와 효과


값·이미지·그라데이션으로 표면을 칠하는 채우기 레이어, 레이어 픽셀이나 마스크에 겹치는 효과, 에셋을 재사용하는 에셋 패널과 라이브러리, 작업 기록과 재생을 설명합니다.

<a id="塗りつぶしレイヤーを作る"></a>

## 채우기 레이어 만들기

레이어 패널의 “새 채우기 레이어” 버튼 (메뉴 모음의 “레이어”에도 있음)에서 종류를 선택합니다. 선택한 레이어 바로 위에 생성됩니다 (그룹 안의 레이어를 선택했으면 해당 그룹 안). “단색”만 선택한 레이어 바로 아래에 생성됩니다.

| 종류 | 생성되는 항목 |
|---|---|
| 단색 | 채널별 값으로 칠하는 레이어 |
| 그라데이션 데칼 | 3D 뷰의 범위 (박스·구·평면 (선형))에 따라 서로 다른 값을 칠하는 레이어 |
| 이미지 | 에셋 이미지로 칠하는 레이어. 목록의 “파일에서 가져오기…”로 PNG도 사용할 수 있습니다 |
| 데칼 | 에셋 이미지를 모델에 붙이는 형태로 배치하는 레이어 |

속성의 “채우기” 절에서 채널별 값을 지정합니다. 값 오른쪽 버튼으로 페인트 색상에서 값을 추가하고 삭제 버튼으로 제거합니다. 색상 채널 (Color·Emission)은 견본을 눌러 색상 창에서, 스칼라 채널 (Roughness·Metallic·Height)은 0〜1 슬라이더로 지정합니다.

<a id="複数のチャンネルを一度に塗る"></a>

### 여러 채널에 한 번에 칠하기

도구 속성의 “페인트 채널” (브러시·지우개·페인트통·다각형 채우기·그라데이션·도형·경로·스포이드와 선택 도구 (사각형 선택·타원 선택·올가미·다각형 선택·자동 선택·선택 펜)의 도구 속성 끝에 있으며 처음에는 접혀 있습니다. 선택 도구에서는 선택 영역 채우기·지우기가 이 조합을 사용)에서 “여러 채널에 동시에 칠하기”를 켜면 체크한 채널을 각 값으로 한 번의 스트로크에 칠합니다 (Color는 페인트 색상, Emission은 색상, Roughness·Metallic·Height는 0〜1, Normal은 기울기). 2D·3D·페인트통·다각형 채우기·경로에 적용되며 실행 취소 1회로 모든 채널이 복원됩니다. 끄면 선택한 채널에 페인트 색상으로 칠합니다.

<a id="画像で塗る"></a>

## 이미지로 칠하기

“이미지” 절에서 페인트 채널이 읽을 이미지를 지정합니다. 에셋 패널에서 필드로 드래그하거나 필드를 눌러 목록에서 선택합니다. “읽기 방식”은 이미지 값이 색상 (sRGB)인지 데이터 (선형)인지 지정하며 해당 이미지를 읽는 모든 레이어에 적용됩니다. “이방성 필터링”은 기본적으로 켜져 있어 비스듬히 투영한 이미지나 가로·세로 반복 수가 다른 이미지의 흐려짐을 줄입니다.

<a id="投影と置き場所"></a>

### 투영과 배치 위치

“투영” 절에서 이미지를 모델에 적용하는 방법을 선택합니다.

- UV: 이미지를 UV 정사각형에 배치합니다.
- 삼면 투영: 박스의 3개 축에서 투영하고 면 방향에 따라 혼합합니다 (“혼합 너비”). UV 이음새가 생기지 않습니다.
- 평면·구·원통: 박스 앞면에서 투영하거나 박스 중심을 둘러싸도록 투영합니다.
- 데칼: 박스 앞면에서 박스 내부에만 이미지 알파로 잘라내어 투영합니다. “깊이 가장자리”·“뒷면”·“면 가장자리”로 사라지는 방식을 바꿉니다.

“반복”·“오프셋”·“회전”·“바깥 영역” (반복·가장자리 연장·투명)으로도 투영을 조정할 수 있습니다. UV 이외의 투영은 베이크한 위치 및 노멀 메시 맵을 읽습니다 (베이크는 [GUIDE_3D.md](GUIDE_3D.md) 참고). 맵이 없는 동안은 필드에 이유가 표시되며 이미지 대신 값이 보입니다. 연 `.ylp`에서 필요한 맵이나 이미지가 부족한 세트는 입력이 갖추어질 때까지 읽기 전용이 됩니다.

UV 이외에서는 “3D 뷰에 핸들 표시” (`Q`로도 표시·숨기기)로 박스를 움직입니다. 화살표와 중앙 사각형은 이동, 고리는 회전 (`Ctrl`로 15° 단위), 면의 손잡이는 크기 (`Shift`로 양쪽 조절)이며 하나의 기즈모에 동시에 표시됩니다. “중심”·“회전”·“크기”는 숫자로도 수정할 수 있으며 “모델에 맞추기 (경계)”로 박스를 모델 경계에 맞출 수 있습니다.

에셋 이미지를 3D 뷰 모델에 드래그하여 놓으면 놓은 면을 향하고 이미지 종횡비를 유지하는 데칼이 현재 페인트 채널에 추가됩니다. 실행 취소 1회로 되돌릴 수 있습니다 (뷰의 위쪽이 이미지 위쪽). 다른 텍스처 세트의 면에는 배치할 수 없습니다.

<a id="グラデーションで塗る"></a>

## 그라데이션으로 칠하기

두 방식 모두 Normal 이외의 채널에 배치할 수 있습니다.

<a id="グラデーションデカール"></a>

### 그라데이션 데칼

“그라데이션 데칼” 절의 “3D 뷰에서 편집”으로 모양 (박스·구·평면 (선형))의 핸들을 표시하고 범위를 정합니다. 범위 안에 서로 다른 값을 칠하며 모델 위치로 결정하므로 UV 이음새가 생기지 않습니다. 위치 메시 맵이 필요합니다.

“감쇠” (평면 제외)로 가장자리가 사라지는 방식을, “반전”으로 그라데이션 방향을 정합니다. 색상과 불투명도 중지점·계조 프리셋·값 곡선은 그라데이션 맵과 같은 램프 필드입니다 ([GRADIENT_MAP.md](GRADIENT_MAP.md)).

<a id="点のグラデーション"></a>

### 포인트 그라데이션

“포인트 그라데이션” 절에서 점을 놓으면 점별 색상과 불투명도가 점까지의 거리에 따라 부드럽게 이어집니다. “모델”은 모델 표면 위치 (위치 메시 맵이 필요하며 UV 이음새에서 끊기지 않음), “UV”는 텍스처 UV 위치를 기준으로 연결합니다.

“점 편집” 중에는 3D 뷰나 2D 캔버스에서 표면을 눌러 점을 추가하고 마커를 드래그하여 이동하며 `Delete`로 선택한 점을 지웁니다 (마지막 1개는 지울 수 없음). 점 색상은 목록 견본에서 색상 창을 열어 수정하며 “퍼짐”으로 점 주변 색상의 균일함을 정합니다. 점은 최대 64개이며 이미지·그라데이션 데칼과 같은 채널에 배치할 수 없습니다.

<a id="効果を重ねる"></a>

## 효과 겹치기

효과는 레이어 픽셀이나 마스크에 적용하는 필터 (픽셀 수정)와 생성기 (값 생성)입니다. 표준 채널이 대상이며 레이어 행 아래에 들여쓰기로 나열됩니다 (위쪽 행일수록 나중에 적용).

<a id="追加する"></a>

### 추가하기

“필터 추가”와 “생성기 추가”는 별도 메뉴입니다.

- 속성의 “레이어”와 “레이어 마스크” 필드 (마스크 필드는 “마스크에 필터 추가”·“마스크에 생성기 추가”)
- 레이어 오른쪽 클릭과 메뉴 모음의 “레이어”에 있는 “필터 추가 ▸”·“생성기 추가 ▸”
- 메뉴 모음의 “필터” (필터와 앵커만)

레이어에 적용할지 마스크에 적용할지는 썸네일로 선택합니다. 레이어 썸네일을 누르면 레이어 픽셀, 마스크 썸네일을 누르면 마스크가 대상이 되며 (대상 썸네일에 파란 테두리), 추가 메뉴와 속성 모두 현재 대상을 따릅니다. 마스크 효과 행을 눌러도 마스크가 대상이 됩니다. 마스크 썸네일을 오른쪽 클릭하면 마스크에 추가와 반전·활성화·마스크 삭제를 선택할 수 있습니다.

행의 눈 아이콘으로 활성·비활성을, 위로·아래로로 순서를 바꾸고 삭제로 제거합니다 (오른쪽 클릭 메뉴에도 같은 항목이 있음). 행을 누르면 속성에 해당 설정이 나타납니다. 모든 효과에는 “강도”가 있으며 생성기는 “결합”에서 아래 값과의 결합 방식 (곱하기·교체·스크린·최댓값·최솟값·더하기·빼기)을 선택합니다.

작업 하나가 실행 취소 1회이며 슬라이더 드래그는 한 번으로 묶입니다. “모두”를 잠근 레이어 (부모 그룹 포함)에는 추가할 수 없습니다.

<a id="効果の種類"></a>

### 효과 종류

필터 23종은 흐림·윤곽과 모양·노이즈·값 조정·색조 보정 순서로 나열됩니다. 흐림 (가우시안), 선명하게 (언샤프 마스크), 노이즈, 레벨 보정, 계조 반전, 정규화 (레이어 전체), 조정 레이어와 같은 필드의 색조 보정 외에 다음 10종이 있습니다.

| 이름 | 동작 |
|---|---|
| 값 추출 | 위치보다 위의 값을 1, 아래를 0에 가깝게 만들며 대비로 경계를 선명하게 합니다 (스칼라와 마스크만) |
| 값 범위 | 값을 위치 주변의 범위로 압축합니다 (스칼라와 마스크만) |
| 노이즈 방향 흐림 | 기본 제공 노이즈의 기울기 방향으로 값을 늘입니다 |
| 방향성 흐림 | 각도 방향의 양쪽으로 선처럼 흐리게 합니다 |
| 왜곡 | 기본 제공 노이즈 기울기로 읽는 위치를 옮겨 왜곡합니다 |
| 팽창·침식 | 원형 범위의 최댓값으로 두껍게, 최솟값으로 얇게 합니다 (스칼라와 마스크만) |
| 윤곽 검출 | 흐리게 한 뒤 윤곽 강도를 추출합니다 (스칼라와 마스크만) |
| 하이패스 | 흐리게 한 이미지와의 차이를 0.5 회색 주변에 남깁니다 |
| 중앙값 | 정사각형 범위의 중앙값으로 작은 잡티를 제거합니다 |
| 글로우 | 임계값보다 밝은 부분을 흐리게 하여 더하고 빛나게 합니다 (색상 채널만) |

생성기는 15종이며 다음과 같이 나뉩니다.

- 베이크한 메시 맵에서 값 생성: 가장자리 마모, 오염·틈새, 위치 그라데이션, 모양 그라데이션, 두께, 방향, 조명 (베이크한 노멀과 빛 방향에서 명암 생성), 마스크 구성 (곡률·AO (앰비언트 오클루전)·위치 높이·두께를 가중치와 레벨로 결합), ID 색상
- 모델 UV 아일랜드에서 생성: 아일랜드별 변동 (아일랜드마다 1개 값)
- 맵 없이도 적용: 노이즈, 그런지, 패턴 (UV 줄무늬·체크·물방울·테두리·격자), 이미지 (에셋 이미지를 채우기 레이어와 같은 투영으로 읽음). 노이즈와 그런지는 위치 맵이 있으면 모델 위에서, 없으면 UV 위에서 생성합니다
- 앵커: 아래 레이어의 결과를 읽습니다

읽을 맵이 없거나·오래되었거나·모델과 대조할 수 없는 생성기는 행에 표시와 이유가 나타나며 입력을 그대로 통과시킵니다 (베이크하면 적용됨). ID 색상은 속성의 “ID 맵에서 선택”을 누른 다음 2D 캔버스나 3D 뷰를 누르면 해당 위치 색상을 추가합니다 (`Ctrl`을 누르면 제거, 최대 32색. 다시 누르면 종료). 앵커는 레이어나 마스크에 이름을 붙여 놓는 참조점이며 위쪽 레이어의 앵커 생성기가 읽습니다.

<a id="継ぎ目をまたいで読む"></a>

### 이음새를 넘어 읽기

흐림이나 선명하게처럼 주변 픽셀을 읽는 필터는 모델이 있으면 UV 아일랜드 가장자리 너머 (3D에서 인접한 면)의 픽셀도 읽습니다. 효과 필드의 “UV 이음새 너머 적용”으로 전환할 수 있으며 해당 텍스처 세트의 모든 필터에 적용됩니다.

<a id="アセットに保存して使い回す"></a>

## 에셋으로 저장하여 재사용하기

오른쪽 위 “에셋” 패널에는 저장 위치가 2개 있습니다. “프로젝트”는 이 프로젝트의 에셋으로 `.ylp`에 저장됩니다 (최대 256개). “라이브러리”는 개인 폴더 (위치는 설정의 “라이브러리 위치”)이며 다른 프로젝트에서도 사용할 수 있습니다.

에셋은 이미지·브러시·머티리얼·스마트 머티리얼·스마트 마스크의 5종이며 위쪽 아이콘으로 필터링하고 이름으로 검색할 수 있습니다. 바로 배치할 수 있는 기본 제공 스마트 머티리얼도 나열됩니다.

- “레이어 저장”: 선택한 레이어 (그룹은 내용 포함)를 스마트 머티리얼로 프로젝트 에셋에 넣습니다. “마스크 저장”은 마스크를 스마트 마스크로 만듭니다. 저장은 별도 스레드에서 진행되며 패널에 “저장 중”과 “취소”가 표시됩니다. 그동안 에셋 삭제·불러오기는 “저장 중입니다”라는 이유로 거부합니다. 사용자 채널·노이즈·그런지·색조 보정·0.5.0 효과를 사용하는 레이어는 `.ylsmart`로 쓸 수 없으므로 이유를 표시하고 저장하지 않습니다.
- “배치” (두 번 클릭·오른쪽 클릭·레이어 목록으로 드래그도 가능): 선택한 레이어 위에 새 레이어로 배치합니다. 크기가 다른 텍스처 세트에는 늘여서 배치하며 실행 취소 1회로 되돌릴 수 있습니다. 스마트 마스크는 “마스크에 적용”으로 선택한 레이어의 마스크와 교체합니다. 배치할 수 없는 에셋은 목록에만 나타나고 이유를 표시합니다.
- “라이브러리에 추가”·“이 프로젝트에서 사용”: 에셋과 라이브러리 사이에서 에셋을 옮깁니다.
- `.ylsmart`는 가져오기·내보내기가 가능합니다 (0.4.x까지의 Unity 브리지에서도 읽을 수 있음. Unity 브리지 0.5.0부터는 가져오지 않음).

채우기 레이어를 오른쪽 클릭한 뒤 “머티리얼로 저장”을 선택하면 채우기 값·그라데이션·투영·필터를 라이브러리의 `Materials`에 `.ylmaterial`로 씁니다 (이름은 레이어 이름이며 같은 이름에는 번호가 붙음). 마스크·클리핑·불투명도·혼합 모드·표시·잠금은 보유하지 않으며 배치하면 새 채우기 레이어의 기본값이 됩니다. 에셋 이미지를 사용하는 채우기는 저장할 수 없습니다 (항목을 누를 수 없고 도구 설명에 이유 표시).

## 작업 기록과 재생

“창” → “액션” 패널에서 레이어·마스크·효과 작업 (추가·삭제·순서 변경·표시·불투명도·혼합 모드·클리핑·잠금·채널 활성화·채우기 값·조정 및 효과 값)을 기록하여 다른 텍스처 세트나 문서에서 재생할 수 있습니다.

1. “기록”을 누르고 레이어나 효과를 조작합니다. 그리기·선택 영역·변형·병합·복제처럼 기록할 수 없는 작업이 있으면 패널에 표시가 나타납니다. 내보내기와 저장은 기록하지 않습니다.
2. “기록 중지”를 누르면 목록에 액션이 추가됩니다. 두 번 클릭하여 이름을 바꾸고 드래그하여 순서를 바꿀 수 있습니다.
3. 목록에서 선택하고 “재생”을 누르면 현재 텍스처 세트에 적용합니다. 전체를 실행 취소 1회로 되돌릴 수 있습니다.

기록을 시작할 때 선택한 레이어와 기록 중 만든 레이어·효과는 다른 문서에서도 같은 대상을 가리킵니다. 다른 레이어는 이름으로 가리키며 같은 이름이 여러 개면 기록하지 않습니다. 액션은 설정 폴더의 `actions/`에 저장되며 `.ylp`에는 포함되지 않습니다. 명령줄의 `run-action` ([CLI.md](CLI.md))이나 MCP 도구 `action_run` ([MCP.md](MCP.md))으로도 적용할 수 있습니다.
