# 레이어와 채널


레이어를 만들고 정리하는 방법, 마스크, 보정 레이어, 채널 사용법을 설명합니다. 채우기 레이어와 레이어에 추가하는 효과 (필터·생성기)는 [GUIDE_FILL.md](GUIDE_FILL.md)에 있습니다.

<a id="レイヤーを作る並べる"></a>

## 레이어 만들기와 배치

“레이어” 패널의 작업 모음 (혼합 모드와 불투명도 행 바로 아래) 버튼이나 메뉴 모음의 “레이어”에서 만듭니다. 같은 항목은 레이어 및 목록의 빈 공간을 오른쪽 클릭해도 나옵니다. 작업 모음에는 왼쪽 끝의 “클리핑”과 오른쪽에 모인 “새 레이어”, “새 채우기 레이어”, “레이어 그룹화”, “새 보정 레이어”, “레이어 삭제”의 6개 버튼이 있습니다 (필터·생성기 추가, 레이어 마스크, 레이어 위로·아래로 이동은 오른쪽 클릭 메뉴에 있음). 새 레이어는 선택한 레이어 바로 위에 만듭니다 (그룹 안의 레이어를 선택했다면 해당 그룹 안). 선택한 레이어가 없으면 맨 위에 만듭니다. 채우기 레이어의 “단색”만은 선택한 레이어 바로 아래에 만듭니다.

| 항목 | 만드는 내용 |
|---|---|
| 새 레이어 (`Ctrl+Shift+N`) | 픽셀을 가진 레이어 |
| 새 채우기 레이어 | 단색·그라데이션 데칼·이미지·데칼 ([GUIDE_FILL.md](GUIDE_FILL.md)) |
| 새 보정 레이어 | 아래 “보정 레이어” 참고 |
| 새 경로 레이어 | 점이 없는 경로 1개를 가진 레이어. 경로 도구로 전환되며 첫 점을 놓으면 이 레이어의 경로가 됩니다 ([GUIDE_PATHS.md](GUIDE_PATHS.md)) |
| 새 그룹 | 레이어를 담는 컨테이너 |

- **선택**: 행을 누릅니다. `Ctrl`＋클릭으로 추가·해제하고, `Shift`＋클릭으로 범위를 선택하며, `Ctrl+Shift`＋클릭으로 범위를 추가합니다.
- **이름**: 행의 이름을 더블 클릭하거나 오른쪽 클릭의 “이름 바꾸기”로 변경합니다.
- **순서 변경**: 행을 드래그합니다. 선택한 행을 누른 채 드래그하면 선택한 항목 전체를 옮길 수 있습니다. “레이어 위로 이동”, “레이어 아래로 이동”으로도 옮길 수 있습니다.
- **표시**: 행의 눈 표시로 전환합니다.
- **자**: 자가 있는 레이어 (그룹 포함)의 행에는 썸네일 오른쪽에 “자” 아이콘이 나타납니다. 클릭·`Shift`＋클릭·드래그·오른쪽 클릭 사용법은 [GUIDE_PAINT.md](GUIDE_PAINT.md)의 “자”에 있습니다.
- **삭제·복제**: “레이어 삭제”와 오른쪽 클릭의 “복제” (`Ctrl+J`)를 사용합니다. 실행 취소로 되돌릴 수 있습니다.

여러 레이어를 선택하면 삭제·복제·그룹화·병합·표시 전환·1단계 위아래 이동·드래그 이동·잠금을 선택한 전체에 한 번에 적용할 수 있습니다. 그리기 대상은 1개로 유지됩니다.

<a id="グループ"></a>

### 그룹

“레이어 그룹화” (`Ctrl+G`)로 선택한 레이어를 그룹에 넣습니다. 그룹은 중첩할 수 있으며 행의 화살표로 열고 닫습니다. “그룹 해제”는 `Ctrl+Shift+G`입니다. 그룹의 “통과”를 켜면 그룹이 없는 것처럼 내용을 아래에 합성합니다. 끄면 내용을 먼저 합친 뒤 합성합니다. 그룹 바로 위에 클리핑된 레이어가 1장이라도 있으면 (숨겨져 있어도), 통과 그룹 역시 내용을 먼저 합친 뒤 합성합니다.

<a id="結合"></a>

### 병합

| 작업 | 키 |
|---|---|
| 아래 레이어와 병합 (그룹이면 그룹을, 여러 레이어를 선택했으면 해당 레이어들을 병합) | `Ctrl+E` |
| 표시된 레이어 병합 | `Ctrl+Shift+E` |

둘 다 실행 취소 1회으로 되돌릴 수 있습니다. 병합 후 외관이 반올림 1단계보다 크게 달라지는 경우에는 변경되는 픽셀 수를 보여 주고 확인합니다. 병합할 수 없는 이유 (아래 레이어 없음, 숨겨진 레이어 있음, 잠금 등)는 짧은 문장으로 표시하며 아무것도 변경하지 않습니다.

<a id="ロック"></a>

### 잠금

잠금은 4종류입니다. “투명 영역”은 그려도 픽셀의 투명도를 바꾸지 않고 색상만 변경합니다. “픽셀”은 픽셀을 변경하지 못하게 합니다 (이동과 마스크 그리기는 가능). “위치”는 이동·변형을 막습니다. “모두”는 픽셀·위치·레이어 설정을 변경하지 못하게 합니다.

설정·해제는 행의 자물쇠 표시 (직접 설정한 잠금은 누르면 해제), 오른쪽 클릭 메뉴의 잠금 항목 (“투명 영역 잠금”, “픽셀 잠금”, “위치 잠금”, “모두 잠금”), “속성”의 “잠금”에서 할 수 있습니다. 그룹 잠금은 내부 항목에 적용됩니다. 잠금은 `.ylp`·PSD·`.ylsmart`에 저장하고 복원합니다.

<a id="合成する"></a>

## 합성

“레이어” 패널 맨 위 행에서 선택한 레이어의 혼합 모드와 불투명도를 정합니다 (그릴 채널의 값). 혼합 모드는 26종류이며 그룹에는 “통과”가 추가됩니다. “아래 레이어로 클리핑” (작업 모음 왼쪽 끝 버튼 또는 오른쪽 클릭의 “클리핑”)을 켜면 아래 레이어의 형태 안에서만 겹쳐집니다. 클리핑된 레이어의 행은 썸네일 왼쪽의 얇은 세로 띠로 표시합니다 (들여쓰지는 않음).

채널마다 다른 값도 사용할 수 있습니다. 혼합 모드 메뉴 맨 위의 “{채널 이름} 전용 값”을 선택하면 해당 채널만의 혼합 모드와 불투명도를 사용합니다. 레이어를 사용할 채널은 “속성”의 “채널”에서 선택합니다 (꺼도 해당 채널의 픽셀은 유지).

오른쪽 클릭의 “참조 레이어”는 채우기 도구의 “비슷한 색상”이 색상을 참조할 레이어와 브러시의 “참조 레이어의 선 넘지 않기”가 선을 참조할 레이어에 표시를 붙입니다 ([GUIDE_PAINT.md](GUIDE_PAINT.md)).

## 레이어 세트

레이어 세트는 1개의 텍스처 세트 안에 있는, 이름이 지정된 레이어 묶음입니다. 채널별로 어느 레이어 세트의 합성을 최종 결과 (3D 보기·내보내기·Live Link에 나가는 내용)로 사용할지 선택할 수 있습니다 (출력 할당). 그림자 마스크처럼 일부 채널만 별도 레이어로 그리거나, 2가지 안을 남겨 두고 할당을 바꿔 비교하는 데 사용할 수 있습니다. 새 문서에는 모든 채널을 출력하는 레이어 세트 1개 (“머티리얼”)만 있습니다. 레이어 세트가 1개이며 이렇게 출력하는 동안에는 아래에서 설명하는 행이나 드롭다운이 나타나지 않습니다.

- **만들기**: 2D 캔버스 오른쪽 위의 그릴 채널 버튼으로 여는 영역에서 “레이어 세트” 열의 “＋” (“레이어 세트 추가”), 또는 “텍스처 세트” 패널의 레이어 세트 행을 오른쪽 클릭한 뒤 “새 레이어 세트”로 만듭니다. 새 레이어 세트는 흰색 단색과 빈 레이어로 시작합니다 (사용자 채널을 추가할 때 만들어지는 레이어 세트는 해당 채널의 출력용이므로 흰색 단색을 두지 않습니다. Live Link의 원본 이미지를 넣는 세트에도 두지 않습니다. [LIVELINK.md](LIVELINK.md)). 오른쪽 클릭에는 “복제”, “이름 바꾸기”, “삭제”도 있습니다 (마지막 1개는 삭제 불가). 모두 실행 취소 1회으로 되돌릴 수 있습니다.
- **선택**: “텍스처 세트” 패널에서 레이어 세트가 2개 이상인 세트의 행 아래에 레이어 세트가 들여쓰기되어 표시됩니다 (더블 클릭으로 이름 변경, 드래그로 순서 변경). 누르면 현재 레이어 세트가 바뀌며 “레이어” 패널의 목록이 전환됩니다. “레이어” 패널 맨 위 드롭다운과 캔버스 오른쪽 위 영역에서도 선택할 수 있습니다.
- **2D 캔버스**: 캔버스·내비게이터·스포이트·색상으로 선택하는 영역의 “모든 레이어”는 현재 레이어 세트의 합성을 읽습니다. 출력하지 않는 레이어 세트를 보는 동안에도 그대로 그릴 수 있습니다 (그동안 2D 표시는 CPU에서 합성). 3D 보기·내보내기·Live Link는 항상 최종 결과를 사용합니다.
- **출력 할당**: “채널” 패널의 행별 드롭다운 (“출력 원본 레이어 세트”)에서 해당 채널의 최종 결과를 낼 레이어 세트 또는 “없음”을 선택합니다 (실행 취소 1회). “없음”인 채널의 최종 결과는 해당 채널의 기본값입니다 (Color이면 흰색). 출력하지 않는 레이어 세트에는 텍스처 세트 패널에서 끊어진 사슬 표시가 나타나며, 그릴 채널을 출력하지 않는 경우에는 “레이어” 패널 맨 위에도 같은 표시가 나타납니다. 현재 레이어 세트가 출력하지 않는 채널을 3D 보기에서 그려도 3D 보기에는 나타나지 않습니다.
- **레이어 이동**: 레이어를 오른쪽 클릭해 “레이어 세트로 이동”을 선택하면 다른 레이어 세트의 맨 위로 이동합니다 (그룹은 내용 전체와 함께). 레이어 세트를 가로지르는 순서 변경·그룹 안팎 이동·그룹화·병합은 할 수 없습니다.
- **삭제**: 레이어 세트를 삭제하면 내부 레이어도 삭제되며 해당 레이어 세트에서 출력하던 채널의 할당은 “없음”이 됩니다 (다른 레이어 세트로 이동하지 않음).
- **사용자 채널**: 새 사용자 채널을 만들면 채널 이름으로 레이어 세트가 생성되고 해당 채널의 출력이 그곳에 할당됩니다.

효과 (Anchor·생성기·복제 원본 등)는 해당 레이어가 속한 레이어 세트 내부만 읽습니다. 현재 레이어 세트는 저장하지 않으므로 다시 열면 첫 번째 레이어 세트부터 시작합니다. 레이어 세트가 2개 이상인 문서와 할당이 “없음”인 채널이 있는 문서는 0.6.x에서 열 수 없습니다. PSD로는 레이어 세트별 그룹으로 내보냅니다 ([GUIDE_FILES.md](GUIDE_FILES.md)).

## 마스크 사용

마스크는 레이어의 일부를 숨깁니다. 모든 채널에서 공유합니다.

1. 레이어를 선택하고 오른쪽 클릭에서 “흰색 레이어 마스크 추가” (아무것도 숨기지 않는 마스크) 또는 “검은색 레이어 마스크 추가” (전체를 숨기는 마스크)를 누릅니다. “속성”의 “흰색 마스크”, “검은색 마스크”도 같습니다.
2. 레이어 행의 마스크 썸네일을 누르면 그리기 대상이 마스크로 바뀝니다. 픽셀 썸네일을 누르면 픽셀로 돌아갑니다. 오른쪽 클릭의 “마스크에 그리기”로도 전환할 수 있습니다.
3. 브러시로 그리면 숨기고 지우개로 그리면 보이게 합니다.

마스크 썸네일을 다른 레이어 (그룹 포함)의 행으로 드래그하면 마스크를 그곳으로 이동합니다 (대상에 마스크가 있으면 교체). `Alt`를 누른 채 놓으면 복사합니다. 오른쪽 클릭의 “마스크 복사”와 “마스크에 붙여넣기”로도 복사할 수 있습니다 (여러 레이어를 선택했다면 모두에 붙여넣기). 마스크에 그리는 동안 `Ctrl+V`를 누르면 클립보드 이미지를 마스크에 붙여넣습니다 (흰색은 표시, 검은색은 숨김. 컬러 이미지는 밝기로 결정).

마스크의 “밀도” (0%면 마스크 없음과 동일), “활성화” (끄면 마스크 없음과 같지만 마스크는 유지), “반전”은 “속성”에서 변경할 수 있습니다. 마스크에 그리는 동안에는 같은 입력란 (레이어 마스크 섹션)이 그리기 도구 (브러시·지우개·채우기·다각형 채우기·그라데이션·도형·경로·스포이트)와 선택 도구 (사각형 선택·타원 선택·올가미·다각형 선택·자동 선택·선택 영역 펜)의 도구 속성 맨 아래에도 나타납니다. 선택 영역에서 마스크를 만들려면 “선택 영역을 레이어 마스크로 만들기”를 사용합니다 ([GUIDE_SELECT.md](GUIDE_SELECT.md)). “레이어 마스크 삭제”로 제거합니다.

## 보정 레이어

“새 보정 레이어”에서 다음 9종류를 선택합니다. 아래 레이어의 픽셀을 덮어쓰지 않고 외관을 보정합니다. 값은 “속성”에서 정합니다.

계조 반전, 레벨 보정, 색조·채도, 그라데이션 맵, 톤 곡선, 색상 균형, 밝기·대비, 2진화, 포스터화.

그라데이션 맵의 램프 사용법은 [GRADIENT_MAP.md](GRADIENT_MAP.md)에 있습니다.

## 채널 사용

1개의 레이어는 채널별로 픽셀을 보유합니다. 표준 6개는 색상·거칠기·금속성·높이·노멀·발광입니다. “채널” 패널에서 그릴 대상과 표시할 내용을 선택합니다.

- 행을 누르거나 행의 브러시 표시를 누르면 해당 채널이 그리기 대상이 됩니다. 눈 표시를 누르면 해당 채널이 2D “캔버스”에 나타납니다. 오른쪽 클릭에도 “그릴 채널로 지정”, “캔버스에 표시”가 있습니다.
- “채널 추가”로 자신의 채널 (사용자 채널)을 만들 수 있습니다 (채널 이름의 레이어 세트도 만들어짐. 위의 “레이어 세트” 참고). 이름은 더블 클릭으로 바꾸고, 종류 (형식 `sRGB8`·`L8`·`RGB8`)는 행 오른쪽 끝에서 선택합니다. “채널 삭제”로 지울 수 있는 것은 사용자 채널뿐입니다.

### 노멀 설정

“채널” 패널의 “노멀” 섹션은 문서 설정입니다. `.ylp`에 저장되며 변경은 실행 취소할 수 있습니다. 같은 값이 3D 보기와 내보내는 노멀에 적용됩니다.

| 항목 | 내용 |
|---|---|
| 높이 → 노멀 | 켜면 높이 채널에서 생성한 노멀을 직접 그린 노멀 레이어 아래에 추가합니다. 높이에서 매번 다시 생성하며 레이어에 그리지 않습니다 |
| 강도 | 높이의 전체 범위 (0 → 1)가 몇 텍셀 높이로 솟는지 정합니다. 음수면 볼록한 부분이 오목해집니다 |
| 가장자리 | “클램프”는 캔버스 가장자리의 기울기를 가장자리 텍셀에서 구하고, “랩 (타일)”은 반대쪽 가장자리를 읽습니다 (타일링 텍스처용) |
| 파일의 Y | 내보낼 이미지의 녹색 방향입니다. “OpenGL (Y+, Unity)” 또는 “DirectX (Y−)”입니다. Unity는 OpenGL을 사용하며 `.ylp`의 텍스처와 미리보기는 항상 OpenGL입니다 |
